# JL-031: レトラクションと冪等写像

## 対象・定義・仮定

`Idempotent p := ∀ x, p (p x) = p x`。可換性は各点での等式。固定点は `p x = x`。

可換な二つの冪等写像の合成は冪等である。レトラクションからの冪等性、固定点と像の同値、単射または全射な冪等写像の恒等性も示す。

## 完全な契約命題

```lean
theorem JonnyLean.Contracts.JL031 {α : Type u} (p q : α → α)
    (hp : ∀ x, p (p x) = p x) (hq : ∀ x, q (q x) = q x)
    (hc : ∀ x, p (q x) = q (p x)) :
    ∀ x, p (q (p (q x))) = p (q x)
```

公開定理: `JonnyLean.Functions.commuting_idempotents`。実装: `JonnyLean/Functions/Retractions.lean`。

## 証明と範囲

合成を二度適用した式の中央で可換性を使い、各写像の冪等性を適用する。固定点の像における証人はその点自身である。
