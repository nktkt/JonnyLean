# JL-076: 各因子の商から有限積の商を構成する

## 対象と定義

商の列を `xs.map (fun a => a/d)` で計算する。整除仮定が各除算の余り0を保証する。

## 証明する命題

全要素がdの倍数なら、積がdの長さ乗と各要素の商の積に分解されることを示す。点ごとの整除と共通因子の累乗整除も導く。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem product_map_quotient (d : Nat) (xs : List Nat)
    (h : ∀ a ∈ xs, d ∣ a) :
    d^xs.length * product (xs.map (fun a => a/d)) = product xs
```

公開補題: `product_map_dvd`、`product_map_quotient`、`uniform_power_dvd_product`、`product_dvd_append_left`。

## 独立契約

`contracts/JL076.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL076` で独立に記述する。`contract_JL076_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

d=0も許すが、この場合の整除仮定は全要素が0であることを意味する。空列の分解は1=1。

境界契約は `product ([12,18].map (fun a => a/6)) = 6` と `(0:Nat)^0*product (([] : List Nat).map (fun a => a/0)) = 1`。
