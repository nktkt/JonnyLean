# JL-015: 有限和がゼロとなる条件

## 対象と境界

非負な自然数値の有限和が 0 であることと、範囲内の全項が 0 であることの同値を示す。外延性、単調性、定数和、上界も整備する。

f は任意の Nat→Nat、n は項数。添字範囲は 0≤i<n、n=0 は空和であり、右辺は空の全称命題になる。

## 完全な契約命題

```lean
∀ (f : Nat → Nat) (n : Nat), sumSpec f n = 0 ↔ ∀ i : Nat, i < n → f i = 0
```

公開定理は `JonnyLean.range_sum_eq_zero_iff`。契約名は `JonnyLean.Contracts.JL015.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 契約が固定する再帰定義

実装側の定義名に依存しない、契約内の独立した定義である。両者の一致は構造帰納法で別に検査する。

```lean
def sumSpec (f : Nat → Nat) : Nat → Nat
  | 0 => 0
  | n + 1 => sumSpec f n + f n
```

## 証明の構成

項数 n について帰納法を使う。自然数の和が 0 なら両項が 0 であり、最後の項とそれ以前の項を分離する。

このモジュールに含まれる名前付き定理:

- `range_sum_congr`
- `range_sum_mono`
- `range_sum_constant`
- `range_sum_le_bound`
- `range_sum_eq_zero_iff`
- `range_sum_prefix_le`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `empty_sum`: `sumSpec (fun i => i + 100) 0 = 0`。
- `all_zero`: `sumSpec (fun _ => 0) 5 = 0`。
- `nonzero_term`: `sumSpec (fun i => i) 3 = 3`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。
