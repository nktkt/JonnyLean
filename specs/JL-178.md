# JL-178: 自然数係数の混合と期待値分子

## 対象と定義

scale n μは各出現重みをn倍し、mix m μ n νは二つのスケール測度を連結する。任意の自然数係数を許す未正規化混合である。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL178_semantics (n : Nat) (μ : Measure α) : scale n μ = μ.map (fun p => (p.1, n * p.2))
```

## 証明する命題

混合の期待値分子と総質量が係数付きの和になることを証明する。スケールの期待値・総質量、連結への分配、合成、係数1も示す。

主要公開定理: `JonnyLean.FiniteProbability.expect_mix`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL178 (m : Nat) (μ : Measure α) (n : Nat) (ν : Measure α) (f : α → Nat) : expect (mix m μ n ν) f = m * expect μ f + n * expect ν f
```

## 境界と範囲

係数の和が1であることを仮定しない。係数0の場合も出現リスト自体は残り、重みだけが0になる。

境界契約:

```lean
theorem contract_JL178_boundary : scale 0 ([(1, 2)] : Measure Nat) = [(1, 0)]
```
