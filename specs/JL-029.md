# JL-029: 写像の合成と全単射

## 対象・定義・仮定

単射は値の等しさから引数の等しさ、全射は任意の終域要素に対する原像の存在。逆写像の選択や非空性は仮定しない。

全単射の合成は全単射である。単射・全射の合成を個別に示し、合成から得られる片側の性質と全射による右消去も提供する。

## 完全な契約命題

`contracts/JL029.lean` は実装モジュールを直接 import し、以下の完全な型に公開定理を当てはめる。型変数は任意の型であり、自然数や非空型への暗黙の制限はない。明示された場合だけ判定可能性・単射性・全域性・推移性を仮定する。

```lean
theorem JonnyLean.Contracts.JL029 {α : Type u} {β : Type v} {γ : Type w} (f : α → β) (g : β → γ)
    (hf : (∀ a b, f a = f b → a = b) ∧ (∀ b, ∃ a, f a = b))
    (hg : (∀ a b, g a = g b → a = b) ∧ (∀ c, ∃ b, g b = c)) :
    (∀ a b, g (f a) = g (f b) → a = b) ∧ (∀ c, ∃ a, g (f a) = c)
```

公開定理: `JonnyLean.Functions.bijective_comp`。実装: `JonnyLean/Functions/Composition.lean`。

## 証明と範囲

単射性は外側から内側の写像へ適用する。全射性は終域から中間の原像を、次に始域の原像を取り出して結合する。
