# JL-144: 言語連結の結合則と空語単位元

## 対象と定義

連結を三つの言語へ反復し、語の分割の括弧を移動する。`epsilon` は空語だけを含む言語である。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL144_semantics (w : List α) : epsilon w ↔ w = []
```

## 証明する命題

連結の結合則を、三つの語の証人を保ったままリスト連結の結合則から導く。空語言語の左右単位元と単一語言語同士の連結も証明する。

主要公開定理: `JonnyLean.Languages.concat_assoc`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL144 (L K M : Language α) : concat (concat L K) M = concat L (concat K M)
```

## 境界と範囲

連結は一般には可換ではない。単位元は空言語ではなく空語だけの言語である。

境界契約:

```lean
theorem contract_JL144_boundary : concat (fun w : List Nat => w = [1]) (fun w => w = [2]) [1, 2]
```
