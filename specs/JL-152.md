# JL-152: 受理言語と再出発による残余

## 対象と定義

状態 q からの受理は `accept (run q w) = true`、機械の言語は初期状態からの受理とする。restart は初期状態だけを変更する。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL152_semantics (M : Machine α Q) (w : List α) : M.language w ↔ M.accept (M.run M.start w) = true
```

## 証明する命題

接頭語 u による受理言語の左商と、u を読んだ後の状態から再出発する機械の言語が等しい。任意状態からの連結受理、再出発による走行保存、空語受理も示す。

主要公開定理: `JonnyLean.Automata.Machine.language_residual`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL152 (M : Machine α Q) (u : List α) : leftQuotient u M.language = (M.restart (M.run M.start u)).language
```

## 境界と範囲

受理判定はBooleanなので語ごとに決定可能である。状態の有限性を必要としない一般則である。

境界契約:

```lean
theorem contract_JL152_boundary (M : Machine α Q) : M.language [] ↔ M.accept M.start = true
```
