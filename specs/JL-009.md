# JL-009: 整除の自然数線形結合

## 対象と境界

共通の約数は自然数係数による線形結合も割り切る。加法、切り捨て減算、加法からの取消しも補助定理として扱う。

全変数は自然数で、係数 x,y は 0 でもよい。整数係数による線形結合はこの仕様の対象外。減算補助定理は Nat の 0 切り捨て減算である。

## 完全な契約命題

```lean
∀ d a b x y : Nat, (∃ i : Nat, a = d * i) → (∃ j : Nat, b = d * j) → ∃ k : Nat, a * x + b * y = d * k
```

公開定理は `JonnyLean.divides_linear_combination`。契約名は `JonnyLean.Contracts.JL009.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 証明の構成

整除の乗法保存を二度使い、整除の加法保存で結ぶ。補助の減算保存は乗数の差と乗法の減算分配則から示す。

このモジュールに含まれる名前付き定理:

- `divides_add`
- `divides_linear_combination`
- `divides_sub`
- `divides_add_cancel_left`
- `divides_add_iff_right`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `zero_coefficients`: `∃ k : Nat, 6 * 0 + 9 * 0 = 3 * k`。
- `positive_combination`: `∃ k : Nat, 6 * 4 + 9 * 2 = 3 * k`。
- `truncated_subtraction`: `∃ k : Nat, 3 - 6 = 3 * k`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。

## 実装・依存・検査

- 実装: `JonnyLean/NumberTheory/DivisibilitySums.lean`。
- 契約: `contracts/JL009.lean`。
- 課題依存: JL-008。
- Lean: `leanprover/lean4:v4.29.1`、同梱 Init/Std のみ。
- `sorry`、`admit`、新規公理、`Classical.choice` は使用しない。
- 許容公理はプロジェクト方針の `propext` と `Quot.sound` のみ。
- 機械検査と独立レビューは区別する。レビューの正式な状態は `reviews/JL-009.json` に記録する。

```sh
lake build +JonnyLean.NumberTheory.DivisibilitySums
lake env lean -DwarningAsError=true JonnyLean/NumberTheory/DivisibilitySums.lean
lake env lean -DwarningAsError=true contracts/JL009.lean
```

契約末尾の `#print axioms` が公開定理と名前付き契約の公理依存を出力する。
