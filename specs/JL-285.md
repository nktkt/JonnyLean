# JL-285: Hoare論理のループ不変条件規則

## 対象と定義

条件が真の状態で本体が不変条件Iを保存するなら、whileが停止したときIと条件が偽であることが成り立つ。減少変量や停止仮定はないため部分正当性である。終了条件を結論から省かない。

状態は `State = Nat → Nat`、変数値は自然数である。減算は自然数の切り捨て減算を用いる。
`Exec c s t` は命令cの有限big-step導出、`run n c s` は燃料nの実行結果である。
`Hoare P c Q` は停止した実行についてのみQを保証する部分正当性を表す。

## 証明する命題

```lean
∀ (I : State → Prop) (b : BExp) (c : Cmd), Hoare (fun s => I s ∧ b.eval s = true) c I → Hoare I (.while b c) (fun s => I s ∧ b.eval s = false)
```

主定理: `JonnyLean.Imperative.hoare_while`。
命題に記載した量化・仮定をすべて保持する。有限のテスト入力のみの主張ではない。
関数の等式は全変数での値の一致を意味し、観測リストでの一致は `Agrees` と区別する。

## 独立契約と境界

`contracts/JL285.lean` の名前付き `contract` は上記の型を明記し、対象定理をその型に代入する。
`definition_check` は基礎定義の計算規則を別の命題で確認する。
次の境界・具体例も名前付き命題としてLeanで検査する。

```lean
Hoare (fun _ => True) (.while (.truth false) .skip) (fun s => True ∧ BExp.eval s (.truth false) = false)
```

0、空の観測集合、更新されない変数も定義の対象である。変数の相異条件がある定理では、その条件を外した結論は主張しない。
`none` は一般には燃料不足であり、単独では非停止の証明としない。停止を含む例題では `∃ t, Exec ...` または具体的終了状態の `Exec` を結論に含める。
