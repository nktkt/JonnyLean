# JL-142: 許可アルファベットの語と言語連結

## 対象と定義

文字述語 A : α → Prop から、全ての文字が A を満たす語の言語 alphabetLanguage A を定義する。文字の出現順や重複をそのまま保持した List α を対象とする。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL142_semantics (A : α → Prop) (w : List α) : alphabetLanguage A w ↔ ∀ a, a ∈ w → A a
```

## 証明する命題

連結語 u ++ v の全ての文字が許可されることと、u と v の両方の全ての文字が許可されることの同値を証明する。アルファベット交差と言語の共通部分の一致、アルファベット和に対する言語和からの包含、文字述語包含の保存、空語所属も示す。一般言語の和・共通部分の代数法則は補助APIとして残す。

主要公開定理: `JonnyLean.Languages.alphabetLanguage_append`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL142 (A : α → Prop) (u v : List α) : alphabetLanguage A (u ++ v) ↔ alphabetLanguage A u ∧ alphabetLanguage A v
```

## 境界と範囲

アルファベットの有限性や文字所属の決定可能性を要求しない。アルファベット和の言語は二言語の和より大きくなり得る。false と true の混合語はその具体的な反例である。空語はどの許可アルファベットの言語にも属する。

境界契約:

```lean
theorem contract_JL142_boundary : alphabetLanguage (fun b : Bool => b = false ∨ b = true) [false, true] ∧ ¬union (alphabetLanguage (fun b : Bool => b = false)) (alphabetLanguage (fun b : Bool => b = true)) [false, true]
```
