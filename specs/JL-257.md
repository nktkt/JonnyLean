# JL-257: 長さヘッダー付きリスト符号の往復

## 対象と命題

リスト長を単進ヘッダーにし、各フィールド符号を続ける自己区切り形式を構築し、任意の末尾を保持して復号する。

ヘッダーはフィールド個数でありビット数ではない。空リストもヘッダーfalseを消費する。

```lean
theorem contract_JL257 (c : Codec Bool β) (xs : List β) (rest : List Bool) : decodeList c (encodeList c xs ++ rest) = some (xs,rest) :=
  list_roundtrip c xs rest
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.Encoding.list_roundtrip` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/Encoding/FramedLists.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL257_definition (c : Codec Bool β) (xs : List β) : encodeList c xs = unary xs.length ++ encodeFields c xs := rfl
```

## 証明の構成

単進ヘッダーを復号して正しい個数を得た後、fields_roundtripを適用する。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL257_boundary : decodeList unaryCodec (encodeList unaryCodec [0,2] ++ [true]) = some ([0,2],[true]) := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。
