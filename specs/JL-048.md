# JL-048: 歩道の連結と結合則

## 対象と定義

終点と始点が一致する歩道 `p : Walk G x y` と `q : Walk G y z` を連結する。端点の一致は型検査で要求される。

`append (nil x) q = q`、`append (cons e p) q = cons e (append p q)` という再帰で連結を定義する。順序は先に `p`、次に `q` とする。

## 証明する命題

最初の歩道について帰納し、連結の長さが二つの長さの和になることを示す。空歩道の左右単位則、連結の結合則、連結後の長さが最初の長さ以上であることも示す。

主要公開定理: `JonnyLean.GraphTheory.Walk.length_append`。

契約は次の型を独立に記述し、公開定理から直接構成する。

```lean
theorem contract_JL048 {V : Type u} {G : Graph V} {x y z : V}
    (p : Walk G x y) (q : Walk G y z) :
    (p.append q).length = p.length + q.length
```

## 境界と範囲

どちらの歩道も空でよい。異なる端点を無条件に連結する演算は提供しない。連結の交換則は主張しない。
