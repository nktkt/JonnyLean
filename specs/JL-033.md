# JL-033: 二項関係の合成代数

## 対象・定義・仮定

`Compose r s a c := ∃ b, r a b ∧ s b c`。`Converse r b a := r a b`。どの関係にも関数性・全域性は要求しない。

型をまたぐ二項関係の合成は結合的である。逆関係は合成の順序を反転し、包含は合成に関して単調になる。等号関係が左右の単位元になる。

```lean
theorem JonnyLean.Contracts.JL033 {α : Type u} {β : Type v} {γ : Type w} {δ : Type z}
    (r : α → β → Prop) (s : β → γ → Prop) (t : γ → δ → Prop) (a : α) (d : δ) :
    (∃ c, (∃ b, r a b ∧ s b c) ∧ t c d) ↔
    (∃ b, r a b ∧ (∃ c, s b c ∧ t c d))
```

公開定理: `JonnyLean.Relations.compose_assoc`。実装: `JonnyLean/Relations/Composition.lean`。

## 証明と範囲

中間点 b,c の存在証人と三つの関係の証拠を、その順序を保ったまま括り直す。
