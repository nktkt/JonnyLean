# JL-200: 長方形行列積の成分上界

## 対象と定義

各行列の成分がa,b以下なら積の各成分は共通次元nにa*bを掛けた値以下になる。

`Vec n`は`Fin n → Nat`、`Mat m n`は`Fin m → Fin n → Nat`である。有限和`sum`は空次元で0、後続次元で先頭座標と残りの和を加える。`dot`は座標積の和、`mulMat`は共通次元の座標積の和である。
すべての行列・ベクトルは自然数値の関数であり、有限添字の次元は型に含まれる。

## 証明する命題

```lean
theorem mulMat_bound {m n p : Nat} (A : Fin m → Fin n → Nat) (B : Fin n → Fin p → Nat) (a b : Nat) (hA : ∀ i j, A i j ≤ a) (hB : ∀ j k, B j k ≤ b) :
    ∀ i k, mulMat A B i k ≤ n * (a*b)
```

共通添字上の各積をa*bで評価し、定数列の和を計算する。

## 量化・仮定・範囲

表示した次元・添字・係数・行列・ベクトルをすべて量化する。自然数次元には0を含み、正の次元を追加で仮定しない。`Fin n`型の添字を要求する命題では、n=0に対する添字は存在しない。
比較を含む定理では命題に明記した成分ごとの不等式だけを仮定する。係数は自然数であり、加法逆元、体、行列の一般的な可換性、実数内積空間についての主張ではない。

## 独立契約と境界検査

`contracts/JL200.lean`は入力を`Fin`から`Nat`への関数として明記した名前付き期待型`contract_JL200`を持ち、実装定理をその型へ代入する。主定理の型を推論させた別名にはしない。
表現の定義を次の独立した式で確認する。

```lean
mulMat A B i k = sum (fun j : Fin n => A i j * B j k)
```

具体計算: `mulMat (fun i j : Fin 2 => i.val+j.val+1) (fun i j : Fin 2 => i.val+j.val+1) 1 1 = 13`。
境界計算: `mulMat (fun (_ : Fin 1) (j : Fin 0) => j.val) (fun (i : Fin 0) (_ : Fin 1) => i.val) 0 0 = 0`。
同一モジュールの法則を共有する複数課題があるが、各課題の主定理と期待型は異なる。
