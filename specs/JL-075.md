# JL-075: 有限積と点ごとの乗算・累乗の交換

## 対象と定義

有限積の入力へ `List.map` で自然数重みを付ける。

## 証明する命題

有限列に沿う二関数の点ごとの積を、各関数の有限積の積へ分解する。定数列、累乗列、共通スカラーの因数分解も示す。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem product_map_mul (f g : α → Nat) (xs : List α) :
    product (xs.map (fun a => f a*g a)) = product (xs.map f)*product (xs.map g)
```

公開補題: `product_map_mul`、`product_map_const`、`product_map_pow`、`product_map_scale`。

## 独立契約

`contracts/JL075.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL075` で独立に記述する。`contract_JL075_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

空列に対するスカラー因数はc^0=1。スカラー0と指数0も扱う。

境界契約は `product (([] : List Nat).map (fun n => n^0)) = 1` と `product ([2,3].map (fun n => 5*n)) = 150`。
