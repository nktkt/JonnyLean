# JL-045: 最初の一致の探索証明書

## 対象・定義・仮定

判定器 p は Bool 値。`firstMatchSplit` は最初の真で走査を止め、その要素から後ろを残り列に置く。一致なしなら前置列は全入力、残りは空。数値添字の最小性を直接扱う代わりに前置列の全拒否で最初の一致を表す。

最初の一致の直前で列を分け、前置列と残りの再結合が元の列であること、前置列の全要素が拒否されること、残りが非空なら先頭が受理されることを同時に示す。残りが空である条件も完全に特徴付ける。

## 完全な契約命題

`contracts/JL045.lean` は実装モジュールを直接 import し、以下の完全な型に公開定理を当てはめる。型変数は任意の型であり、自然数や非空型への暗黙の制限はない。明示された場合だけ判定可能性・単射性・全域性・推移性を仮定する。

```lean
theorem JonnyLean.Contracts.JL045 {α : Type u} (p : α → Bool) (xs : List α) :
    xs = (JonnyLean.Algorithms.firstMatchSplit p xs).1 ++
      (JonnyLean.Algorithms.firstMatchSplit p xs).2 ∧
    (∀ x ∈ (JonnyLean.Algorithms.firstMatchSplit p xs).1, p x = false) ∧
    (∀ x tail, (JonnyLean.Algorithms.firstMatchSplit p xs).2 = x :: tail → p x = true)
```
