# JL-016: 有限和の線形性

## 対象と境界

自然数係数による二つの列の線形結合と有限和が交換する。項ごとの差の和には必要な大小条件を明示する。

f,g は自然数値の任意の関数。a,b,n は 0 を含む自然数。主定理には大小仮定は不要。差の和の補助定理では範囲内の g i≤f i を要求する。

## 完全な契約命題

```lean
∀ (f g : Nat → Nat) (a b n : Nat), sumSpec (fun i => a * f i + b * g i) n = a * sumSpec f n + b * sumSpec g n
```

公開定理は `JonnyLean.range_sum_linear_combination`。契約名は `JonnyLean.Contracts.JL016.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 契約が固定する再帰定義

実装側の定義名に依存しない、契約内の独立した定義である。両者の一致は構造帰納法で別に検査する。

```lean
def sumSpec (f : Nat → Nat) : Nat → Nat
  | 0 => 0
  | n + 1 => sumSpec f n + f n
```

## 証明の構成

加法の保存と定数倍の保存を、それぞれ項数に関する帰納法で証明する。主定理はこの二つを組み合わせる。

このモジュールに含まれる名前付き定理:

- `range_sum_add`
- `range_sum_mul_left`
- `range_sum_mul_right`
- `range_sum_linear_combination`
- `range_sum_sub`
- `range_sum_complement`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `empty_combination`: `sumSpec (fun i => 3 * i + 5 * (i + 1)) 0 = 0`。
- `concrete_combination`: `sumSpec (fun i => 2 * i + 3 * (i + 1)) 4 = 42`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。
