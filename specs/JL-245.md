# JL-245: 先読みパーサーの入力非消費

## 対象と命題

lookAheadは元パーサーの値を保ちつつ、成功時の末尾を元入力へ戻す。その正確な成功条件を示す。

基底パーサーのSafe性は不要で、元入力をそのまま返す。失敗を成功へ変えない。

```lean
theorem contract_JL245 (p : Parser α β) (input rest : List α) (b : β) : lookAhead p input = some (b,rest) ↔ rest = input ∧ ∃ discarded, p input = some (b,discarded) :=
  lookAhead_iff p input rest b
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.Parsing.lookAhead_iff` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/Parsing/Primitives.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL245_definition (p : Parser α β) (input : List α) (h : p input = none) : lookAhead p input = none := by simp [lookAhead,h]
```

## 証明の構成

元パーサーのOption結果を分解し、返した値の同一性と末尾の復元を取り出す。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL245_boundary : lookAhead (satisfy id) [true,false] = some (true,[true,false]) := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。

## 検証と範囲

- 日本語仕様、主定理、定義契約、境界契約を別の担当が照合する。
- Lean 4.29.1同梱のInit/StdとJonnyLean内部の証明のみを使う。
- `sorry`、`admit`、独自公理、`Classical.choice`を許さず、privateと自動生成宣言を含む公理監査を行う。許容する基礎は`propext`と`Quot.sound`だけ。
- 機械検査の成功と意味のAIレビューを区別し、人間の承認は未記録のままとする。
