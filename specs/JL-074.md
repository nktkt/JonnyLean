# JL-074: 重み付き有限和による合同と整除の保存

## 対象と定義

`weightedSum w []=0`、`weightedSum w (a::xs)=w a+weightedSum w xs`。重複した値は出現ごとに数える。

## 証明する命題

任意型の有限列上で重み付き和を定義し、各位置での合同から和の合同を導く。線形結合、共通約数、連結も扱う。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem weightedSum_residue (m : Nat) (w v : α → Nat) (xs : List α)
    (h : ∀ a ∈ xs, w a % m = v a % m) :
    weightedSum w xs % m = weightedSum v xs % m
```

公開補題: `weightedSum_append`、`weightedSum_residue`、`weightedSum_dvd`、`weightedSum_linear`。

## 独立契約

`contracts/JL074.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL074` で独立に記述する。`contract_JL074_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

空列の和は0。合同の法0も許し、このとき各重みの等式を和へ保存する。

境界契約は `weightedSum (fun n : Nat => n*n) [] = 0` と `weightedSum (fun n : Nat => n*n) [1,2,3] = 14`。
