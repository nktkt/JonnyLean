# JL-017: 有限和の区間分割

## 対象と境界

最初の m+n 項の和を、最初の m 項と、添字を m だけずらした n 項に分割する。三分割、中央項の抽出、先頭項の移動も扱う。

m,n は任意の自然数で両方 0 を許す。後半の添字は m+i で、m+1+i ではない。

## 完全な契約命題

```lean
∀ (f : Nat → Nat) (m n : Nat), sumSpec f (m + n) = sumSpec f m + sumSpec (fun i => f (m + i)) n
```

公開定理は `JonnyLean.range_sum_split`。契約名は `JonnyLean.Contracts.JL017.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 契約が固定する再帰定義

実装側の定義名に依存しない、契約内の独立した定義である。両者の一致は構造帰納法で別に検査する。

```lean
def sumSpec (f : Nat → Nat) : Nat → Nat
  | 0 => 0
  | n + 1 => sumSpec f n + f n
```

## 証明の構成

後半の長さ n について帰納法を使い、最後の項 f(m+n) を両側に追加する。

このモジュールに含まれる名前付き定理:

- `range_sum_split`
- `range_sum_tail`
- `range_sum_split_three`
- `range_sum_middle`
- `range_sum_shift_one`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `empty_prefix`: `sumSpec (fun i => i + 1) (0 + 3) = sumSpec (fun i => i + 1) 0 + sumSpec (fun i => (0 + i) + 1) 3`。
- `empty_tail`: `sumSpec (fun i => i + 1) (3 + 0) = sumSpec (fun i => i + 1) 3 + sumSpec (fun i => (3 + i) + 1) 0`。
- `split_example`: `sumSpec (fun i => i) 5 = sumSpec (fun i => i) 2 + sumSpec (fun i => 2 + i) 3`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。
