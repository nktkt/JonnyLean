# JL-077: 有限積の上下界と列の分割

## 対象と定義

自然数の非負性を使う有限積の比較。因子の並び順と列の長さを明示する。

## 証明する命題

各因子がc以下なら有限積がcの長さ乗以下となることを示す。下界、点ごとの単調性、反転不変性、take/drop分割も証明する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem product_bound (c : Nat) (xs : List Nat) (h : ∀ a ∈ xs, a ≤ c) :
    product xs ≤ c^xs.length
```

公開補題: `product_map_mono`、`product_bound`、`product_lower_bound`、`product_reverse`、`product_split`。

## 独立契約

`contracts/JL077.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL077` で独立に記述する。`contract_JL077_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

因子0を排除しない。空列では上界も下界も1となる。反転では重複を保持する。

境界契約は `product [2,3,4] ≤ (4:Nat)^3` と `product (([2,0,7] : List Nat).reverse) = 0`。
