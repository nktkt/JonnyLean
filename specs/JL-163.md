# JL-163: 座標別選択列と積公式

## 対象と定義

リストのリストxssを各座標の候補とし、各座標から一つずつ選んだ語をchoices xssで列挙する。Compatibleは語と候補列の長さおよび座標ごとの所属を再帰的に検査する命題である。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL163_semantics (xs : List α) (xss : List (List α)) : choices (xs :: xss) = xs.flatMap (fun x => (choices xss).map (fun w => x :: w))
```

## 証明する命題

選択語の個数が座標ごとの候補数の積であることを証明する。所属とCompatibleの同値、出力語の長さ、空候補座標による列挙消滅も示す。

主要公開定理: `JonnyLean.Counting.length_choices`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL163 (xss : List (List α)) : (choices xss).length = natProduct (xss.map List.length)
```

## 境界と範囲

座標がゼロ個なら空語を一個列挙する。どこかの座標の候補が空なら選択結果は存在しない。

境界契約:

```lean
theorem contract_JL163_boundary : choices ([] : List (List Nat)) = [[]]
```
