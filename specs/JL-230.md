# JL-230: 正規表現反転の意味保存

## 対象と命題

連結順序を逆にし各部分式を再帰的に反転する変換が、入力語の反転と一致する。

閉包も反転し、有限語のみを扱う。文字自体は変換しない。

```lean
theorem contract_JL230 (r : Regex α) (w : List α) : denotes (reversed r) w ↔ denotes r w.reverse :=
  reversed_correct r w
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.RegularExpressions.reversed_correct` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/RegularExpressions/Transformations.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL230_definition (r s : Regex α) : reversed (.seq r s) = .seq (reversed s) (reversed r) := rfl
```

## 証明の構成

連結反転法則と、Starの連結成分を逆順に組み直す構成的な補題を用いる。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL230_boundary : accepts (reversed (.seq (.atom true) (.atom false)) : Regex Bool) [false,true] = true := by decide
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。

## 検証と範囲

- 日本語仕様、主定理、定義契約、境界契約を別の担当が照合する。
- Lean 4.29.1同梱のInit/StdとJonnyLean内部の証明のみを使う。
- `sorry`、`admit`、独自公理、`Classical.choice`を許さず、privateと自動生成宣言を含む公理監査を行う。許容する基礎は`propext`と`Quot.sound`だけ。
- 機械検査の成功と意味のAIレビューを区別し、人間の承認は未記録のままとする。
- 契約ファイル: `contracts/JL230.lean`。
