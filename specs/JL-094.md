# JL-094: 係数の再帰的拡大による入力の倍率変更

## 対象と定義

`dilate c []=[]`、`dilate c (a::p)=a::scale c (dilate c p)`。定数項は変更しない。

## 証明する命題

p(cX)を係数ごとの再帰的な倍率変更として構成し、評価との一致、倍率合成、係数長、単位倍率とスカラー倍の保存を証明する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem evaluate_dilate (c : Nat) (p : Polynomial) (x : Nat) :
    evaluate (dilate c p) x = evaluate p (c*x)
```

公開補題: `evaluate_dilate`、`dilate_dilate`、`dilate_length`、`dilate_one`、`dilate_scale`。

## 独立契約

`contracts/JL094.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL094` で独立に記述する。`contract_JL094_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

倍率0でも定数項は残る。係数列の長さは元と同じで、末尾0を削除しない。

境界契約は `dilate 0 [3,2,1] = [3,0,0]` と `dilate 2 [3,2,1] = [3,4,4]`。
