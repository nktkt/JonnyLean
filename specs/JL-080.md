# JL-080: 有限列の最大公約数・最小公倍数・積の関係

## 対象と定義

JL-062、JL-066、JL-067の三つの畳み込みを同じ自然数列に適用する。非空列はa::xsで表す。

## 証明する命題

非空列の最大公約数が最小公倍数を割ること、最小公倍数が有限積を割ることを合成し、整除順序の吸収則を証明する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem listGcd_listLcm_absorb (a : Nat) (xs : List Nat) :
    Nat.gcd (listGcd (a::xs)) (listLcm (a::xs)) = listGcd (a::xs)
```

公開補題: `listLcm_dvd_product`、`listGcd_dvd_listLcm`、`listGcd_listLcm_absorb`、`common_dvd_product`、`common_multiple_product`。

## 独立契約

`contracts/JL080.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL080` で独立に記述する。`contract_JL080_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

gcdがlcmを割る結論では非空性が必要。空列ではgcd=0、lcm=1で0は1を割らない。

境界契約は `Nat.gcd (listGcd [6,10,15]) (listLcm [6,10,15]) = 1` と `listLcm [0,6] = 0`。
