# JL-151: 決定性遷移の反復と語の分割

## 対象と定義

`Machine α Q` は遷移 Q → α → Q、初期状態、Boolean受理判定を持つ。run は空語で現在状態を返し、先頭文字を遷移に渡して残りを処理する。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL151_semantics (M : Machine α Q) (q : Q) (a : α) (w : List α) : M.run q (a :: w) = M.run (M.step q a) w
```

## 証明する命題

連結語の走行が前半の走行結果から後半を走行することと一致すると示す。空語・先頭文字・一文字語・同一文字反復の走行式も示す。

主要公開定理: `JonnyLean.Automata.Machine.run_append`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL151 (M : Machine α Q) (q : Q) (u v : List α) : M.run q (u ++ v) = M.run (M.run q u) v
```

## 境界と範囲

走行法則自体は任意状態型で成立する。DFAへ適用する場合の有限状態carrierはJL-160で明示的に扱う。

境界契約:

```lean
theorem contract_JL151_boundary (M : Machine α Q) (q : Q) : M.run q [] = q
```
