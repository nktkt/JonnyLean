# JL-096: 非負係数多項式の単調性と下界

## 対象と定義

`CoefficientLE [] q=True`、非空列と空列ではFalse、両列が非空なら先頭の大小と末尾の比較の論理積。

## 証明する命題

入力値および係数を大きくすると評価が小さくならないことを示す。係数の比較は短い左側を許す再帰関係として構成し、定数項と接頭係数列からの下界を導く。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem evaluate_coefficients_mono (p q : Polynomial) (x : Nat)
    (h : CoefficientLE p q) : evaluate p x ≤ evaluate q x
```

公開補題: `evaluate_mono`、`evaluate_coefficients_mono`、`evaluate_constant_lower`、`evaluate_prefix_lower`、`evaluate_positive_of_constant`。

## 独立契約

`contracts/JL096.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL096` で独立に記述する。`contract_JL096_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

係数は自然数であるため非負性を別途仮定しない。係数関係は十分条件であり、評価大小の必要条件とは主張しない。

境界契約は `evaluate [1,2] 3 ≤ evaluate [2,3,4] 3` と `evaluate [0,0,1] 0 = 0`。
