# JL-103: 木への写像と中順走査の可換性

## 対象と境界

値だけを写す木のmapを実行してから走査した結果は、先に走査して列をmapした結果と一致する。写像合成と節点数保存を伴う。

木は空木 `empty` または左右の部分木と値を持つ `node` からなる有限二分木。空木は節点数・高さ0で、外部葉としては1個に数える。値型に有限性・順序・等号判定は仮定しない。

## 完全な契約命題

```lean
∀ (α : Type u) (β : Type v) (f : α → β) (t : Tree α), traversal (Tree.map f t) = (traversal t).map f
```

公開定理は `JonnyLean.Trees.Tree.inorder_map`。固定された名前付き契約は `JonnyLean.Contracts.JL103.contract`。

## 独立した意味モデル

以下は `JonnyLean/Trees/SpecificationModels.lean` にある固定モデルである。実装対象の関数を呼ばずに再帰または一命令の状態遷移を定義する。各 `*_matches` 補題を構造帰納法で検査してから公開定理と接続する。

```lean
def traversal : Tree α → List α
  | .empty => []
  | .node l x r => traversal l ++ [x] ++ traversal r
```

## 証明の構成と再利用補題

構文または入力列の構造帰納法を基礎にし、任意の部分木・式・初期状態について帰納仮定を適用する。蓄積引数・後続列・環境は必要に応じて一般化している。独立モデルとの橋渡しは契約の検査に含まれ、主張を実装の型の別名だけで済ませない。

この課題に関連する再利用補題:

- `map_comp`。
- `map_size`。

同じ補題を複数の課題として重複計上しない。評価保存、固定点、サイズ制約、静的検査は異なる明示命題として区別する。

## 境界例

- `empty_map`: `Tree.map Nat.succ (Tree.empty : Tree Nat) = .empty`。
- `mapped_node`: `traversal (Tree.map Nat.succ (.node .empty 3 .empty)) = [4]`。

有限例は境界条件の固定に使う。一般命題の証明を例の列挙で代替しない。

- 実装: `JonnyLean/Trees/Binary.lean`。

- 独立モデル: `JonnyLean/Trees/SpecificationModels.lean`（editable対象外）。

- 全宣言の許容公理依存は `propext` と `Quot.sound` のみ。
