# JL-055: 有限アルファベット上の語の列挙

## 対象と定義

任意の型 `α` のリストをアルファベットとし、`words alphabet n : List (List α)` で長さ `n` の語を列挙する。等値判定や重複除去は要求しない。

長さ 0 の語は空語ただ一つ。長さ `n+1` の語はアルファベットの各出現 `a` について長さ `n` の全語へ `a` を前置し、それらを平坦化したリストとする。

## 証明する命題

列挙への所属が「語の長さが `n` であり、すべての文字がアルファベットに属する」ことと同値であると示す。語の長さと各文字の所属を取り出す補助定理、アルファベットを拡大したときの所属の保存も示す。

主要公開定理: `JonnyLean.Combinatorics.mem_words`。

契約は次の型を独立に記述し、公開定理から直接構成する。

```lean
theorem contract_JL055 {α : Type u} (alphabet : List α) (n : Nat) (w : List α) :
    w ∈ words alphabet n ↔ w.length = n ∧ ∀ a, a ∈ w → a ∈ alphabet
```

## 境界と範囲

空アルファベットでも長さ 0 の語は 1 個。アルファベットに重複があれば列挙結果にも重複がある。この課題は重複のない集合列挙を主張しない。Boolean の長さ 2 と重複アルファベットを検査する。
