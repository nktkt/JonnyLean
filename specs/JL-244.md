# JL-244: 反復回数上限と早期停止の完全性

## 対象と命題

manyの結果個数は燃料以下であり、燃料未満で止まったなら返された末尾で基底パーサーは失敗する。

燃料ちょうどで止まる場合には次が失敗するとは限らない。消費しないpureでも燃料上限を守る。

```lean
theorem contract_JL244 (p : Parser α β) (n : Nat) (input : List α) : (many p n input).1.length ≤ n ∧ ((many p n input).1.length < n → p (many p n input).2 = none) :=
  many_bounds p n input
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.Parsing.many_bounds` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/Parsing/Repetition.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL244_definition (p : Parser α β) (n : Nat) (input : List α) (h : p input = none) : many p (n+1) input = ([],input) := by simp [many,h]
```

## 証明の構成

燃料の帰納法。成功枝では結果長が一つ増え、厳密な上限未満の仮定を残りの燃料へ移す。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL244_boundary : many (pureP 7 : Parser Bool Nat) 3 [] = ([7,7,7],[]) := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。
