# JL-046: 有向グラフの構成と包含の反対称性

## 対象と定義

任意の型 `V` 上の有向グラフを、頂点間の命題 `edge : V → V → Prop` を持つ構造体として定義する。有限性・辺の決定可能性・自己ループの禁止は仮定しない。

`empty.edge x y = False`、`complete.edge x y = True`。和の辺は論理和、共通部分の辺は論理積、転置の辺は向きを交換した辺とする。`Subgraph G H` は全頂点対での辺の含意を意味する。

## 証明する命題

両方向の辺包含から、グラフ構造の等式を示す。辺述語の論理同値を命題外延性、関数外延性で等式へ変換する。包含の反射性・推移性、空グラフからの包含、完全グラフへの包含、和・共通部分の交換則、転置の対合性も公開する。

主要公開定理: `JonnyLean.GraphTheory.Graph.subgraph_antisymm`。

契約は次の型を独立に記述し、公開定理から直接構成する。

```lean
theorem contract_JL046 {V : Type u} {G H : Graph V} :
    (∀ x y, G.edge x y → H.edge x y) →
    (∀ x y, H.edge x y → G.edge x y) → G = H
```

## 境界と範囲

空グラフは自己ループを持たず、完全グラフは自己ループを持つ。空の頂点型も許す。辺の多重度はこのモデルには含めない。
