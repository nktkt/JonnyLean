# JL-171: 自然数重みを持つ有限出現測度

## 対象と定義

`Measure α := List (α × Nat)` とし、各出現に値と自然数重みを持たせる。totalは全出現の重み和、point a nは単一出現、dirac aは重み1の点測度である。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL171_semantics (a : α) (n : Nat) (μ : Measure α) : total ((a, n) :: μ) = n + total μ
```

## 証明する命題

測度リストの連結で総質量が加法的になることを示す。空・先頭出現、点測度、Dirac測度、全て重み0の列の総質量も証明する。

主要公開定理: `JonnyLean.FiniteProbability.total_append`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL171 (μ ν : Measure α) : total (μ ++ ν) = total μ + total ν
```

## 境界と範囲

同じ値の出現は統合しない。空測度と総質量0を許す未正規化モデルであり、確率としての正規化にはJL-177の正性を要求する。

境界契約:

```lean
theorem contract_JL171_boundary : total ([(1, 0), (1, 0)] : Measure Nat) = 0
```
