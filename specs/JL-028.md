# JL-028: 単射写像の像と共通部分

## 対象・定義・仮定

像は存在量化による定義。単射性は `∀ a b, f a = f b → a = b`。単射性なしでは共通部分の像から像の共通部分への包含だけを主張する。

単射写像は述語の共通部分を像へ移すとき等しさを保つ。逆像による復元と、像が包含を反映することも示す。

```lean
theorem JonnyLean.Contracts.JL028 {α : Type u} {β : Type v} (f : α → β)
    (hf : ∀ a b, f a = f b → a = b) (p q : α → Prop) :
    ∀ y, (∃ x, (p x ∧ q x) ∧ f x = y) ↔
      ((∃ x, p x ∧ f x = y) ∧ (∃ x, q x ∧ f x = y))
```

公開定理: `JonnyLean.Predicate.image_meet_of_injective`。実装: `JonnyLean/Logic/InjectiveImages.lean`。

## 証明と範囲

二つの像の証人 a,b は同じ像を持つので単射性により等しい。この同一の証人が両方の述語を満たす。全射の補助定理では明示された存在証人を使用する。
