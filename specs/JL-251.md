# JL-251: 終端付き単進自然数の完全な復号仕様

## 対象と命題

自然数nをtrueをn個 followed by falseで符号化し、復号成功がその符号語と未消費末尾への分解に一致する。

0もfalse一つで表す。trueだけの未終端入力は失敗する。桁数効率を主張する方式ではない。

```lean
theorem contract_JL251 (input : List Bool) (n : Nat) (rest : List Bool) : readUnary input = some (n,rest) ↔ input = unary n ++ rest :=
  readUnary_exact input n rest
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.Encoding.readUnary_exact` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/Encoding/Unary.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL251_definition (n : Nat) : unary n = List.replicate n true ++ [false] := rfl
```

## 証明の構成

nについてのroundtripと入力についてのsoundnessを、それぞれ帰納法で証明して同値にまとめる。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL251_boundary : readUnary [true,true,false,true] = some (2,[true]) := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。

## 検証と範囲

- 日本語仕様、主定理、定義契約、境界契約を別の担当が照合する。
- Lean 4.29.1同梱のInit/StdとJonnyLean内部の証明のみを使う。
- `sorry`、`admit`、独自公理、`Classical.choice`を許さず、privateと自動生成宣言を含む公理監査を行う。許容する基礎は`propext`と`Quot.sound`だけ。
