# JL-220: 正規化外積からの冪等行列

## 対象と定義

中間内積が1となる二ベクトルの外積行列は、自分自身との積で変わらない。

`Vec n`は`Fin n → Nat`、`Mat m n`は`Fin m → Fin n → Nat`である。有限和`sum`は空次元で0、後続次元で先頭座標と残りの和を加える。`dot`は座標積の和、`mulMat`は共通次元の座標積の和である。
すべての行列・ベクトルは自然数値の関数であり、有限添字の次元は型に含まれる。

## 証明する命題

```lean
theorem outer_idempotent_of_dot_one {n : Nat} (x y : Fin n → Nat) (h : dot y x = 1) :
    mulMat (outer x y) (outer x y) = outer x y
```

二外積の積公式で内積を係数として取り出し、仮定による係数1とスカラー単位則を適用する。同じ作用の二度適用で不変になることとトレースが1になることも証明する。

## 量化・仮定・範囲

表示した次元・添字・係数・行列・ベクトルをすべて量化する。自然数次元には0を含み、正の次元を追加で仮定しない。`Fin n`型の添字を要求する命題では、n=0に対する添字は存在しない。
比較を含む定理では命題に明記した成分ごとの不等式だけを仮定する。係数は自然数であり、加法逆元、体、行列の一般的な可換性、実数内積空間についての主張ではない。

## 独立契約と境界検査

`contracts/JL220.lean`は入力を`Fin`から`Nat`への関数として明記した名前付き期待型`contract_JL220`を持ち、実装定理をその型へ代入する。主定理の型を推論させた別名にはしない。
表現の定義を次の独立した式で確認する。

```lean
outer x y i j = x i * y j
```

具体計算: `trace (outer (fun i : Fin 2 => i.val+1) (fun i => i.val+1)) = 5`。
境界計算: `trace (outer (fun i : Fin 0 => i.val) (fun i => i.val)) = 0`。
さらにx=(1,0)、y=(1,2)について内積が1であり外積が冪等となる具体例を検査する。
同一モジュールの法則を共有する複数課題があるが、各課題の主定理と期待型は異なる。
