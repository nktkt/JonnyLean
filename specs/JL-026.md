# JL-026: 述語の束と分配法則

## 対象・定義・仮定

述語は `α → Prop`。`meet p q x := p x ∧ q x`、`join p q x := p x ∨ q x`、`complement p x := ¬ p x`。集合の等しさは各点での論理同値とする。排中律は仮定しない。

共通部分は和集合へ分配される。包含関係の上下限性、補集合の反変性、和集合に対するド・モルガン則も構成的に示す。

```lean
theorem JonnyLean.Contracts.JL026 {α : Type u} (p q r : α → Prop) :
    ∀ x, (p x ∧ (q x ∨ r x)) ↔ ((p x ∧ q x) ∨ (p x ∧ r x))
```
