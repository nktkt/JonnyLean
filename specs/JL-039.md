# JL-039: 有限集合の差による濃度分解

## 対象・定義・仮定

差は A の列から B に属さない要素を抽出する。濃度は重複のない列の長さ。A と B の包含関係や互いに素という仮定は不要。

任意の有限集合 A,B に対して、A∩B と A\B の濃度の和は A の濃度に等しい。互いに素な被覆、差と和集合のド・モルガン型の関係も示す。

## 完全な契約命題

`contracts/JL039.lean` は実装モジュールを直接 import し、以下の完全な型に公開定理を当てはめる。型変数は任意の型であり、自然数や非空型への暗黙の制限はない。明示された場合だけ判定可能性・単射性・全域性・推移性を仮定する。

```lean
theorem JonnyLean.Contracts.JL039 {α : Type u} [DecidableEq α] (A B : JonnyLean.FiniteSet α) :
    (JonnyLean.FiniteSet.intersection A B).elems.length +
      (JonnyLean.FiniteSet.difference A B).elems.length = A.elems.length
```

公開定理: `JonnyLean.FiniteSet.card_intersection_add_difference`。実装: `JonnyLean/Collections/Difference.lean`。

## 証明と範囲

共通部分と差が互いに素で、それらの和集合が A と外延的に同値であることを示す。既存の互いに素な和集合の濃度定理と同値集合の濃度保存を適用する。
