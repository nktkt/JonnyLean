# JL-044: 重複除去と有限集合の構成

## 対象・定義・仮定

`deduplicate` は先頭が末尾に現れる場合に先頭を捨てる。各値の最後の出現を残すアルゴリズム。`DecidableEq α` を仮定する。選択される出現順の安定性の独立定理や計算量の保証は対象外。

重複除去の結果は Nodup であり、元の列と同じ要素を持つ。長さは増えず、重複なしの列を変えず、冪等である。結果から FiniteSet を構成する。

## 完全な契約命題

`contracts/JL044.lean` は実装モジュールを直接 import し、以下の完全な型に公開定理を当てはめる。型変数は任意の型であり、自然数や非空型への暗黙の制限はない。明示された場合だけ判定可能性・単射性・全域性・推移性を仮定する。

```lean
theorem JonnyLean.Contracts.JL044 {α : Type u} [DecidableEq α] (xs : List α) :
    (JonnyLean.Algorithms.deduplicate xs).Nodup
```

## 証明と範囲

まず所属の同値を帰納的に示す。先頭を残す場合、元の末尾に存在しないことを所属同値で結果の末尾へ移し、Nodup を構成する。
