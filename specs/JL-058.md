# JL-058: 二項係数と位置選択の個数

## 対象と定義

自然数上の `binomial n k` を Pascal の漸化式で定義し、JL-057 の選択列挙の長さと接続する。

`binomial n 0 = 1`、`binomial 0 (k+1) = 0`、`binomial (n+1) (k+1) = binomial n k + binomial n (k+1)`。これらで範囲外も含め全自然数に定義する。

## 証明する命題

入力リストについて帰納し、選択列挙の個数が `binomial xs.length k` になることを示す。元の値の重複に依存しない位置の選択数である。全位置選択と不可能な選択の結果から対角値 1 と範囲外値 0 を導き、1 位置の選択数が `n` であることも示す。

主要公開定理: `JonnyLean.Combinatorics.length_selections`。

契約は次の型を独立に記述し、公開定理から直接構成する。

```lean
theorem contract_JL058 {α : Type u} (xs : List α) (k : Nat) :
    (selections k xs).length = binomial xs.length k
```

## 境界と範囲

`binomial 0 0 = 1`、`binomial 5 2 = 10`、`binomial 3 4 = 0` を検査する。階乗表示や実数への拡張はこの課題の範囲外である。
