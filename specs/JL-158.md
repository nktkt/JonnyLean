# JL-158: 到達状態集合の閉性と最小性

## 対象と定義

状態 q の到達可能性は、初期状態からある有限語を読んだ結果が q であることと定義する。語の存在を命題として保持する。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL158_semantics (M : Machine α Q) (q : Q) : M.Reachable q ↔ ∃ w, M.run M.start w = q
```

## 証明する命題

初期状態を含む遷移閉集合が全到達状態を含む最小性を示す。初期状態の到達性、一文字遷移・任意語による閉性、受理語からの受理到達状態の存在も示す。

主要公開定理: `JonnyLean.Automata.Machine.reachable_minimal`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL158 (M : Machine α Q) (P : Q → Prop) (hs : M.Stable P) (h0 : P M.start) : ∀ q, M.Reachable q → P q
```

## 境界と範囲

到達語の列挙・最短語の選択は主張しない。状態が有限かどうかによらず成立する。

境界契約:

```lean
theorem contract_JL158_boundary (M : Machine α Q) : M.Reachable M.start
```
