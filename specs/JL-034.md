# JL-034: 核関係と明示的切断による因子分解

## 対象・定義・仮定

`Kernel f a b := f a = f b`。切断は `f (s b) = b`。全射だけから切断の存在は主張せず、s は明示的な入力とする。

同じ f の値を持つ点で g が一定であり、f の切断 s が与えられれば g は g∘s を通して因子分解する。核関係の同値関係性と単射後合成による保存、一意性を示す。

## 完全な契約命題

`contracts/JL034.lean` は実装モジュールを直接 import し、以下の完全な型に公開定理を当てはめる。型変数は任意の型であり、自然数や非空型への暗黙の制限はない。明示された場合だけ判定可能性・単射性・全域性・推移性を仮定する。

```lean
theorem JonnyLean.Contracts.JL034 {α : Type u} {β : Type v} {γ : Type w}
    (f : α → β) (s : β → α) (hs : ∀ b, f (s b) = b)
    (g : α → γ) (hg : ∀ a a', f a = f a' → g a = g a') :
    ∀ a, g (s (f a)) = g a
```

公開定理: `JonnyLean.Relations.factor_with_section`。実装: `JonnyLean/Relations/Kernels.lean`。

## 証明と範囲

f (s (f a)) = f a により s (f a) と a は同じファイバーに属するので、g のファイバー上の一定性を適用する。
