# JL-169: 順序を保つ二語の混合と二項係数

## 対象と定義

shuffles xs ys は各語内の順序を保って二語を混合する全選択を列挙する。両語が非空なら先頭をどちらから取るかで分岐する。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL169_semantics (a b : α) (xs ys : List α) : shuffles (a :: xs) (b :: ys) = (shuffles xs (b :: ys)).map (fun w => a :: w) ++ (shuffles (a :: xs) ys).map (fun w => b :: w)
```

## 証明する命題

混合列挙の個数が binomial (length xs + length ys) (length xs) に等しいことをPascal漸化式で証明する。各出力語の長さと空の右語との混合も示す。

主要公開定理: `JonnyLean.Counting.length_shuffles`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL169 (xs ys : List α) : (shuffles xs ys).length = JonnyLean.Combinatorics.binomial (xs.length + ys.length) xs.length
```

## 境界と範囲

同じ文字の出自も区別して列挙するため値列は重複し得る。再帰の停止性は二語の長さの和で証明する。

境界契約:

```lean
theorem contract_JL169_boundary (ys : List α) : shuffles [] ys = [ys]
```
