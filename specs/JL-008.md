# JL-008: 整除の積への保存

## 対象と境界

a が c を割り切り、b が d を割り切るなら、a*b が c*d を割り切ることを示す。整除の推移性も証人から構成する。

a,b,c,d はすべて自然数。0 による整除も定義どおりに扱い、除数が正であるとは仮定しない。

## 完全な契約命題

```lean
∀ a b c d : Nat, (∃ i : Nat, c = a * i) → (∃ j : Nat, d = b * j) → ∃ k : Nat, c * d = (a * b) * k
```

公開定理は `JonnyLean.divides_product`。契約名は `JonnyLean.Contracts.JL008.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 証明の構成

仮定の乗数 i,j を取り出し、結論の乗数を i*j とする。積の結合法則と交換法則で等式を確認する。

このモジュールに含まれる名前付き定理:

- `divides_refl`
- `divides_trans`
- `divides_mul_right`
- `divides_mul_left`
- `divides_product`
- `zero_divides_iff`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `zero_divisor`: `∃ k : Nat, 0 * 6 = (0 * 3) * k`。
- `product_witness`: `∃ k : Nat, 6 * 20 = (2 * 5) * k`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。

## 実装・依存・検査

- 実装: `JonnyLean/NumberTheory/Divisibility.lean`。
- 契約: `contracts/JL008.lean`。
- 課題依存: なし（Lean 同梱 Init/Std のみ）。
- Lean: `leanprover/lean4:v4.29.1`、同梱 Init/Std のみ。
- `sorry`、`admit`、新規公理、`Classical.choice` は使用しない。
- 許容公理はプロジェクト方針の `propext` と `Quot.sound` のみ。
- 機械検査と独立レビューは区別する。レビューの正式な状態は `reviews/JL-008.json` に記録する。

```sh
lake build +JonnyLean.NumberTheory.Divisibility
lake env lean -DwarningAsError=true JonnyLean/NumberTheory/Divisibility.lean
lake env lean -DwarningAsError=true contracts/JL008.lean
```

契約末尾の `#print axioms` が公開定理と名前付き契約の公理依存を出力する。
