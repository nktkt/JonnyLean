# JL-027: 像と逆像の随伴関係

## 対象・定義・仮定

`image f p y := ∃ x, p x ∧ f x = y`、`preimage f q x := q (f x)`。写像 `f` の単射性・全射性は不要。

像が目標述語に含まれることと、元の述語が逆像に含まれることの同値を示す。像の単調性、和集合保存、合成則を含む。

## 完全な契約命題

`contracts/JL027.lean` は実装モジュールを直接 import し、以下の完全な型に公開定理を当てはめる。型変数は任意の型であり、自然数や非空型への暗黙の制限はない。明示された場合だけ判定可能性・単射性・全域性・推移性を仮定する。

```lean
theorem JonnyLean.Contracts.JL027 {α : Type u} {β : Type v} (f : α → β) (p : α → Prop) (q : β → Prop) :
    (∀ y, (∃ x, p x ∧ f x = y) → q y) ↔ (∀ x, p x → q (f x))
```

公開定理: `JonnyLean.Predicate.image_preimage_adjunction`。実装: `JonnyLean/Logic/Images.lean`。

## 証明と範囲

順方向は各 x の自明な像の証人を使う。逆方向は像の存在証人を取り出し、等式に沿って結論を移す。像の合成則では中間点の存在証人を結合する。
