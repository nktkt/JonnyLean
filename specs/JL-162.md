# JL-162: 要素ごとに変わる選択肢と和の法則

## 対象と定義

fibers xs choices は左の出現 x ごとに異なるリスト choices x の要素を対にして列挙する。各fiberの大きさの和を自然数massで表す。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL162_semantics (xs : List α) (cs : α → List β) (x : α) (y : β) : (x, y) ∈ fibers xs cs ↔ x ∈ xs ∧ y ∈ cs x
```

## 証明する命題

列挙長がfiber長の和に一致することを証明する。所属の正確な特徴づけ、固定fiberと直積の一致、一般重み付き和のmap/flatMap公式も示す。

主要公開定理: `JonnyLean.Counting.length_fibers`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL162 (xs : List α) (cs : α → List β) : (fibers xs cs).length = mass (fun x => (cs x).length) xs
```

## 境界と範囲

fiberの大きさは均一でなくてよく、空のfiberも許す。重複は出現として保持する。

境界契約:

```lean
theorem contract_JL162_boundary (xs : List α) : fibers xs (fun _ => ([] : List Nat)) = []
```
