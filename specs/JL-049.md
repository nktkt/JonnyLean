# JL-049: 到達可能性と反射推移閉包の最小性

## 対象と定義

`Reachable G x y` を `Nonempty (Walk G x y)` と定義する。存在する歩道を選択してデータとして取り出す選択公理は使わず、命題の証明内で歩道を消去する。

長さ 0 の歩道を含むため全頂点は自分自身へ到達可能である。辺 1 本は到達可能性を与え、歩道の連結で到達可能性の推移性を示す。

## 証明する命題

任意の二項関係 `R` が反射的・推移的で、グラフのすべての辺を含むなら、到達可能な端点は `R` でも関係する。歩道の帰納法でこの最小性を証明する。また、到達可能性を「端点が等しい、または最初の辺と残りの歩道が存在する」と分解する。

主要公開定理: `JonnyLean.GraphTheory.reachable_minimal`。

契約は次の型を独立に記述し、公開定理から直接構成する。

```lean
theorem contract_JL049 {V : Type u} {G : Graph V} {x y : V}
    (R : V → V → Prop) (hr : ∀ x, R x x)
    (ht : ∀ x y z, R x y → R y z → R x z)
    (he : ∀ x y, G.edge x y → R x y) : Nonempty (Walk G x y) → R x y
```

## 境界と範囲

反射性に自己ループは不要。最小性の定理は、反射性・推移性・辺の包含という三つの仮定をすべて明示する。無限歩道については主張しない。
