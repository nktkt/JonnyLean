# JL-249: 区切り付き任意データ列の厳密な復号

## 対象と命題

各要素をsomeで包みnoneを終端とするブロックについて、復号成功と符号列＋未消費末尾という分解の同値を示す。

データ型に予約値や等号判定を要求しない。空ペイロードもnone一つで符号化され、終端がない列は失敗する。

```lean
theorem contract_JL249 (input : List (Option α)) (xs : List α) (rest : List (Option α)) : decodeBlock input = some (xs,rest) ↔ input = encodeBlock xs ++ rest :=
  decodeBlock_exact input xs rest
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.Encoding.decodeBlock_exact` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/Encoding/Blocks.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL249_definition (xs : List α) : encodeBlock xs = xs.map some ++ [none] := rfl
```

## 証明の構成

符号化後の復号をペイロード帰納法、成功からの入力復元を入力帰納法で別々に証明する。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL249_boundary : decodeBlock [some 1,some 2] = (none : Option (List Nat × List (Option Nat))) := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。
