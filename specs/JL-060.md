# JL-060: 有限計数分布の正規化と補事象

## 対象と定義

`Distribution α` は結果リスト、自然数重み、総質量が正である証明を持つ。`Probability` は分子・分母・分母正性・分子が分母以下である証明を持つ既約化しない分数の表現である。

事象の確率を、分子 `eventMass d.weight event d.outcomes`、分母 `mass d.weight d.outcomes` とする。これは有理数 n/d の明示的な表現であり、異なる分母の同値な分数を構造体の等式で同一視しない。

## 証明する命題

事象と補事象の分子の和が共通分母に等しいことを証明する。空事象の分子 0、全事象の分子と分母の一致、同じ分母での単調性・交わらない和の加法性を示す。非空リストの各位置へ重み 1 を付ける一様分布を作り、その分子が事象を満たす位置の個数、分母が全位置数であることを示す。

主要公開定理: `JonnyLean.DiscreteProbability.Distribution.probability_complement`。

契約は次の型を独立に記述し、公開定理から直接構成する。

```lean
theorem contract_JL060 {α : Type u} (d : Distribution α) (p : α → Bool) :
    (d.probability p).numerator + (d.probability (fun a => !p a)).numerator =
      mass d.weight d.outcomes
```

## 境界と範囲

空リストや総質量 0 から正規化分布を作ることはできない。`[false,true]` の一様分布で真の分子は 1、分母は 2。重複した値は出現回数に比例する重みを持つ。実数値確率、測度、分数同値類の一般演算は提供しない。
