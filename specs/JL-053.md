# JL-053: 閉歩道の反復と始点の移動

## 対象と定義

`ClosedWalk G x` は `Walk G x x` であり、単純サイクルではない。頂点・辺の反復および空歩道を許す。

`power p 0` は空歩道、`power p (n+1)` は `power p n` の後ろに `p` を連結する。繰り返す歩道は具体的な入力として与える。

## 証明する命題

反復回数 `n` に関する帰納法で、反復の長さが `n * p.length` になることを示す。反復回数の加法が歩道の連結に対応することも示す。往復する二つの区間 `p : x→y` と `q : y→x` の連結順を交換して閉歩道の始点を移しても長さは変わらない。

主要公開定理: `JonnyLean.GraphTheory.ClosedWalk.length_power`。

契約は次の型を独立に記述し、公開定理から直接構成する。

```lean
theorem contract_JL053 {V : Type u} {G : Graph V} {x : V} (p : Walk G x x) (n : Nat) :
    (ClosedWalk.power p n).length = n * p.length
```

## 境界と範囲

0 回反復も定義する。長さ 0 の閉歩道も許し、正の長さや頂点の非重複は結論に含めない。回転後の歩道と元の歩道が同じ型・同じ値であるとは主張しない。
