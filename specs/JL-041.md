# JL-041: 挿入ソートの順列保存

## 対象・定義・仮定

`orderedInsert r a` は先頭 b で r a b が真なら a を前へ置き、そうでなければ再帰する。`insertionSort` は末尾をソートして先頭を挿入する。順列保存だけには全域性や推移性を仮定しない。

任意の判定可能な比較関係を用いた挿入ソートは、入力列の順列を返す。従って要素と重複数、列の長さを保存する。

## 完全な契約命題

`contracts/JL041.lean` は実装モジュールを直接 import し、以下の完全な型に公開定理を当てはめる。型変数は任意の型であり、自然数や非空型への暗黙の制限はない。明示された場合だけ判定可能性・単射性・全域性・推移性を仮定する。

```lean
theorem JonnyLean.Contracts.JL041 {α : Type u} (r : α → α → Prop) [DecidableRel r] (xs : List α) :
    (JonnyLean.Algorithms.insertionSort r xs).Perm xs
```

公開定理: `JonnyLean.Algorithms.insertionSort_perm`。実装: `JonnyLean/Algorithms/InsertionSort.lean`。

## 証明と範囲

挿入した列が a::xs の順列になることを帰納的に示し、再帰的ソートの順列と合成する。並び順の正しさは別の JL-042 が扱う。
