# JL-168: 重み付き部分列和の積展開

## 対象と定義

語の重みwordWeightを文字の自然数重みの積とし、全位置部分列の重みを足す。空語の重みは空積として1とする。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL168_semantics (w : α → Nat) (xs : List α) : wordWeight w xs = natProduct (xs.map w)
```

## 証明する命題

全部分列の重みの和が各位置の (1 + w a) の積に等しいことを証明する。重み和の加法・定数倍、語重みの連結積公式も示す。

主要公開定理: `JonnyLean.Counting.weighted_subsequences`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL168 (w : α → Nat) (xs : List α) : mass (wordWeight w) (subsequences xs) = wordWeight (fun a => 1 + w a) xs
```

## 境界と範囲

自然数重み0を許す。重複値の位置も独立の因子を与える。実数や収束の問題は扱わない有限恒等式である。

境界契約:

```lean
theorem contract_JL168_boundary (w : Nat → Nat) : mass (wordWeight w) (subsequences []) = 1
```
