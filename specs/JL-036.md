# JL-036: 安定分割の保存性と分離

## 対象・定義・仮定

判定器 p は `α → Bool`。`partition` は受理列と拒否列の組を返す。元の順序は各側で保つが、両側の連結順は元の全体順序と一致するとは限らない。重複を許す。

一回の再帰的走査で得られる受理側・拒否側の列を連結すると元の列の順列になる。両側は相補的フィルタに一致し、長さの和が保存され、共通要素を持たない。

## 完全な契約命題

`contracts/JL036.lean` は実装モジュールを直接 import し、以下の完全な型に公開定理を当てはめる。型変数は任意の型であり、自然数や非空型への暗黙の制限はない。明示された場合だけ判定可能性・単射性・全域性・推移性を仮定する。

```lean
theorem JonnyLean.Contracts.JL036 {α : Type u} (p : α → Bool) (xs : List α) :
    ((JonnyLean.Collections.partition p xs).1 ++
      (JonnyLean.Collections.partition p xs).2).Perm xs
```

公開定理: `JonnyLean.Collections.partition_perm`。実装: `JonnyLean/Collections/Partition.lean`。

## 証明と範囲

列の帰納法。受理時には同じ先頭を追加し、拒否時には順列の中間移動で先頭要素を拒否列へ移す。フィルタとの等式が安定性を与える。
