# JL-001: 偶数どうしの和

## 対象と定義

対象は自然数 `Nat` とする。自然数には **0 を含む**。

この課題は偶数の定義と、偶数どうしの和の定理を対象とする。JL-002以降の定理にはそれぞれ独立した仕様と契約を用意する。

自然数 `n` が偶数であるとは、自然数 `k` が存在して `n = 2 * k` となることをいう。

```lean
def JonnyLean.Even (n : Nat) : Prop := ∃ k : Nat, n = 2 * k
```

## 証明する命題

すべての自然数 `a` と `b` について、`a` と `b` がともに偶数ならば、`a + b` も偶数である。

- 量化する変数: 任意の `a b : Nat`。
- 仮定: `∃ ka : Nat, a = 2 * ka` および `∃ kb : Nat, b = 2 * kb`。
- 結論: `∃ k : Nat, a + b = 2 * k`。
- 追加の仮定: なし。特に `a > 0` や `b > 0` は仮定しない。

完全な命題は次のとおり。

```lean
∀ (a b : Nat),
  (∃ ka : Nat, a = 2 * ka) →
  (∃ kb : Nat, b = 2 * kb) →
  ∃ k : Nat, a + b = 2 * k
```

公開する定理名と型:

```lean
JonnyLean.even_add (a b : Nat)
  (ha : JonnyLean.Even a) (hb : JonnyLean.Even b) :
  JonnyLean.Even (a + b)
```

## 証明の方針

仮定から証人 `ka` と `kb` を取り出す。結論の証人には自然数 `ka + kb` を選ぶ。

`a + b = 2 * ka + 2 * kb = 2 * (ka + kb)`

最初の等号には仮定の等式を、次の等号には分配法則 `Nat.mul_add` を逆向きに使う。存在を示す証人が具体的に得られる証明であり、場合分けによる有限個の検証だけに依存しない。

## 実装と検査

- 実装: `JonnyLean/NumberTheory/Parity.lean`。
- 契約: `contracts/JL001.lean`。
- Lean: `leanprover/lean4:v4.29.1`。Lean に同梱されたライブラリのみを使う。
- この最初の課題には Mathlib やその他の外部パッケージを必要としない。
- `sorry`、`admit`、新たな公理は導入しない。
- 契約は `JonnyLean.Even` を用いずに完全な存在命題を書き、`JonnyLean.even_add` をその型に直接代入する。必要な仮定を増やしたり、`Even` の定義を別の命題に変えたりする変更を検出する。
- 境界例として `0 + 0`、`0 + 4`、正の例として `2 + 4` を検査する。
- `#print axioms JonnyLean.even_add` で定理の公理依存を表示する。

実行コマンド:

```sh
lake build
lake env lean contracts/JL001.lean
```

これらは機械検査の手順であり、人間によるレビューや承認を意味しない。
