# JL-213: 行列累乗の指数加法則

## 対象と定義

自然数行列のk+l乗をk乗とl乗の積へ分解する。

`Vec n`は`Fin n → Nat`、`Mat m n`は`Fin m → Fin n → Nat`である。有限和`sum`は空次元で0、後続次元で先頭座標と残りの和を加える。`dot`は座標積の和、`mulMat`は共通次元の座標積の和である。
すべての行列・ベクトルは自然数値の関数であり、有限添字の次元は型に含まれる。

## 証明する命題

```lean
theorem matPow_add {n : Nat} (A : Fin n → Fin n → Nat) (k l : Nat) :
    matPow A (k+l) = mulMat (matPow A k) (matPow A l)
```

指数kへの帰納法を行い、基底で単位行列、帰納段階で行列積の結合則を使う。

## 量化・仮定・範囲

表示した次元・添字・係数・行列・ベクトルをすべて量化する。自然数次元には0を含み、正の次元を追加で仮定しない。`Fin n`型の添字を要求する命題では、n=0に対する添字は存在しない。
比較を含む定理では命題に明記した成分ごとの不等式だけを仮定する。係数は自然数であり、加法逆元、体、行列の一般的な可換性、実数内積空間についての主張ではない。

## 独立契約と境界検査

`contracts/JL213.lean`は入力を`Fin`から`Nat`への関数として明記した名前付き期待型`contract_JL213`を持ち、実装定理をその型へ代入する。主定理の型を推論させた別名にはしない。
表現の定義を次の独立した式で確認する。

```lean
matPow A (k+1) = mulMat A (matPow A k)
```

具体計算: `matPow (fun i j : Fin 2 => i.val+j.val+1) 2 1 1 = 13`。
境界計算: `matPow (fun _ _ : Fin 1 => 0) 0 0 0 = 1`。
同一モジュールの法則を共有する複数課題があるが、各課題の主定理と期待型は異なる。
