# JL-082: 係数列の長さが異なる多項式の加法

## 対象と定義

`add [] q=q`、`add p []=p`、両列が非空なら先頭係数を足して残りを再帰的に加える。

## 証明する命題

短い係数列の不足分を0と解釈する加法を実装し、評価の加法性、リストとしての交換則・結合則、長さの最大値を示す。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem evaluate_add (p q : Polynomial) (x : Nat) :
    evaluate (add p q) x = evaluate p x + evaluate q x
```

公開補題: `evaluate_add`、`add_comm`、`add_assoc`、`add_length`。

## 独立契約

`contracts/JL082.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL082` で独立に記述する。`contract_JL082_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

空列は加法の単位元。末尾0の正規化をしないため長さは厳密に元の二長さの最大値。

境界契約は `add [] [1,2] = [1,2]` と `add [1,2] [3] = [4,2]`。
