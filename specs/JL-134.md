# JL-134: 静的スタック深さ検査の健全性

## 対象と境界

命令だけから計算した深さ検査が成功すれば、同じ長さの任意の値スタック上の実行も成功し、出力長は検査値に一致する。値や環境に依存しない安全性証明。

命令は定数push・環境load・二項add・二項mul。スタック先頭が頂上で、演算時の上二要素 `b :: a` から `a op b` を作る。要素不足は `none`、空プログラムは初期スタックを返す。

## 完全な契約命題

```lean
∀ (env : Nat → Nat) (code : List Instr) (stack : List Nat) (depth : Nat), verifiedDepth code stack.length = some depth → ∃ result, execution env code stack = some result ∧ result.length = depth
```

公開定理は `JonnyLean.VerifiedPrograms.Machine.check_sound`。固定された名前付き契約は `JonnyLean.Contracts.JL134.contract`。

## 独立した意味モデル

以下は `JonnyLean/VerifiedPrograms/MachineSpecifications.lean` にある固定モデルである。実装対象の関数を呼ばずに再帰または一命令の状態遷移を定義する。各 `*_matches` 補題を構造帰納法で検査してから公開定理と接続する。

```lean
def abstractInstruction : Instr → Nat → Option Nat
  | .push _, n | .load _, n => some (n + 1)
  | .add, n + 2 | .mul, n + 2 => some (n + 1)
  | .add, _ | .mul, _ => none

def verifiedDepth : List Instr → Nat → Option Nat
  | [], n => some n
  | i :: code, n => (abstractInstruction i n).bind (verifiedDepth code)

def instruction (env : Nat → Nat) : Instr → List Nat → Option (List Nat)
  | .push n, s => some (n :: s)
  | .load x, s => some (env x :: s)
  | .add, b :: a :: s => some ((a + b) :: s)
  | .mul, b :: a :: s => some ((a * b) :: s)
  | .add, _ => none
  | .mul, _ => none

def execution (env : Nat → Nat) : List Instr → List Nat → Option (List Nat)
  | [], s => some s
  | i :: code, s => (instruction env i s).bind (execution env code)
```

## 証明の構成と再利用補題

構文または入力列の構造帰納法を基礎にし、任意の部分木・式・初期状態について帰納仮定を適用する。蓄積引数・後続列・環境は必要に応じて一般化している。独立モデルとの橋渡しは契約の検査に含まれ、主張を実装の型の別名だけで済ませない。

この課題に関連する再利用補題:

- `run_check_sound`。
- `check_append`。

同じ補題を複数の課題として重複計上しない。評価保存、固定点、サイズ制約、静的検査は異なる明示命題として区別する。

## 境界例

- `reject_underflow`: `verifiedDepth [.add] 1 = none`。
- `accept_operation`: `verifiedDepth [.mul] 2 = some 1`。

有限例は境界条件の固定に使う。一般命題の証明を例の列挙で代替しない。

## 実装・依存・検査

- 実装: `JonnyLean/VerifiedPrograms/StackMachine.lean`。
- 契約: `contracts/JL134.lean`。
- 独立モデル: `JonnyLean/VerifiedPrograms/MachineSpecifications.lean`（editable対象外）。
- 課題依存: JL-131。
- Lean: `leanprover/lean4:v4.29.1`、同梱 Init/Std のみ。
- `sorry`、`admit`、独自公理、`Classical.choice` を使わない。
- 全宣言の許容公理依存は `propext` と `Quot.sound` のみ。

```sh
lake build +JonnyLean.VerifiedPrograms.StackMachine +JonnyLean.VerifiedPrograms.MachineSpecifications
lake env lean -DwarningAsError=true JonnyLean/VerifiedPrograms/StackMachine.lean

```
