# JL-154: Boolean受理判定による補機械

## 対象と定義

補機械は遷移・初期状態を保ち、受理Booleanだけを否定する。全域的な遷移関数を前提とする。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL154_semantics (M : Machine α Q) (q : Q) : M.complement.accept q = Bool.not (M.accept q)
```

## 証明する命題

補機械の言語が元の語受理の否定と同値であることを示す。走行の保存、二重補の機械としての等式、いずれか一方の受理も証明する。

主要公開定理: `JonnyLean.Automata.Machine.language_complement`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL154 (M : Machine α Q) (w : List α) : M.complement.language w ↔ ¬M.language w
```

## 境界と範囲

一般の命題言語に排中律を仮定するのではなく、Boolean値の二場合に分けて補性を証明する。未定義遷移は存在しない。

境界契約:

```lean
theorem contract_JL154_boundary (M : Machine α Q) : M.complement.complement = M
```

## 検証

- 実装: `JonnyLean/Automata/Complement.lean`。
- 独立契約: `contracts/JL154.lean`。主定理・定義の意味・境界を名前付き命題で検査する。
- 同梱 Init/Std と既存 JonnyLean のみを利用し、Mathlib は使用しない。
- 全宣言について `sorry`、独自公理、`Classical.choice` を禁止する。許容する基礎公理は `propext` と `Quot.sound` のみ。
- 機械検証は独立レビューによる承認を意味しない。

```sh
lake build JonnyLean.Automata.Complement
lake env lean -DwarningAsError=true JonnyLean/Automata/Complement.lean
lake env lean -DwarningAsError=true contracts/JL154.lean
```
