# JL-007: 平方の偶数性と元の偶数性

## 対象と境界

自然数の平方が偶数であることと、その自然数自身が偶数であることの同値を示す。積と累乗の偶奇保存を再利用する。

n は 0 を含む任意の自然数。偶数の定義を変更せず、平方は自然数の積 n*n とする。

## 完全な契約命題

```lean
∀ n : Nat, (∃ k : Nat, n * n = 2 * k) ↔ (∃ k : Nat, n = 2 * k)
```

公開定理は `JonnyLean.even_square_iff`。契約名は `JonnyLean.Contracts.JL007.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 証明の構成

逆向きは偶数と任意の自然数の積の証人を構成する。順向きは偶奇分解を使い、奇数の平方が奇数となることと偶奇排他性から示す。

このモジュールに含まれる名前付き定理:

- `even_mul_right`
- `even_mul_left`
- `odd_mul_odd`
- `even_pow_succ`
- `odd_pow`
- `even_square_iff`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `zero_square`: `∃ k : Nat, 0 * 0 = 2 * k`。
- `odd_square`: `¬ (∃ k : Nat, 3 * 3 = 2 * k)`。
- `even_square`: `∃ k : Nat, 4 * 4 = 2 * k`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。
