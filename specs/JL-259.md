# JL-259: 二分木形状の燃料付き復号

## 対象と命題

葉をfalse、分岐をtrueと左右の符号列で表す前置形式を、高さより大きい燃料で復号すれば形状と末尾が復元される。

木は葉に値を持たない有限二分木の形状。燃料は再帰深さを制限し、0では葉も失敗する。各左右の再帰に同じ残り燃料を渡す。

```lean
theorem contract_JL259 (t : Shape) (fuel : Nat) (rest : List Bool) (h : height t < fuel) : decodeTree fuel (encodeTree t ++ rest) = some (t,rest) :=
  tree_roundtrip t fuel rest h
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.Encoding.tree_roundtrip` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/Encoding/Trees.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL259_definition (l r : Shape) : encodeTree (.branch l r) = true :: (encodeTree l ++ encodeTree r) := rfl
```

## 証明の構成

木への構造帰納法。max高さから左右への燃料条件を導き、左の復号後に右を復号する。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。
