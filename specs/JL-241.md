# JL-241: 固定回数反復と独立した解析連鎖

## 対象と命題

n回の逐次解析を行うrepeatPの成功が、n段の帰納的関係Chainと同値である。

途中の一回でも失敗すれば全体が失敗する。Chainは実装関数の等式ではなくnil/stepの独立した帰納的仕様。

```lean
theorem contract_JL241 (p : Parser α β) (n : Nat) (input rest : List α) (bs : List β) : repeatP p n input = some (bs,rest) ↔ Chain p n input bs rest :=
  repeat_iff p n input rest bs
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.Parsing.repeat_iff` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/Parsing/Repetition.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL241_definition (p : Parser α β) (input : List α) : repeatP p 0 input = some ([],input) := rfl
```

## 証明の構成

nへの帰納法で実装の二段のOption分岐とChain.stepの証拠を対応させる。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL241_boundary : repeatP (satisfy id) 2 [true,true,false] = some ([true,true],[false]) := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。

## 検証と範囲
