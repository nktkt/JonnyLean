# JL-172: 有限測度の押し出しと質量保存

## 対象と定義

押し出しpush fは各出現の値にfを適用し、同じ出現の重みを保持する。像が衝突しても出現の統合や再重み付けを行わない。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL172_semantics (f : α → β) (μ : Measure α) : push f μ = μ.map (fun p => (f p.1, p.2))
```

## 証明する命題

押し出しによる総質量保存を示す。恒等写像、写像合成、測度連結、Dirac測度との整合性も証明する。

主要公開定理: `JonnyLean.FiniteProbability.total_push`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL172 (f : α → β) (μ : Measure α) : total (push f μ) = total μ
```

## 境界と範囲

fは単射でなくてよい。値だけから重みを再計算しないことで、異なる元が同じ像へ移る場合にも質量が正しく保存される。

境界契約:

```lean
theorem contract_JL172_boundary : push (fun _ : Nat => true) [(1, 2), (2, 3)] = [(true, 2), (true, 3)]
```
