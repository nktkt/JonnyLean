# JL-228: 分割入力によるストリーミング照合

## 対象と命題

u++vを一括照合する結果と、uで残余式を計算してvを照合する結果がBoolean値そのものとして一致する。

入力分割位置は任意であり、前半・後半が空の場合も含む。構文サイズの上界や計算時間の線形性は主張しない。

```lean
theorem contract_JL228 [DecidableEq α] (r : Regex α) (u v : List α) : accepts r (u ++ v) = accepts (derivatives u r) v :=
  accepts_append r u v
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.RegularExpressions.accepts_append` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/RegularExpressions/Matcher.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL228_definition [DecidableEq α] (r : Regex α) (a : α) (w : List α) : derivatives (a::w) r = derivatives w (derivative a r) := rfl
```

## 証明の構成

微分反復のappend合成則を先に証明し、その等式をnullableの引数へ代入する。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL228_boundary : accepts (.seq (.atom true) (.atom false) : Regex Bool) [true] = false := by decide
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。
