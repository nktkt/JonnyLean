# JL-086: Horner構造による多項式合成

## 対象と定義

`compose [] q=[]`、`compose (a::p) q=add [a] (multiply q (compose p q))`。

## 証明する命題

外側の多項式をHorner形式で走査し、内側の多項式との積と定数加算から合成を構成する。評価と代入の一致、結合、恒等代入、定数代入を示す。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem evaluate_compose (p q : Polynomial) (x : Nat) :
    evaluate (compose p q) x = evaluate p (evaluate q x)
```

公開補題: `evaluate_compose`、`evaluate_compose_assoc`、`evaluate_compose_identity`、`evaluate_compose_constant`、`evaluate_compose_add`。

## 独立契約

`contracts/JL086.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL086` で独立に記述する。`contract_JL086_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

[0,1]は恒等代入を表す。内側が空列なら0への代入となる。等式の結論は評価上のもの。

境界契約は `evaluate (compose [] [1,1]) 5 = 0` と `evaluate (compose [1,0,1] [1,1]) 2 = 10`。
