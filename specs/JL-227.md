# JL-227: 実行可能な正規表現照合器の完全性と健全性

## 対象と命題

全入力の微分後にnullableを呼ぶBoolean照合器が、正規表現の独立した言語意味と必要十分に一致する。

これは入力全体の照合であり、部分文字列検索ではない。空語やKleene閉包も扱う。

```lean
theorem contract_JL227 [DecidableEq α] (r : Regex α) (w : List α) : accepts r w = true ↔ denotes r w :=
  accepts_correct r w
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.RegularExpressions.accepts_correct` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/RegularExpressions/Matcher.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL227_definition [DecidableEq α] (r : Regex α) (w : List α) : accepts r w = nullable (derivatives w r) := rfl
```

## 証明の構成

nullable_correctとderivatives_correctを空の残余語に適用し、u++[]=uを使う。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL227_boundary : accepts (.star (.alt (.atom true) (.atom false)) : Regex Bool) [true,false,true] = true := by decide
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。
