# JL-098: 形式微分の構成と線形性

## 対象と定義

`derivative []=[]`、`derivative (a::p)=add p (0::derivative p)`。解析的極限ではなく有限係数の形式操作。

## 証明する命題

D(a+Xp)=p+XDpという再帰式で自然数係数の形式微分を構成し、加法とスカラー倍への線形性、定数と一次式の微分を証明する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem evaluate_derivative_add (p q : Polynomial) (x : Nat) :
    evaluate (derivative (add p q)) x =
      evaluate (derivative p) x + evaluate (derivative q) x
```

公開補題: `evaluate_derivative_cons`、`evaluate_derivative_add`、`evaluate_derivative_scale`、`evaluate_derivative_constant`、`evaluate_derivative_affine`。

## 独立契約

`contracts/JL098.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL098` で独立に記述する。`contract_JL098_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

定数多項式の微分は評価0だが、結果の係数列が空になるとは限らない。実数微分可能性は扱わない。

境界契約は `evaluate (derivative [7]) 5 = 0` と `evaluate (derivative [3,2,1]) 4 = 10`。
