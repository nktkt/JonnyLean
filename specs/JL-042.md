# JL-042: 挿入ソートの整列性と冪等性

## 対象・定義・仮定

`List.Pairwise r` は列の左にある任意の要素と右にある任意の要素について r が成り立つこと。比較関係には `∀ a b, r a b ∨ r b a` と推移性を仮定する。反対称性は不要で重複を許す。

全域的・推移的な判定可能関係に対する挿入ソートは Pairwise 整列列を返す。整列済み入力を変えず、二度ソートしても結果は変わらない。

## 完全な契約命題

`contracts/JL042.lean` は実装モジュールを直接 import し、以下の完全な型に公開定理を当てはめる。型変数は任意の型であり、自然数や非空型への暗黙の制限はない。明示された場合だけ判定可能性・単射性・全域性・推移性を仮定する。

```lean
theorem JonnyLean.Contracts.JL042 {α : Type u} (r : α → α → Prop) [DecidableRel r]
    (total : ∀ a b, r a b ∨ r b a)
    (trans : ∀ a b c, r a b → r b c → r a c) (xs : List α) :
    (JonnyLean.Algorithms.insertionSort r xs).Pairwise r
```

公開定理: `JonnyLean.Algorithms.insertionSort_sorted`。実装: `JonnyLean/Algorithms/SortCorrectness.lean`。

## 証明と範囲

整列列への挿入を帰納的に証明する。先頭へ挿入する場合は推移性、後ろへ進む場合は全域性で逆向きの比較を得る。これをソートの帰納法に適用する。

一般の入力に対する証明であり、具体例のみの有限検査ではない。補助定理は同じモジュールにあり、契約の追加例では境界ケースや関連した性質も検査する。仕様にない性能計算量・停止時間・外部環境での実行結果は主張しない。
