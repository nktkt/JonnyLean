# JL-126: 定数畳込みによる構文サイズの非増加

## 対象と境界

葉と演算節点を各一つと数える構文サイズについて、定数畳込みがサイズを増やさないことを証明する。開いた式で等号になる場合と、閉じた部分式で減少する場合を含む。

式は自然数定数、自然数で表す変数名、二項加算・乗算からなる。環境は任意の `Nat → Nat`。変数出現列は順序と重複を保ち、束縛構文は持たない。

## 完全な契約命題

```lean
∀ e : Expr, syntaxSize (folded e) ≤ syntaxSize e
```

公開定理は `JonnyLean.VerifiedPrograms.Expr.foldConstants_size`。固定された名前付き契約は `JonnyLean.Contracts.JL126.contract`。

## 独立した意味モデル

以下は `JonnyLean/VerifiedPrograms/ExpressionSpecifications.lean` にある固定モデルである。実装対象の関数を呼ばずに再帰または一命令の状態遷移を定義する。各 `*_matches` 補題を構造帰納法で検査してから公開定理と接続する。

```lean
def syntaxSize : Expr → Nat
  | .lit _ | .var _ => 1
  | .add a b | .mul a b => 1 + syntaxSize a + syntaxSize b

def folded : Expr → Expr
  | .lit n => .lit n
  | .var x => .var x
  | .add a b =>
    match folded a, folded b with
    | .lit n, .lit m => .lit (n + m)
    | a', b' => .add a' b'
  | .mul a b =>
    match folded a, folded b with
    | .lit n, .lit m => .lit (n * m)
    | a', b' => .mul a' b'
```

## 証明の構成と再利用補題

構文または入力列の構造帰納法を基礎にし、任意の部分木・式・初期状態について帰納仮定を適用する。蓄積引数・後続列・環境は必要に応じて一般化している。独立モデルとの橋渡しは契約の検査に含まれ、主張を実装の型の別名だけで済ませない。

この課題に関連する再利用補題:

- `constantAdd_size`。
- `constantMul_size`。

同じ補題を複数の課題として重複計上しない。評価保存、固定点、サイズ制約、静的検査は異なる明示命題として区別する。

## 境界例

- `open_size`: `syntaxSize (folded (.add (.var 0) (.lit 1))) = 3`。
- `strict_reduction`: `syntaxSize (folded (.add (.lit 1) (.lit 2))) < syntaxSize (.add (.lit 1) (.lit 2))`。

有限例は境界条件の固定に使う。一般命題の証明を例の列挙で代替しない。
