# JL-143: 存在証人による言語連結と分配

## 対象と定義

連結 `concat L K w` は、語 w を u ++ v に分割し L u と K v の証拠を持つことと定義する。分割は空語も許す。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL143_semantics (L K : Language α) (w : List α) : concat L K w ↔ ∃ u v, L u ∧ K v ∧ u ++ v = w
```

## 証明する命題

右側の言語和に対する連結の分配則を証明する。連結の導入、両変数の単調性、空言語の左右零元も示す。

主要公開定理: `JonnyLean.Languages.concat_union`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL143 (L K M : Language α) : concat L (union K M) = union (concat L K) (concat L M)
```

## 境界と範囲

語の分割や所属の探索アルゴリズムは仮定しない。存在命題の中で証人を組み替える。

境界契約:

```lean
theorem contract_JL143_boundary : ¬concat (epsilon : Language Nat) empty []
```

## 検証
