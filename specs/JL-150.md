# JL-150: 文字写像による言語像とKleene閉包

## 対象と定義

文字写像 f を List.map により語へ延長し、像言語を元の語の存在で定義する。写像は単射・全射でなくてもよい。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL150_semantics (f : α → β) (L : Language α) (w : List β) : image f L w ↔ ∃ u, L u ∧ u.map f = w
```

## 証明する命題

像操作とKleene閉包の可換性を、双方の帰納的生成を輸送して証明する。連結との可換性、恒等写像・写像合成との整合性も示す。

主要公開定理: `JonnyLean.Languages.image_star`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL150 (f : α → β) (L : Language α) : image f (Star L) = Star (image f L)
```

## 境界と範囲

各文字を一文字へ写す写像であり、文字を任意の語へ写す一般の消去可能準同型は対象外である。

境界契約:

```lean
theorem contract_JL150_boundary : image (fun _ : Nat => true) (fun w => w = [1, 2]) [true, true]
```

## 検証

- 実装: `JonnyLean/Languages/Image.lean`。
- 独立契約: `contracts/JL150.lean`。主定理・定義の意味・境界を名前付き命題で検査する。
- 同梱 Init/Std と既存 JonnyLean のみを利用し、Mathlib は使用しない。
- 全宣言について `sorry`、独自公理、`Classical.choice` を禁止する。許容する基礎公理は `propext` と `Quot.sound` のみ。
- 機械検証は独立レビューによる承認を意味しない。

```sh
lake build JonnyLean.Languages.Image
lake env lean -DwarningAsError=true JonnyLean/Languages/Image.lean
lake env lean -DwarningAsError=true contracts/JL150.lean
```
