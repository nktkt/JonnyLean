# JL-089: 係数剰余化と合同入力による多項式評価の正規化

## 対象と定義

`Polynomial` は低次から並べた自然数係数の有限リスト。評価は `evaluate [] x = 0`、`evaluate (a::p) x = a + x * evaluate p x` である。

係数の正規化は `p.map (fun a => a % m)` によって全係数を同じ法 m の剰余へ置き換える。入力の合同は `x % m = y % m` という剰余等式で表す。係数列の長さや末尾の0は変更しない。

## 証明する命題

すべての自然数法 m、有限係数列 p、合同な自然数入力 x,y について、係数を剰余化して x で評価した結果と、元の係数を y で評価した結果は m を法として等しい。係数の変換と入力の置換を同時に許す評価正規化を主題とする。

```lean
theorem evaluate_normalized_congruent (m : Nat) (p : Polynomial) (x y : Nat)
    (h : x % m = y % m) :
    evaluate (p.map (fun a => a % m)) x % m = evaluate p y % m
```

証明は、任意長の係数列について帰納的に示した係数剰余化の保存 `evaluate_coefficients_mod` と、合同入力による評価保存 `evaluate_congruent` を推移的に合成する。係数が m 未満であることや入力が同じであることを仮定しない。

法付きHorner評価器 `evaluateMod` とその正しさ・範囲・入力正規化の補題も保持する。`evaluateMod m [] x=0`、`evaluateMod m (a::p) x=(a+x*evaluateMod m p x)%m` であり、計算中の値を法に応じて抑える実装である。

公開補題: `evaluateMod_correct`、`evaluate_congruent`、`evaluate_coefficients_mod`、`evaluate_normalized_congruent`、`evaluateMod_bound`、`evaluateMod_input`。

## 独立契約

`contracts/JL089.lean` はモジュールを直接 import し、係数列を `List Nat` と明記した名前付き命題 `contract_JL089` で、係数の `map`、入力合同の仮定、両評価の剰余等式を独立に記述する。

`contract_JL089_definition` は剰余化した係数列の先頭をHorner評価する計算式を展開し、`contract_JL089_horner_definition` は既存の法付き評価器の再帰式も保持する。

## 境界と範囲

法0では各係数はそのまま残り、入力合同の仮定は x=y になる。法1ではすべての評価の剰余が0になる。空係数列については入力合同なしでも両辺が0になることを契約で検査する。

具体的な境界契約には、法0で `[3,2,1]` を10で評価すると123になることと、法7で `[10,9,8]` を剰余化した `[3,2,1]` の入力10での評価が、元係数列の入力3での評価と合同になることを含める。10と3は異なるが法7で合同であり、係数も実際に変更される。

係数・入力はいずれも自然数に限る。法が正であることは主定理に不要だが、結果が法未満という範囲補題には必要である。
