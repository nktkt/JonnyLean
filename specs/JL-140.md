# JL-140: 任意バイトコードの構文再構成証明書

## 対象と境界

構文スタック上の逆コンパイルが成功すれば、その入力式を任意の環境で評価した数値スタック上でも実行が成功し、再構成した式を評価した結果に一致する。コンパイラ由来でない命令列も扱う。

命令は定数push・環境load・二項add・二項mul。スタック先頭が頂上で、演算時の上二要素 `b :: a` から `a op b` を作る。要素不足は `none`、空プログラムは初期スタックを返す。

## 完全な契約命題

```lean
∀ (env : Nat → Nat) (code : List Instr) (stack result : List Expr), reconstruction code stack = some result → execution env code (stack.map (meaning env)) = some (result.map (meaning env))
```

公開定理は `JonnyLean.VerifiedPrograms.Machine.decompile_sound`。固定された名前付き契約は `JonnyLean.Contracts.JL140.contract`。

## 独立した意味モデル

以下は `JonnyLean/VerifiedPrograms/MachineSpecifications.lean` にある固定モデルである。実装対象の関数を呼ばずに再帰または一命令の状態遷移を定義する。各 `*_matches` 補題を構造帰納法で検査してから公開定理と接続する。

```lean
def syntaxInstruction : Instr → List Expr → Option (List Expr)
  | .push n, s => some (.lit n :: s)
  | .load x, s => some (.var x :: s)
  | .add, b :: a :: s => some (.add a b :: s)
  | .mul, b :: a :: s => some (.mul a b :: s)
  | .add, _ => none
  | .mul, _ => none

def reconstruction : List Instr → List Expr → Option (List Expr)
  | [], s => some s
  | i :: code, s => (syntaxInstruction i s).bind (reconstruction code)

def instruction (env : Nat → Nat) : Instr → List Nat → Option (List Nat)
  | .push n, s => some (n :: s)
  | .load x, s => some (env x :: s)
  | .add, b :: a :: s => some ((a + b) :: s)
  | .mul, b :: a :: s => some ((a * b) :: s)
  | .add, _ => none
  | .mul, _ => none

def execution (env : Nat → Nat) : List Instr → List Nat → Option (List Nat)
  | [], s => some s
  | i :: code, s => (instruction env i s).bind (execution env code)

def meaning (env : Nat → Nat) : Expr → Nat
  | .lit n => n
  | .var x => env x
  | .add a b => meaning env a + meaning env b
  | .mul a b => meaning env a * meaning env b
```

## 証明の構成と再利用補題

構文または入力列の構造帰納法を基礎にし、任意の部分木・式・初期状態について帰納仮定を適用する。蓄積引数・後続列・環境は必要に応じて一般化している。独立モデルとの橋渡しは契約の検査に含まれ、主張を実装の型の別名だけで済ませない。

この課題に関連する再利用補題:

- `run_map`。

同じ補題を複数の課題として重複計上しない。評価保存、固定点、サイズ制約、静的検査は異なる明示命題として区別する。

## 境界例

- `raw_instruction`: `reconstruction [.add] [.var 1, .lit 2] = some [.add (.lit 2) (.var 1)]`。
- `raw_underflow`: `reconstruction [.mul] [.lit 2] = none`。

有限例は境界条件の固定に使う。一般命題の証明を例の列挙で代替しない。
