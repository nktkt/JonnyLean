# JL-091: 多項式列の有限和と評価

## 対象と定義

`sumPolynomials []=[]`、非空列では先頭多項式と残りの和を `add` で足す。数値和は JL-074 の `weightedSum`。

## 証明する命題

多項式列の有限和を係数加法で構成し、評価が各多項式評価の有限和になることを示す。連結、スカラー倍、共通約数を保存する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem evaluate_sumPolynomials (ps : List Polynomial) (x : Nat) :
    evaluate (sumPolynomials ps) x = Arithmetic.weightedSum (fun p => evaluate p x) ps
```

公開補題: `evaluate_sumPolynomials`、`sumPolynomials_append`、`sumPolynomials_scale`、`evaluate_sumPolynomials_dvd`。

## 独立契約

`contracts/JL091.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL091` で独立に記述する。`contract_JL091_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

空和は空係数列。多項式の長さが異なる場合も0埋め加法により定義される。

境界契約は `sumPolynomials [] = []` と `evaluate (sumPolynomials [[1,2],[3],[0,1]]) 4 = 16`。
