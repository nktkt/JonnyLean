# JL-174: 積測度と分離観測量の期待値

## 対象と定義

積測度は全ての出現対を列挙し、その重みを元の二つの重みの積とする。対の観測量 f(a)g(b) を扱う。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL174_semantics (μ : Measure α) (ν : Measure β) : product μ ν = μ.flatMap (fun p => ν.map (fun q => ((p.1, q.1), p.2 * q.2)))
```

## 証明する命題

積測度上の分離観測量の期待値分子が各期待値分子の積に等しいと証明する。総質量の積公式と各射影観測量の公式も導く。

主要公開定理: `JonnyLean.FiniteProbability.expect_product`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL174 (μ : Measure α) (ν : Measure β) (f : α → Nat) (g : β → Nat) : expect (product μ ν) (fun p => f p.1 * g p.2) = expect μ f * expect ν g
```

## 境界と範囲

一方の成分だけの観測量では他方の総質量が掛かる。未正規化なので総質量1を暗黙に仮定しない。

境界契約:

```lean
theorem contract_JL174_boundary (ν : Measure β) : total (product ([] : Measure Nat) ν) = 0
```
