# JL-064: 有限燃料付きEuclid法の停止と正しさ

## 対象と定義

`euclidStep (a,b)` は `a=0` のとき不変、それ以外は `(b%a,a)`。`euclidRun n` はこのステップを n 回適用する。

## 証明する命題

剰余によるEuclidステップを実装し、第一成分aに対してa+1回以内に停止状態(0,gcd(a,b))へ到達することを示す。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem euclidRun_computes (a b : Nat) :
    euclidRun (a+1) (a,b) = (0, Nat.gcd a b)
```

公開補題: `euclidStep_gcd`、`euclidRun_gcd`、`euclidRun_result`、`euclidRun_zero`、`euclidStep_decreases`、`euclidRun_terminates`、`euclidRun_computes`。

## 独立契約

`contracts/JL064.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL064` で独立に記述する。`contract_JL064_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

第一成分0は固定点。燃料0は入力を返す。停止証明はa+1という一様な上界を与えるが、計算量の最良上界は主張しない。

境界契約は `euclidRun 1 (0,0) = (0,0)` と `euclidRun 5 (48,18) = (0,6)`。
