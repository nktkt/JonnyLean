# JL-013: 累乗列の整除と順序

## 対象と境界

同じ底の自然数累乗について、小さい指数の累乗が大きい指数の累乗を割り切る。整除を累乗へ持ち上げる補助定理も含む。

a,m,n は自然数で m≤n。主定理は底 a=0 を許し、0^0=1 という Lean の規約を使用する。指数方向の単調性の補助定理では a>0 を仮定する。

## 完全な契約命題

```lean
∀ a m n : Nat, m ≤ n → ∃ k : Nat, a ^ n = a ^ m * k
```

公開定理は `JonnyLean.power_divides_later`。契約名は `JonnyLean.Contracts.JL013.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 証明の構成

n=m+k となる差の証人を取り出し、累乗の加法公式から乗数 a^k を構成する。

このモジュールに含まれる名前付き定理:

- `power_divides_later`
- `divides_power`
- `base_divides_positive_power`
- `power_even_exponent`
- `power_monotone_exponent`
- `power_successor_lower_bound`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `zero_exponent`: `∃ k : Nat, 0 ^ 0 = 0 ^ 0 * k`。
- `zero_base`: `∃ k : Nat, 0 ^ 3 = 0 ^ 1 * k`。
- `power_example`: `∃ k : Nat, 3 ^ 5 = 3 ^ 2 * k`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。

## 実装・依存・検査

- 実装: `JonnyLean/NumberTheory/Powers.lean`。
- 契約: `contracts/JL013.lean`。
- 課題依存: JL-008。
- Lean: `leanprover/lean4:v4.29.1`、同梱 Init/Std のみ。
- `sorry`、`admit`、新規公理、`Classical.choice` は使用しない。
- 許容公理はプロジェクト方針の `propext` と `Quot.sound` のみ。
- 機械検査と独立レビューは区別する。レビューの正式な状態は `reviews/JL-013.json` に記録する。

```sh
lake build +JonnyLean.NumberTheory.Powers
lake env lean -DwarningAsError=true JonnyLean/NumberTheory/Powers.lean
lake env lean -DwarningAsError=true contracts/JL013.lean
```

契約末尾の `#print axioms` が公開定理と名前付き契約の公理依存を出力する。
