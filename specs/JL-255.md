# JL-255: 値型の変換に沿った符号器の輸送

## 対象と命題

符号化前にgで元の値型へ戻し、復号後にfを適用することで、f∘g=idの値について往復を保つ。

主定理の往復には右逆fgのみを使う。成功入力の厳密な復元と完全Codecの構成には別途左逆gfも要求する。

```lean
theorem contract_JL255 (c : Codec α β) (f : β → γ) (g : γ → β) (fg : ∀ value, f (g value) = value) (value : γ) (rest : List α) : transportDecode c f (transportEncode c g value ++ rest) = some (value,rest) :=
  transport_roundtrip c f g fg value rest
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.Encoding.transport_roundtrip` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/Encoding/Combinators.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL255_definition (c : Codec α β) (g : γ → β) (value : γ) : transportEncode c g value = c.encode (g value) := rfl
```

## 証明の構成

基底Codecのroundtrip後の値f(g(value))を明記した仮定でvalueへ戻す。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL255_boundary : transportDecode unaryCodec id (transportEncode unaryCodec id 2 ++ [false]) = some (2,[false]) := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。

## 検証と範囲

- 日本語仕様、主定理、定義契約、境界契約を別の担当が照合する。
