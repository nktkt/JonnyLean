# JL-052: 相互到達可能性による強連結成分

## 対象と定義

`SameComponent G x y` は `Reachable G x y ∧ Reachable G y x` と定義する。任意の有向グラフを対象とする。

成分は相互到達可能性という同値関係として扱い、この課題では商集合や代表元の選択を作らない。無向グラフでは一方向の到達可能性と同値になる。

## 証明する命題

相互到達可能性の反射性・対称性・推移性から `Equivalence` を構成する。同じ成分に属する二頂点は、同じ頂点へ到達でき、成分への所属条件も一致する。準同型が同じ成分への所属を保存することも示す。

主要公開定理: `JonnyLean.GraphTheory.component_equivalence`。

契約は次の型を独立に記述し、公開定理から直接構成する。

```lean
theorem contract_JL052 {V : Type u} (G : Graph V) :
    Equivalence (fun x y => Nonempty (Walk G x y) ∧ Nonempty (Walk G y x))
```

## 境界と範囲

孤立点も自分自身と同じ成分に属する。無向性なしに一方向の到達可能性と同値とはしない。成分の個数や成分列挙は扱わない。
