# JL-035: 到達関係による不変条件の保存

## 対象・定義・仮定

有限到達関係は JL-032 の `Reach`。不変条件 p は任意の述語。初期点で p が成立し、各辺が p を保つことを仮定する。

各遷移が保存する述語は有限回の遷移でも保存される。写像による経路輸送、複数辺によるシミュレーション、経路反転、到達不能性も示す。

```lean
theorem JonnyLean.Contracts.JL035 {α : Type u} (r : α → α → Prop) (p : α → Prop)
    (step : ∀ a b, p a → r a b → p b) (a b : α)
    (path : JonnyLean.Relations.Reach r a b) (ha : p a) : p b
```

## 証明と範囲

経路の帰納法で初期の証拠を一辺ずつ運ぶ。シミュレーションでは一辺に対応する有限経路を連結し、反転では経路の連結順を逆にする。
