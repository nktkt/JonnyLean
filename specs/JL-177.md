# JL-177: 正の有限測度の確率表示と押し出し

## 対象と定義

Distributionは出現測度と総質量が正である証明を持つ。確率は事象質量を分子、総質量を分母とする既存の未約分Probability構造体で表す。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL177_semantics (d : Distribution α) (p : α → Bool) : (d.probability p).denominator = total d.measure
```

## 証明する命題

分布の押し出しを正性保存から構成し、事象確率分子が逆像事象の分子に等しいことを示す。分母保存、補確率分子の和、測度の非空性も示す。

主要公開定理: `JonnyLean.FiniteProbability.Distribution.probability_map`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL177 (d : Distribution α) (f : α → β) (p : β → Bool) : ((d.map f).probability p).numerator = (d.probability (fun a => p (f a))).numerator
```

## 境界と範囲

異なる分数表現の構造体等式を有理数等式と同一視しない。0分母は構造体の正性条件により排除される。

境界契約:

```lean
theorem contract_JL177_boundary (d : Distribution α) : d.measure ≠ []
```
