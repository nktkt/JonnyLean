# JL-011: 合同類の標準剰余の一意性

## 対象と境界

m 未満の剰余候補 r が a と合同なら、r は a%m に一致する。合同を剰余の等式として定義し、法 0 の場合も明示する。

a,m,r は自然数。主定理には r<m が必要で、これにより m>0 が従う。合同関係そのものは m=0 でも定義し、その場合は通常の等式となる。

## 完全な契約命題

```lean
∀ m a r : Nat, r < m → a % m = r % m → r = a % m
```

公開定理は `JonnyLean.congruent_unique_remainder`。契約名は `JonnyLean.Contracts.JL011.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 証明の構成

r<m なら r%m=r。合同の等式の右辺を書き換えて対称性を適用する。法の倍数を加えた値の合同も別に証明する。

このモジュールに含まれる名前付き定理:

- `congruent_refl`
- `congruent_symm`
- `congruent_trans`
- `congruent_remainder`
- `congruent_zero_modulus`
- `congruent_add_multiple`
- `congruent_small_iff`
- `congruent_unique_remainder`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `zero_value`: `(0 : Nat) = 0 % 5`。
- `remainder_two`: `(2 : Nat) = 17 % 5`。
- `modulus_zero`: `∀ a b : Nat, a % 0 = b % 0 ↔ a = b`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。

## 実装・依存・検査

- 実装: `JonnyLean/NumberTheory/Congruence.lean`。
- 契約: `contracts/JL011.lean`。
- 課題依存: なし（Lean 同梱 Init/Std のみ）。
- Lean: `leanprover/lean4:v4.29.1`、同梱 Init/Std のみ。
- `sorry`、`admit`、新規公理、`Classical.choice` は使用しない。
- 許容公理はプロジェクト方針の `propext` と `Quot.sound` のみ。
