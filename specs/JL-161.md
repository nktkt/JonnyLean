# JL-161: 出現を数える直積列挙

## 対象と定義

二つのリストの直積を、左の各出現に対して右の全出現を対にするflatMap/mapで列挙する。リスト長を個数とする。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL161_semantics (x : α) (xs : List α) (ys : List β) : product (x :: xs) ys = ys.map (fun y => (x, y)) ++ product xs ys
```

## 証明する命題

直積の列挙長が両リスト長の積であることを証明する。対の所属条件、左入力の連結への分配、空・先頭要素の再帰式も示す。

主要公開定理: `JonnyLean.Counting.length_product`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL161 (xs : List α) (ys : List β) : (product xs ys).length = xs.length * ys.length
```

## 境界と範囲

同値な値の重複は別の出現として数える。DecidableEqや重複除去は不要であり、集合の濃度とは区別する。

境界契約:

```lean
theorem contract_JL161_boundary : (product [1, 1] [true, false]).length = 4
```
