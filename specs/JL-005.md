# JL-005: 冪集合の濃度

## 対象と数学的意味

JL-004 の重複なし列挙 `JonnyLean.FiniteSet α` を用い、任意の型 `α : Type u` 上の任意の有限集合 `A` を対象とする。空集合を含む。冪集合は `A` のすべての部分集合からなる集合であり、空集合と `A` 自身も含む。

各部分集合は `A.elems` の順序を保つ部分列として一度だけ列挙する。同じ部分集合の並べ替えを別の要素として数えることはしない。`A` 自体の列挙順序を変えることはできるが、濃度は JL-004 の `card_eq_of_equivalent` で不変である。

まず `subsequences` を次のように定義する。

```lean
subsequences [] = [[]]
subsequences (a :: xs) =
  subsequences xs ++ (subsequences xs).map (List.cons a)
```

`a` を含めない場合と含める場合を分ける再帰である。`mem_subsequences` は列挙への membership が `List.Sublist` と同値であることを証明する。元の列挙に重複がなければ、各部分列も重複なしであり、部分列の列挙自体も重複がない。

各部分列に重複なし証明を付け、次の型の冪集合を構成する。

```lean
JonnyLean.FiniteSet.powerset (A : FiniteSet α) :
  FiniteSet (FiniteSet α)
```

`powerset` の構成と主定理には `DecidableEq α` を要求しない。任意の順序で与えられた部分集合から対応する代表を計算する完全性の定理のみ、フィルターのために `DecidableEq α` を要求する。

## 主定理

```lean
JonnyLean.FiniteSet.card_powerset (A : FiniteSet α) :
  card (powerset A) = 2 ^ card A
```

任意の有限集合に対し、その冪集合の濃度は `2` の元の濃度乗に等しい。非空性などの追加仮定はない。空集合のときは `2 ^ 0 = 1` であり、唯一の要素は空集合である。

主定理は、上の再帰で列挙数が各段階で二倍になることを帰納法で示して証明する。列挙数の等式だけで冪集合と呼ぶのではなく、次の意味と一意性もすべて証明する。

```lean
mem_powerset (A B : FiniteSet α) :
  B ∈ powerset A ↔ B.elems.Sublist A.elems

powerset_sound (A B : FiniteSet α) (h : B ∈ powerset A) :
  Subset B A

powerset_complete [DecidableEq α] (A B : FiniteSet α)
  (h : Subset B A) :
  ∃ C, C ∈ powerset A ∧ Equivalent B C

powerset_unique (A B C : FiniteSet α)
  (hb : B ∈ powerset A) (hc : C ∈ powerset A)
  (he : Equivalent B C) : B = C
```

これらの名前はすべて `JonnyLean.FiniteSet` 名前空間に属する。`Subset` は要素の包含、`Equivalent` は全要素の membership の同値であり、リストの順序の一致を仮定しない。

完全性では `A.elems` を `B` の membership でフィルターすることにより、`B` と同じ要素を持つ正規の代表 `C` を得る。一意性では、重複のない同じ元リストの二つの部分列が同じ membership を持つなら、リスト自体が等しいことを帰納法で証明する。このため、異なる順序の同じ数学的部分集合が二重に数えられる余地はない。

## 独立契約と境界例

- 実装: `JonnyLean/FiniteSet/Powerset.lean`。集合の基本表現は `Basic.lean` に依存する。
- 契約: `contracts/JL005.lean`。
- `JL005Contract.target` は `card` を使わず、冪集合と元集合の実際の列挙の長さで主定理を記述する。
- `canonicalMembership` は部分列との一致、`soundness` は要素包含、`completeness` は全ての部分集合の代表の存在、`uniqueRepresentation` は同じ membership の代表の一意性を要求する。契約では `Subset` や `Equivalent` の別名を使わず、完全な要素条件を展開する。
- `enumerationNodup` は冪集合の列挙に重複がないことを検査する。
- 空集合の濃度 `1` と空集合自体の membership、一要素集合の濃度 `2`、二要素集合の濃度 `4` を検査する。
- `[0, 1]` の冪集合を要素列挙へ戻すと `[[], [1], [0], [0, 1]]` になることを検査する。また `[1, 0]` という別順序の部分集合にも同じ membership の代表が存在することを完全性から検査する。

Lean `4.29.1` の同梱ライブラリのみを使う。Mathlib、`sorry`、`admit`、新たな公理は導入しない。主定理と名前付き契約の実際の公理依存は標準補題に由来する `propext` と `Quot.sound` のみであり、プロジェクトの許可方針に明示する。`Classical.choice` と `sorryAx` には依存しない。

```sh
lake build
lake env lean -DwarningAsError=true contracts/JL005.lean
```

機械検査の成功と人間によるレビュー・承認は別の記録とする。
