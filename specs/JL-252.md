# JL-252: 自然数復号による厳密な消費量

## 対象と命題

単進復号がnを返す場合、入力長はn+1+残余長であり、残余は必ず元入力より短い。

0でも終端一文字を消費する。成功条件なしに空入力へ長さ不等式を主張しない。

```lean
theorem contract_JL252 {input rest : List Bool} {n : Nat} (h : readUnary input = some (n,rest)) : input.length = n + 1 + rest.length ∧ rest.length < input.length :=
  readUnary_consumption h
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.Encoding.readUnary_consumption` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/Encoding/Unary.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL252_definition : unary 0 = [false] := rfl
```

## 証明の構成

厳密な復号仕様で入力を復元し、複製リストと終端の長さ公式を使う。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL252_boundary : readUnary [false,true] = some (0,[true]) := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。
