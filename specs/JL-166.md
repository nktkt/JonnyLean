# JL-166: 全位置への一文字挿入

## 対象と定義

insertions a xs は先頭から末尾まで全ての境界へ文字aを挿入した語を列挙する。先頭挿入と、先頭文字を保持した残りへの挿入を再帰的にまとめる。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL166_semantics (a b : α) (xs : List α) : insertions a (b :: xs) = (a :: b :: xs) :: (insertions a xs).map (fun ys => b :: ys)
```

## 証明する命題

全ての列挙結果の語長が元より一つ大きいと証明する。挿入候補の個数がlength xs+1、挿入文字の所属、先頭挿入の所属も示す。

主要公開定理: `JonnyLean.Counting.insertion_length`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL166 (a : α) {xs ys : List α} (h : ys ∈ insertions a xs) : ys.length = xs.length + 1
```

## 境界と範囲

挿入文字と既存文字が等しくても各位置を別に数える。空語への挿入は一文字語一個を返す。

境界契約:

```lean
theorem contract_JL166_boundary : insertions 1 [1] = [[1, 1], [1, 1]]
```
