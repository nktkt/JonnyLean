# JL-164: 全位置部分列の列挙と二の冪

## 対象と定義

各位置を残すか捨てるかで全ての順序保存部分列を列挙する。先頭位置を捨てる列挙と残す列挙を連結する再帰定義を使う。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL164_semantics (a : α) (xs : List α) : subsequences (a :: xs) = subsequences xs ++ (subsequences xs).map (fun ys => a :: ys)
```

## 証明する命題

列挙長が 2^length xs であることを証明する。列挙への所属とList.Sublistの同値を両方向に証明する。

主要公開定理: `JonnyLean.Counting.length_subsequences`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL164 (xs : List α) : (subsequences xs).length = 2 ^ xs.length
```

## 境界と範囲

同じ値を含む異なる位置選択は同じ出力語を重複して生成し得る。2^nは位置選択の数であり異なる値列の数ではない。

境界契約:

```lean
theorem contract_JL164_boundary : subsequences [1, 1] = [[], [1], [1], [1, 1]]
```
