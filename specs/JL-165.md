# JL-165: 語を二つへ分割する全境界

## 対象と定義

splits xs は語を接頭語uと接尾語vに分ける全境界を列挙する。空の接頭語と空の接尾語の両端を含める。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL165_semantics (a : α) (xs : List α) : splits (a :: xs) = ([], a :: xs) :: (splits xs).map (fun p => (a :: p.1, p.2))
```

## 証明する命題

列挙された対の所属が u ++ v = xs と同値であることを証明する。分割数が語長+1であること、左右端の分割の所属も示す。

主要公開定理: `JonnyLean.Counting.mem_splits`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL165 (xs u v : List α) : (u, v) ∈ splits xs ↔ u ++ v = xs
```

## 境界と範囲

切断位置は文字間の境界であり、空語にも一つの分割がある。文字の等値判定は使わない。

境界契約:

```lean
theorem contract_JL165_boundary : splits ([] : List Nat) = [([], [])]
```
