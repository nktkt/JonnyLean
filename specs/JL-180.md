# JL-180: 有限遷移核の合成と結合則

## 対象と定義

二段階の核kとlを、各入力aについてbind (k a) lと合成する。出現の並びと積重みを含めたリスト表現そのものの等式を扱う。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL180_semantics (μ : Measure α) (f : α → β) : bind μ (fun a => dirac (f a)) = push f μ
```

## 証明する命題

二回bindする場合と核を先に合成する場合の結合則を証明する。bindとスケールの可換性、Dirac右単位元、点核による押し出し表現も示す。

主要公開定理: `JonnyLean.FiniteProbability.bind_assoc`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL180 (μ : Measure α) (k : α → Measure β) (l : β → Measure γ) : bind (bind μ k) l = bind μ (fun a => bind (k a) l)
```

## 境界と範囲

測度を商で同一視せず、列挙順序を固定したリスト等式として成立する。各核は有限リストを返す。

境界契約:

```lean
theorem contract_JL180_boundary (μ : Measure α) : bind μ dirac = μ
```
