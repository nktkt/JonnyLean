# JL-141: 語の言語と包含順序

## 対象と定義

任意のアルファベット型 α 上の言語を `List α → Prop` とする。包含 `Included L K` は全ての語について L の所属から K の所属を導く命題である。空言語、空語だけの言語、和、共通部分を定義する。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL141_semantics (L K : Language α) : Included L K ↔ ∀ w, L w → K w
```

## 証明する命題

包含の反射性・推移性・反対称性を示す。空言語の最小性と、和言語からの包含が二つの包含と同値であることも証明する。

主要公開定理: `JonnyLean.Languages.included_antisymm`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL141 {L K : Language α} (h : ∀ w, L w → K w) (g : ∀ w, K w → L w) : L = K
```

## 境界と範囲

アルファベットや言語の有限性、所属の決定可能性を仮定しない。反対称性は命題外延性と関数外延性だけを使う。

境界契約:

```lean
theorem contract_JL141_boundary : ¬(empty : Language Nat) []
```

## 検証

- 実装: `JonnyLean/Languages/Basic.lean`。

- 同梱 Init/Std と既存 JonnyLean のみを利用し、Mathlib は使用しない。
- 全宣言について `sorry`、独自公理、`Classical.choice` を禁止する。許容する基礎公理は `propext` と `Quot.sound` のみ。

