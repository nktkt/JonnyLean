# JL-246: 入力終端パーサーの空入力仕様

## 対象と命題

eofの成功を入力と残余の双方が空であることによって必要十分に特徴付ける。

入力型は任意で等号判定は不要。末尾に一文字でもあれば失敗する。

```lean
theorem contract_JL246 (input rest : List α) : eof input = some ((),rest) ↔ input = [] ∧ rest = [] :=
  eof_iff input rest
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.Parsing.eof_iff` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/Parsing/Primitives.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL246_definition : (eof : Parser Bool Unit) [] = some ((),[]) := rfl
```

## 証明の構成

入力の空/非空の場合分けとOptionの構築子の分離。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL246_boundary : (eof : Parser Bool Unit) [true] = none := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。
