# JL-066: 有限列の最小公倍数

## 対象と定義

`listLcm [] = 1`、`listLcm (a::xs) = Nat.lcm a (listLcm xs)`。

## 証明する命題

空列を1とする最小公倍数の畳み込みを実装し、全要素の共通倍数による仕様、連結、要素の整除、ゼロ条件を証明する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem listLcm_dvd (xs : List Nat) (d : Nat) :
    listLcm xs ∣ d ↔ ∀ a ∈ xs, a ∣ d
```

公開補題: `listLcm_dvd`、`listLcm_append`、`member_dvd_listLcm`、`listLcm_eq_zero`。

## 独立契約

`contracts/JL066.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL066` で独立に記述する。`contract_JL066_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

空列の結果は1。結果が0であることと0が列に含まれることは同値。

境界契約は `listLcm [] = 1` と `listLcm [6,10,15] = 30`。
