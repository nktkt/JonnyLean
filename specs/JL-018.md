# JL-018: 連続する奇数の区間和

## 対象と境界

2a+1 から始まる n 個の連続奇数の和が 2an+n² であることを示す。初めの n 奇数の和、添字和、等差列の二倍和も導く。

開始位置 a と項数 n は自然数で、空和 n=0 を含む。最初の項は 2a+1、最後の項は n>0 のとき 2(a+n-1)+1。

## 完全な契約命題

```lean
∀ a n : Nat, sumSpec (fun i => 2 * (a + i) + 1) n = 2 * a * n + n ^ 2
```

公開定理は `JonnyLean.sum_odd_interval`。契約名は `JonnyLean.Contracts.JL018.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 契約が固定する再帰定義

実装側の定義名に依存しない、契約内の独立した定義である。両者の一致は構造帰納法で別に検査する。

```lean
def sumSpec (f : Nat → Nat) : Nat → Nat
  | 0 => 0
  | n + 1 => sumSpec f n + f n
```

## 証明の構成

平方の後者公式から初めの n 奇数の和が n² であると帰納的に示す。一般の開始位置は、各項に定数 2a を足す有限和の線形性から得る。

このモジュールに含まれる名前付き定理:

- `sum_first_odds`
- `twice_sum_indices`
- `twice_sum_successors`
- `sum_affine_double`
- `sum_odd_interval`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `empty_odds`: `sumSpec (fun i => 2 * (9 + i) + 1) 0 = 0`。
- `initial_odds`: `sumSpec (fun i => 2 * i + 1) 5 = 25`。
- `shifted_odds`: `sumSpec (fun i => 2 * (3 + i) + 1) 4 = 40`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。
