# JL-090: 単項式の積・和・合成の指数法則

## 対象と定義

`monomial a n=shift n [a]`、したがって評価は `a*x^n`。

## 証明する命題

単項式aX^nを係数列として構成し、積での指数加法、同次数の和、合成での指数乗法と係数の累乗を示す。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem monomial_compose (a b m n : Nat) :
    Equivalent (compose (monomial a m) (monomial b n)) (monomial (a*b^m) (n*m))
```

公開補題: `evaluate_monomial`、`monomial_length`、`monomial_multiply`、`monomial_add`、`monomial_compose`。

## 独立契約

`contracts/JL090.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL090` で独立に記述する。`contract_JL090_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

係数0でも長さn+1の列を保持する。指数0では定数を表し、0^0はLeanの自然数累乗規約で1。

境界契約は `evaluate (monomial 0 0) 0 = 0` と `evaluate (compose (monomial 2 3) (monomial 5 2)) 2 = 16000`。
