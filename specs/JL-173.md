# JL-173: 自然数観測量の期待値分子と線形性

## 対象と定義

expect μ fを各出現の重みと自然数観測量fの積の有限和とする。正規化前の期待値分子であり、総質量で割る操作はしない。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL173_semantics (a : α) (n : Nat) (μ : Measure α) (f : α → Nat) : expect ((a, n) :: μ) f = n * f a + expect μ f
```

## 証明する命題

観測量の加法に対する線形性を証明する。自然数定数倍、定数観測量、測度連結、押し出し変数変換、観測量の単調性も示す。

主要公開定理: `JonnyLean.FiniteProbability.expect_add`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL173 (μ : Measure α) (f g : α → Nat) : expect μ (fun a => f a + g a) = expect μ f + expect μ g
```

## 境界と範囲

観測量と重みは非負の自然数である。総質量0や空測度でも恒等式は成立する。

境界契約:

```lean
theorem contract_JL173_boundary (f : Nat → Nat) : expect [] f = 0
```
