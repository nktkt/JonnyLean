# JL-023: Fibonacci の加法公式と倍角公式

## 対象と境界

F(m+n+1)=F(m+1)F(n+1)+F(m)F(n) をすべての自然数添字で示し、奇数添字・偶数添字の倍角公式を得る。

m,n は 0 を含む自然数。負の添字や自然数減算を使わない形の加法公式とする。

## 完全な契約命題

```lean
∀ m n : Nat, fibonacciSpec (m + n + 1) = fibonacciSpec (m + 1) * fibonacciSpec (n + 1) + fibonacciSpec m * fibonacciSpec n
```

公開定理は `JonnyLean.fibonacci_addition`。契約名は `JonnyLean.Contracts.JL023.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 契約が固定する再帰定義

実装側の定義名に依存しない、契約内の独立した定義である。両者の一致は構造帰納法で別に検査する。

```lean
def fibonacciPairSpec : Nat → Nat × Nat
  | 0 => (0, 1)
  | n + 1 => let p := fibonacciPairSpec n; (p.2, p.1 + p.2)

def fibonacciSpec (n : Nat) : Nat := (fibonacciPairSpec n).1
```

## 証明の構成

隣接する二つの加法公式を組にして n について帰納法を行う。片方は前のもう片方から得て、次の式は Fibonacci の再帰式と分配法則で構成する。

このモジュールに含まれる名前付き定理:

- `fibonacci_add_pair`
- `fibonacci_addition`
- `fibonacci_double_odd`
- `fibonacci_double_even`
- `fibonacci_three_step`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `zero_indices`: `fibonacciSpec (0 + 0 + 1) = fibonacciSpec 1 * fibonacciSpec 1 + fibonacciSpec 0 * fibonacciSpec 0`。
- `addition_example`: `fibonacciSpec 8 = fibonacciSpec 4 * fibonacciSpec 5 + fibonacciSpec 3 * fibonacciSpec 4`。
- `double_odd_example`: `fibonacciSpec 9 = fibonacciSpec 5 ^ 2 + fibonacciSpec 4 ^ 2`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。
