# JL-176: 事象への測度制限と条件質量

## 対象と定義

restrict μ pはBoolean事象pを満たす出現だけを残し、その重みを保持する。正規化前の条件測度として扱う。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL176_semantics (μ : Measure α) (p : α → Bool) : restrict μ p = μ.filter (fun z => p z.1)
```

## 証明する命題

制限測度の期待値分子が事象外で観測量を0にした期待値分子と一致すると証明する。制限後の総質量、二重制限と共通事象、制限の交換、制限内事象の質量も示す。

主要公開定理: `JonnyLean.FiniteProbability.expect_restrict`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL176 (μ : Measure α) (p : α → Bool) (f : α → Nat) : expect (restrict μ p) f = expect μ (fun a => if p a then f a else 0)
```

## 境界と範囲

条件事象の質量が0でも制限は定義できる。条件付き確率として割り算する操作はここでは行わない。

境界契約:

```lean
theorem contract_JL176_boundary : restrict ([(1, 2), (2, 3)] : Measure Nat) (fun _ => false) = []
```
