# JL-224: 閉包の簡約と冪等性

## 対象と命題

空言語・空語の閉包を空語へ、閉包の二重適用を一重へ簡約するsmartStarが言語を保存する。

閉包は有限回の連結であり、無限語や無限反復を含まない。空語を含む基底言語も許す。

```lean
theorem contract_JL224 (r : Regex α) : denotes (smartStar r) = JonnyLean.Languages.Star (denotes r) :=
  smartStar_correct r
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.RegularExpressions.smartStar_correct` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/RegularExpressions/Smart.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL224_definition : smartStar (.zero : Regex Bool) = .eps := rfl
```

## 証明の構成

空言語閉包、空語閉包、閉包の冪等性を構成的な帰納証明により適用する。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL224_boundary : smartStar (.star (.atom true : Regex Bool)) = .star (.atom true) := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。

## 検証と範囲

- 日本語仕様、主定理、定義契約、境界契約を別の担当が照合する。
- Lean 4.29.1同梱のInit/StdとJonnyLean内部の証明のみを使う。
- `sorry`、`admit`、独自公理、`Classical.choice`を許さず、privateと自動生成宣言を含む公理監査を行う。許容する基礎は`propext`と`Quot.sound`だけ。
- 機械検査の成功と意味のAIレビューを区別し、人間の承認は未記録のままとする。
- 契約ファイル: `contracts/JL224.lean`。
