# JL-081: 有限係数多項式のHorner評価と連結

## 対象と定義

`Polynomial` は `List Nat` の略記。`evaluate [] x=0`、`evaluate (a::p) x=a+x*evaluate p x`。係数の末尾の0は削除しない。

## 証明する命題

自然数係数を低次から並べた有限リストで多項式を表現し、Horner評価と係数列連結の評価公式を証明する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem evaluate_append (p q : Polynomial) (x : Nat) :
    evaluate (p++q) x = evaluate p x + x^p.length * evaluate q x
```

公開補題: `evaluate_append`、`evaluate_zero`、`evaluate_singleton`、`evaluate_append_zero`、`evaluate_replicate_zero`。

## 独立契約

`contracts/JL081.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL081` で独立に記述する。`contract_JL081_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

零多項式の表現は一意ではなく[]と[0]は異なるリストだが評価は同じ。空列、入力0、末尾0を扱う。

境界契約は `evaluate [] 0 = 0` と `evaluate [3,2,1] 10 = 123`。
