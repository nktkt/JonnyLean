# JL-065: 三数の最小公倍数の普遍性

## 対象と定義

`lcmTriple a b c = Nat.lcm a (Nat.lcm b c)`。最小性は整除順序による普遍性で表す。

## 証明する命題

三数の最小公倍数を構成し、共通倍数との同値、スカラー倍、単位元、一意性を証明する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem lcmTriple_dvd (a b c d : Nat) :
    lcmTriple a b c ∣ d ↔ a ∣ d ∧ b ∣ d ∧ c ∣ d
```

公開補題: `lcmTriple_dvd`、`lcmTriple_scale`、`lcmTriple_one`、`lcmTriple_unique`。

## 独立契約

`contracts/JL065.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL065` で独立に記述する。`contract_JL065_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

引数のいずれかが0なら結果は0。1は最小公倍数演算の単位元。

境界契約は `lcmTriple 0 6 10 = 0` と `lcmTriple 6 10 15 = 30`。
