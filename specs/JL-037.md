# JL-037: 末尾再帰の反転と蓄積変数

## 対象・定義・仮定

`reverseInto xs acc` は xs の先頭を acc へ移して再帰する。空入力では acc を返す。acc は任意の列であり空には限定しない。

蓄積変数を持つ末尾再帰の反転は、入力の反転と元の蓄積列の連結に等しい。入力連結の処理則、長さ保存、map との交換、反転の対合性も示す。

## 完全な契約命題

`contracts/JL037.lean` は実装モジュールを直接 import し、以下の完全な型に公開定理を当てはめる。型変数は任意の型であり、自然数や非空型への暗黙の制限はない。明示された場合だけ判定可能性・単射性・全域性・推移性を仮定する。

```lean
theorem JonnyLean.Contracts.JL037 {α : Type u} (xs acc : List α) :
    JonnyLean.Collections.reverseInto xs acc = xs.reverse ++ acc
```

公開定理: `JonnyLean.Collections.reverseInto_spec`。実装: `JonnyLean/Collections/ReverseAccumulator.lean`。

## 証明と範囲

acc を一般化した列の帰納法。再帰呼び出しの不変条件を x::acc に適用し、連結の結合則で正規化する。
