# JL-050: グラフ準同型による歩道の輸送

## 対象と定義

`Hom G H` は頂点写像 `vertex : V → W` と、各辺を像の端点間の辺へ送る証明を持つ。頂点型の universe は独立でよい。

`mapWalk` は空歩道を像の頂点の空歩道へ、辺付き歩道を写像で送った辺と再帰的に送った残りへ写す。恒等準同型と準同型の合成を定義する。

## 証明する命題

準同型による輸送で辺数が変わらないことを歩道の帰納法で示す。連結との可換性、恒等写像・写像の合成との整合性、到達可能性の保存も示す。

主要公開定理: `JonnyLean.GraphTheory.Hom.length_mapWalk`。

契約は次の型を独立に記述し、公開定理から直接構成する。

```lean
theorem contract_JL050 {V : Type u} {W : Type v} {G : Graph V} {H : Graph W}
    (f : Hom G H) {x y : V} (p : Walk G x y) :
    (f.mapWalk p).length = p.length
```

## 境界と範囲

準同型に単射性・全射性は要求しない。異なる頂点が同じ頂点へ写っても、歩道の辺数は保存される。像から元への到達可能性の反映は主張しない。
