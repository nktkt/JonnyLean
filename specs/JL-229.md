# JL-229: 言語同値な式の残余同値

## 対象と命題

元の正規表現二つが全語で同じ意味を持つなら、任意の共通入力を読んだ後の残余も全語で同値になる。

同値は構文等号ではない。アルファベットの有限性や等価判定器の存在を要求しない。

```lean
theorem contract_JL229 [DecidableEq α] {r s : Regex α} (h : ∀ w, denotes r w ↔ denotes s w) (u : List α) : ∀ v, denotes (derivatives u r) v ↔ denotes (derivatives u s) v :=
  derivatives_congr h u
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.RegularExpressions.derivatives_congr` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/RegularExpressions/Matcher.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL229_definition (r s : Regex α) : Equivalent r s = (∀ w, denotes r w ↔ denotes s w) := rfl
```

## 証明の構成

双方の残余の意味を元の式のu++v受理へ戻し、仮定の意味同値を適用する。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL229_boundary : accepts (.alt (.zero : Regex Bool) (.atom true)) [true] = accepts (.atom true : Regex Bool) [true] := by decide
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。

## 検証と範囲

- 日本語仕様、主定理、定義契約、境界契約を別の担当が照合する。
- Lean 4.29.1同梱のInit/StdとJonnyLean内部の証明のみを使う。
- `sorry`、`admit`、独自公理、`Classical.choice`を許さず、privateと自動生成宣言を含む公理監査を行う。許容する基礎は`propext`と`Quot.sound`だけ。
- 機械検査の成功と意味のAIレビューを区別し、人間の承認は未記録のままとする。
- 契約ファイル: `contracts/JL229.lean`。
