# JL-022: Fibonacci 数列の前方和

## 対象と境界

F₀=0,F₁=1 の Fibonacci 数列について F₁+…+Fₙ+1=Fₙ₊₂ を示す。正値性、単調性、線形下界も証明する。

n は 0 を含む自然数。有限和の最後の添字は n であり、F₀ から Fₙ を足す仕様とは区別する。n=0 の左辺は空和に 1 を加えた値。

## 完全な契約命題

```lean
∀ n : Nat, sumSpec (fun i => fibonacciSpec (i + 1)) n + 1 = fibonacciSpec (n + 2)
```

公開定理は `JonnyLean.fibonacci_prefix_sum`。契約名は `JonnyLean.Contracts.JL022.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 契約が固定する再帰定義

実装側の定義名に依存しない、契約内の独立した定義である。両者の一致は構造帰納法で別に検査する。

```lean
def sumSpec (f : Nat → Nat) : Nat → Nat
  | 0 => 0
  | n + 1 => sumSpec f n + f n

def fibonacciPairSpec : Nat → Nat × Nat
  | 0 => (0, 1)
  | n + 1 => let p := fibonacciPairSpec n; (p.2, p.1 + p.2)

def fibonacciSpec (n : Nat) : Nat := (fibonacciPairSpec n).1
```

## 証明の構成

隣接する Fibonacci 数の組を構造再帰で計算する。二段の再帰式を導き、和の長さ n に関する帰納法で公式を証明する。

このモジュールに含まれる名前付き定理:

- `fibonacci_recurrence`
- `fibonacci_positive`
- `fibonacci_step_le`
- `fibonacci_mono`
- `fibonacci_linear_lower_bound`
- `fibonacci_prefix_sum`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `initial_values`: `fibonacciSpec 0 = 0 ∧ fibonacciSpec 1 = 1`。
- `empty_fibonacci_sum`: `sumSpec (fun i => fibonacciSpec (i + 1)) 0 + 1 = fibonacciSpec 2`。
- `first_five_sum`: `sumSpec (fun i => fibonacciSpec (i + 1)) 5 + 1 = 13`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。
