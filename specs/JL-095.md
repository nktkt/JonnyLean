# JL-095: 減算を避けた合成除法と剰余公式

## 対象と定義

`dividedDifference a []=[]`、`dividedDifference a (c::p)=add [evaluate p a] (0::dividedDifference a p)`。先頭係数cは商に寄与しない。

## 証明する命題

p(X)-p(a)をX-aで割った商を自然数係数で再帰構成し、減算なしの対称恒等式から、a≤xにおける剰余公式を導く。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem dividedDifference_remainder (a x : Nat) (p : Polynomial) (h : a ≤ x) :
    evaluate p x = evaluate p a + (x-a)*evaluate (dividedDifference a p) x
```

公開補題: `dividedDifference_identity`、`dividedDifference_remainder`、`dividedDifference_constant`、`dividedDifference_affine`。

## 独立契約

`contracts/JL095.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL095` で独立に記述する。`contract_JL095_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

自然数の切り捨て減算を含む剰余公式にはa≤xが必要。前提を必要としない対称恒等式も別に証明する。

境界契約は `evaluate (dividedDifference 7 [5]) 9 = 0` と `evaluate (dividedDifference 2 [1,0,1]) 5 = 7`。
