# JL-040: 有限集合の単射像と包含反映

## 対象・定義・仮定

`mapInjective f hf A` は列を f で map し、hf から Nodup を得る。一般の写像の像は対象外。基礎的な像・濃度定理では等号の判定可能性は要求しない。

単射写像で移した二つの有限集合の包含は、元の有限集合の包含と同値になる。像の所属、濃度保存、共通部分保存も示す。

## 完全な契約命題

`contracts/JL040.lean` は実装モジュールを直接 import し、以下の完全な型に公開定理を当てはめる。型変数は任意の型であり、自然数や非空型への暗黙の制限はない。明示された場合だけ判定可能性・単射性・全域性・推移性を仮定する。

```lean
theorem JonnyLean.Contracts.JL040 {α : Type u} {β : Type v} (f : α → β)
    (hf : ∀ a b, f a = f b → a = b) (A B : JonnyLean.FiniteSet α) :
    (∀ y, y ∈ JonnyLean.FiniteSet.mapInjective f hf A →
      y ∈ JonnyLean.FiniteSet.mapInjective f hf B) ↔
    (∀ x, x ∈ A → x ∈ B)
```

公開定理: `JonnyLean.FiniteSet.mapInjective_reflects_subset`。実装: `JonnyLean/Collections/InjectiveImage.lean`。

## 証明と範囲

逆方向は元の所属証人を写す。順方向では像の所属証人 y を取り出し、f y = f x から単射性で y = x として元の所属を得る。

一般の入力に対する証明であり、具体例のみの有限検査ではない。補助定理は同じモジュールにあり、契約の追加例では境界ケースや関連した性質も検査する。仕様にない性能計算量・停止時間・外部環境での実行結果は主張しない。
