# JL-243: 燃料付き貪欲反復の末尾保存

## 対象と命題

最大n回の成功を集め最初の失敗で停止するmanyは、基底パーサーが末尾保存なら元入力の末尾を返す。

燃料により必ず停止する。入力非消費の成功も許すため、無制限manyの停止性は主張しない。

```lean
theorem contract_JL243 {p : Parser α β} (hp : Safe p) (n : Nat) (input : List α) : ∃ consumed, input = consumed ++ (many p n input).2 :=
  many_safe hp n input
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.Parsing.many_safe` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/Parsing/Repetition.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL243_definition (p : Parser α β) (input : List α) : many p 0 input = ([],input) := rfl
```

## 証明の構成

燃料への帰納法。成功ごとにSafeの消費部分をつなぎ、失敗枝では消費を空とする。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL243_boundary : many (satisfy id) 10 [true,true,false] = ([true,true],[false]) := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。
