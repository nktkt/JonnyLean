# JL-062: 有限列の最大公約数

## 対象と定義

`listGcd [] = 0`、`listGcd (a::xs) = Nat.gcd a (listGcd xs)` と再帰定義する。

## 証明する命題

空列を0とする最大公約数の畳み込みを構成し、全要素の共通約数による仕様、連結、スカラー倍、ゼロ条件を証明する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem dvd_listGcd (d : Nat) (xs : List Nat) :
    d ∣ listGcd xs ↔ ∀ a ∈ xs, d ∣ a
```

公開補題: `dvd_listGcd`、`listGcd_append`、`listGcd_dvd_member`、`listGcd_scale`、`listGcd_eq_zero`。

## 独立契約

`contracts/JL062.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL062` で独立に記述する。`contract_JL062_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

空列には全自然数が共通約数となるため、空列の結果は 0。重複要素を許す。

境界契約は `listGcd [] = 0` と `listGcd [0,18,30,42] = 6`。
