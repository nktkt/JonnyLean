# JL-024: 単調列の差分和

## 対象と境界

範囲内で非減少な自然数列について、隣接差の総和に最初の値を足すと最後の値になることを示す。区間版と増分の上界も含む。

各 i<n について f i≤f(i+1) を仮定する。Nat の減算は負の値を 0 にするため、この仮定は必要。n=0 では仮定は空。

## 完全な契約命題

```lean
∀ (f : Nat → Nat) (n : Nat), (∀ i : Nat, i < n → f i ≤ f (i + 1)) → sumSpec (fun i => f (i + 1) - f i) n + f 0 = f n
```

公開定理は `JonnyLean.telescoping_sum`。契約名は `JonnyLean.Contracts.JL024.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 契約が固定する再帰定義

実装側の定義名に依存しない、契約内の独立した定義である。両者の一致は構造帰納法で別に検査する。

```lean
def sumSpec (f : Nat → Nat) : Nat → Nat
  | 0 => 0
  | n + 1 => sumSpec f n + f n
```

## 証明の構成

n の帰納法により、それまでの差分和を f n へまとめる。単調性の仮定を使って最後の切り捨て減算を取り消す。

このモジュールに含まれる名前付き定理:

- `telescoping_sum`
- `telescoping_sub`
- `telescoping_interval`
- `constant_increment_formula`
- `bounded_increment_formula`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `empty_differences`: `sumSpec (fun i => (i + 1) - i) 0 + 0 = 0`。
- `constant_sequence`: `sumSpec (fun _ => (7 : Nat) - 7) 4 + 7 = 7`。
- `square_differences`: `sumSpec (fun i => (i + 1) ^ 2 - i ^ 2) 4 = 16`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。
