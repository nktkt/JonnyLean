# JL-179: 有限遷移核と全期待値分子公式

## 対象と定義

核k : α → Measure βは各値に有限重み付き出力列を割り当てる。bind μ kは入力出現の重みで各核の重みをスケールして連結する。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL179_semantics (μ : Measure α) (k : α → Measure β) : bind μ k = μ.flatMap (fun p => scale p.2 (k p.1))
```

## 証明する命題

bind後の期待値分子が、核ごとの期待値分子を入力観測量とした期待値に等しいことを証明する。総質量公式、一定行質量の場合の積、連結の分配、Dirac始点も示す。

主要公開定理: `JonnyLean.FiniteProbability.expect_bind`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL179 (μ : Measure α) (k : α → Measure β) (f : β → Nat) : expect (bind μ k) f = expect μ (fun a => expect (k a) f)
```

## 境界と範囲

各行の質量は一般には異なってよい。一定行質量nの結論では全てのaに対する等式を明示的に要求する。

境界契約:

```lean
theorem contract_JL179_boundary (a : α) (k : α → Measure β) : bind (dirac a) k = k a
```
