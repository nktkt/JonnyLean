# JL-079: 有限因子列の倍数に1を足すEuclid構成

## 対象と定義

`avoidance xs k=product xs*k+1`。新しい素数そのものを返す関数ではなく、既存因子による整除を避ける正の整数を返す。

## 証明する命題

有限積に自然数kを掛けて1を加えた数が、元の積および各因子と互いに素であることを示し、1より大きい元の因子では割れないと結論する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem avoidance_not_dvd (xs : List Nat) (k a : Nat) (ha : a ∈ xs) (h : 1 < a) :
    ¬ a ∣ avoidance xs k
```

公開補題: `avoidance_coprime`、`avoidance_member_coprime`、`avoidance_not_dvd`、`avoidance_positive`。

## 独立契約

`contracts/JL079.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL079` で独立に記述する。`contract_JL079_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

k=0または積0なら結果は1。非整除結論には対象因子が1より大きいことが必要。素因数分解や無限素数定理はここでは主張しない。

境界契約は `avoidance [] 0 = 1` と `avoidance [2,3,5] 1 = 31`。
