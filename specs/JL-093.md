# JL-093: 多項式の入力平行移動

## 対象と定義

`translate c p=compose p [c,1]`。移動量cは自然数。

## 証明する命題

p(X+c)を係数列として合成で構成し、平行移動の合成が移動量の和となることと、加法・積の保存を評価同値として示す。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem translate_translate (c d : Nat) (p : Polynomial) :
    Equivalent (translate c (translate d p)) (translate (c+d) p)
```

公開補題: `evaluate_translate`、`translate_translate`、`translate_add`、`translate_multiply`、`translate_zero`。

## 独立契約

`contracts/JL093.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL093` で独立に記述する。`contract_JL093_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

負の移動量を扱わない。移動量0は評価同値の意味で恒等写像。

境界契約は `evaluate (translate 0 []) 5 = 0` と `evaluate (translate 3 [0,0,1]) 2 = 25`。
