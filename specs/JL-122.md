# JL-122: 式の一斉代入と評価

## 対象と境界

各変数を式で一斉に置き換えた結果の評価は、置換式を元の環境で評価して作った環境による元の式の評価に一致する。束縛のない構文なので捕獲回避仮定は不要。

式は自然数定数、自然数で表す変数名、二項加算・乗算からなる。環境は任意の `Nat → Nat`。変数出現列は順序と重複を保ち、束縛構文は持たない。

## 完全な契約命題

```lean
∀ (replacement : Nat → Expr) (env : Nat → Nat) (e : Expr), meaning env (substituted replacement e) = meaning (fun x => meaning env (replacement x)) e
```

公開定理は `JonnyLean.VerifiedPrograms.Expr.eval_subst`。固定された名前付き契約は `JonnyLean.Contracts.JL122.contract`。

## 独立した意味モデル

以下は `JonnyLean/VerifiedPrograms/ExpressionSpecifications.lean` にある固定モデルである。実装対象の関数を呼ばずに再帰または一命令の状態遷移を定義する。各 `*_matches` 補題を構造帰納法で検査してから公開定理と接続する。

```lean
def meaning (env : Nat → Nat) : Expr → Nat
  | .lit n => n
  | .var x => env x
  | .add a b => meaning env a + meaning env b
  | .mul a b => meaning env a * meaning env b

def substituted (replacement : Nat → Expr) : Expr → Expr
  | .lit n => .lit n
  | .var x => replacement x
  | .add a b => .add (substituted replacement a) (substituted replacement b)
  | .mul a b => .mul (substituted replacement a) (substituted replacement b)
```

## 証明の構成と再利用補題

構文または入力列の構造帰納法を基礎にし、任意の部分木・式・初期状態について帰納仮定を適用する。蓄積引数・後続列・環境は必要に応じて一般化している。独立モデルとの橋渡しは契約の検査に含まれ、主張を実装の型の別名だけで済ませない。

この課題に関連する再利用補題:

- `subst_variables`。

同じ補題を複数の課題として重複計上しない。評価保存、固定点、サイズ制約、静的検査は異なる明示命題として区別する。

## 境界例

- `constant_expression`: `substituted (fun _ => .lit 99) (.lit 4) = .lit 4`。
- `replace_variable`: `meaning id (substituted (fun x => .add (.var x) (.lit 1)) (.var 2)) = 3`。

有限例は境界条件の固定に使う。一般命題の証明を例の列挙で代替しない。

## 実装・依存・検査

- 実装: `JonnyLean/VerifiedPrograms/Expressions.lean`。
- 契約: `contracts/JL122.lean`。
- 独立モデル: `JonnyLean/VerifiedPrograms/ExpressionSpecifications.lean`（editable対象外）。
- 課題依存: JL-121。
- Lean: `leanprover/lean4:v4.29.1`、同梱 Init/Std のみ。
- `sorry`、`admit`、独自公理、`Classical.choice` を使わない。
- 全宣言の許容公理依存は `propext` と `Quot.sound` のみ。
- 機械検査は独立レビューとは別であり、正式なレビューは `reviews/JL-122.json` に記録する。

```sh
lake build +JonnyLean.VerifiedPrograms.Expressions +JonnyLean.VerifiedPrograms.ExpressionSpecifications
lake env lean -DwarningAsError=true JonnyLean/VerifiedPrograms/Expressions.lean
lake env lean -DwarningAsError=true contracts/JL122.lean
```
