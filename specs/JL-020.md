# JL-020: 階乗の単調性

## 対象と境界

階乗を 0!=1 として定義し、引数に関する単調性を証明する。正値性、入力以上の下界、n>0 での厳密な増加も扱う。

m,n は自然数で m≤n。0! と 1! はともに 1 なので、主定理は厳密不等式ではなく ≤ である。

## 完全な契約命題

```lean
∀ m n : Nat, m ≤ n → factorialSpec m ≤ factorialSpec n
```

公開定理は `JonnyLean.factorial_mono`。契約名は `JonnyLean.Contracts.JL020.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 契約が固定する再帰定義

実装側の定義名に依存しない、契約内の独立した定義である。両者の一致は構造帰納法で別に検査する。

```lean
def factorialSpec : Nat → Nat
  | 0 => 1
  | n + 1 => (n + 1) * factorialSpec n
```

## 証明の構成

すべての階乗が正であることを帰納的に示し、各ステップで少なくとも 1 倍されることを使う。隣接する大小関係から任意の m≤n へ帰納法で拡張する。

このモジュールに含まれる名前付き定理:

- `factorial_positive`
- `factorial_one_le`
- `factorial_step_le`
- `factorial_mono`
- `factorial_ge_input`
- `factorial_strict_step`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `empty_product`: `factorialSpec 0 = 1`。
- `equal_first_values`: `factorialSpec 0 = factorialSpec 1`。
- `factorial_five`: `factorialSpec 5 = 120`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。
