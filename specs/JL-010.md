# JL-010: 相互整除の反対称性

## 対象と境界

自然数が互いに整除するなら等しいことを示す。正の被除数に対する約数の上界と、大きい約数の一意性を含む。

a,b は 0 を含む任意の自然数。両方が正であるという仮定を追加しない。

## 完全な契約命題

```lean
∀ a b : Nat, (∃ i : Nat, b = a * i) → (∃ j : Nat, a = b * j) → a = b
```

公開定理は `JonnyLean.divides_antisymm`。契約名は `JonnyLean.Contracts.JL010.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 証明の構成

0 の場合を先に扱う。正の場合は整除の乗数が正になるため、約数が被除数以下になる。その二つの不等式に反対称性を適用する。

このモジュールに含まれる名前付き定理:

- `divisor_le`
- `divides_antisymm`
- `divides_one_iff`
- `divisor_positive`
- `divisor_eq_of_large`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `zero_case`: `(0 : Nat) = 0`。
- `positive_case`: `(12 : Nat) = 12`。
- `zero_not_divisor`: `¬ (∃ k : Nat, 1 = 0 * k)`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。

## 実装・依存・検査

- 実装: `JonnyLean/NumberTheory/DivisibilityOrder.lean`。
- 契約: `contracts/JL010.lean`。
- 課題依存: JL-008。
- Lean: `leanprover/lean4:v4.29.1`、同梱 Init/Std のみ。
- `sorry`、`admit`、新規公理、`Classical.choice` は使用しない。
- 許容公理はプロジェクト方針の `propext` と `Quot.sound` のみ。
- 機械検査と独立レビューは区別する。レビューの正式な状態は `reviews/JL-010.json` に記録する。

```sh
lake build +JonnyLean.NumberTheory.DivisibilityOrder
lake env lean -DwarningAsError=true JonnyLean/NumberTheory/DivisibilityOrder.lean
lake env lean -DwarningAsError=true contracts/JL010.lean
```

契約末尾の `#print axioms` が公開定理と名前付き契約の公理依存を出力する。
