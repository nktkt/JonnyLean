# JL-149: Kleene閉包の冪表示と冪等性

## 対象と定義

帰納的に生成した Star を、自然数回の言語冪の存在として特徴づける。閉包をさらに閉包にする操作も扱う。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL149_semantics (L : Language α) : Star (Star L) = Star L
```

## 証明する命題

Star L への所属と、ある自然数 n に対する power L n への所属が同値であることを示す。Star の冪等性、閉包同士の連結、空言語の閉包も証明する。

主要公開定理: `JonnyLean.Languages.star_iff_power`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL149 (L : Language α) (w : List α) : Star L w ↔ ∃ n, power L n w
```

## 境界と範囲

存在する指数の最小性・一意性は要求しない。L が空語を含めば、同じ語に複数の指数があり得る。

境界契約:

```lean
theorem contract_JL149_boundary : Star (empty : Language Nat) = epsilon
```

## 検証

- 実装: `JonnyLean/Languages/StarClosure.lean`。
