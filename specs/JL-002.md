# JL-002: 連続する自然数の積

## 対象・定義

対象は任意の自然数 `n : Nat`。自然数には **0 を含む**。連続する二つの自然数とは `n` と `n + 1` をいう。

偶数の定義は JL-001 と共通であり、自然数の証人を用いる。

```lean
def JonnyLean.Even (n : Nat) : Prop := ∃ k : Nat, n = 2 * k
```

## 証明する命題

任意の自然数 `n` について、積 `n * (n + 1)` は偶数である。正値性や偶奇についての追加の仮定はない。

```lean
∀ n : Nat, ∃ k : Nat, n * (n + 1) = 2 * k
```

公開定理の型:

```lean
JonnyLean.even_consecutive_product (n : Nat) :
  JonnyLean.Even (n * (n + 1))
```

## 証明の方針

自然数 `n` について帰納法を用いる。`n = 0` の証人は `0`。帰納段階では、`n * (n + 1) = 2 * k` の証人 `k` に対し、次の積の証人を `k + (n + 1)` とする。

```text
(n + 1) * (n + 1 + 1)
  = n * (n + 1) + 2 * (n + 1)
  = 2 * k + 2 * (n + 1)
  = 2 * (k + (n + 1))
```

最初の等式を補題 `JonnyLean.consecutive_product_step` として公開する。証明には、自然数の乗法の再帰式、加法の結合法則、分配法則を用いる。すべての `n` を扱う帰納法であり、有限個の具体例の列挙ではない。
