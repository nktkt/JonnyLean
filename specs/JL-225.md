# JL-225: Kleene閉包を含む正規表現微分の正しさ

## 対象と命題

一文字aに関するBrzozowski微分を計算し、微分後が語wを受理することと元の式がa::wを受理することの同値を示す。

文字のDecidableEqのみを仮定する。閉包内部が空語を受理する場合にも対応し、空語の無限除去を行わない。

```lean
theorem contract_JL225 [DecidableEq α] (r : Regex α) (a : α) (w : List α) : denotes (derivative a r) w ↔ denotes r (a::w) :=
  derivative_correct r a w
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.RegularExpressions.derivative_correct` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/RegularExpressions/Derivative.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL225_definition [DecidableEq α] (a b : α) : derivative a (.atom b) = (if a = b then .eps else .zero) := rfl
```

## 証明の構成

構文帰納法。連結の先頭文字が左側に属する場合と空の左側を通過する場合を分離する。Starの帰納証拠から最初の非空成分を抽出する。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL225_boundary : derivative true (.eps : Regex Bool) = .zero := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。

## 検証と範囲

- 日本語仕様、主定理、定義契約、境界契約を別の担当が照合する。
- Lean 4.29.1同梱のInit/StdとJonnyLean内部の証明のみを使う。
- `sorry`、`admit`、独自公理、`Classical.choice`を許さず、privateと自動生成宣言を含む公理監査を行う。許容する基礎は`propext`と`Quot.sound`だけ。
- 機械検査の成功と意味のAIレビューを区別し、人間の承認は未記録のままとする。
- 契約ファイル: `contracts/JL225.lean`。
