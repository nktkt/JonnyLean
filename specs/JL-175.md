# JL-175: Boolean事象の質量と積事象の分離

## 対象と定義

Boolean事象の指示関数を0または1とし、event μ pをその期待値分子と定義する。積事象は各成分のBoolean条件の論理積である。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL175_semantics (μ : Measure α) (p : α → Bool) : event μ p = expect μ (fun a => if p a then 1 else 0)
```

## 証明する命題

積事象の質量が成分事象質量の積に等しいことを証明する。補事象との質量分割、総質量による上界、押し出しの逆像公式、空事象も示す。

主要公開定理: `JonnyLean.FiniteProbability.event_product`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL175 (μ : Measure α) (ν : Measure β) (p : α → Bool) (q : β → Bool) : event (product μ ν) (fun z => p z.1 && q z.2) = event μ p * event ν q
```

## 境界と範囲

独立性は積測度の構成から得られる。任意の相関を持つ対の測度に対して積公式を主張しない。

境界契約:

```lean
theorem contract_JL175_boundary (μ : Measure α) : event μ (fun _ => false) = 0
```
