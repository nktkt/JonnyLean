# JL-092: 多項式列の有限積と零点の存在

## 対象と定義

`productPolynomials []=[1]`、非空列では `multiply` を再帰適用する。

## 証明する命題

多項式列の有限積を構成し、自然数入力において積の評価が0であることと、ある因子の評価が0であることの同値を証明する。連結と反復因子も扱う。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem productPolynomials_zero (ps : List Polynomial) (x : Nat) :
    evaluate (productPolynomials ps) x = 0 ↔ ∃ p ∈ ps, evaluate p x = 0
```

公開補題: `evaluate_productPolynomials`、`productPolynomials_append`、`productPolynomials_replicate`、`productPolynomials_zero`。

## 独立契約

`contracts/JL092.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL092` で独立に記述する。`contract_JL092_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

空積は1であり零点を持たない。ここでの零点は自然数入力に限り、複素数や整数係数多項式の理論ではない。

境界契約は `evaluate (productPolynomials []) 0 = 1` と `evaluate (productPolynomials [[1,1],[0,1]]) 0 = 0`。
