# JL-233: パーサー合成の未消費末尾保存

## 対象と命題

成功時に入力の末尾を返すパーサーと、その値に依存する同性質の後続パーサーをbindで合成しても末尾保存が成立する。

入力を消費しない成功も許す。副作用や位置情報はなく、結果はOption (値×未消費末尾)。

```lean
theorem contract_JL233 {p : Parser α β} {f : β → Parser α γ} (hp : Safe p) (hf : ∀ b, Safe (f b)) : ∀ input c rest, bindP p f input = some (c,rest) → ∃ consumed, input = consumed ++ rest :=
  bind_safe hp hf
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.Parsing.bind_safe` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/Parsing/Core.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL233_definition (b : β) (input : List α) : pureP b input = some (b,input) := rfl
```

## 証明の構成

前後それぞれの消費語の証人を連結し、List.appendの結合則で元入力を復元する。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL233_boundary : bindP (failP : Parser Bool Nat) (fun n => pureP (n+1)) [] = none := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。
