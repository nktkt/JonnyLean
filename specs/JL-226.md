# JL-226: 語全体による残余正規表現

## 対象と命題

入力語uの各文字で微分を繰り返すと、残余式がvを受理する条件は元の式がu++vを受理する条件になる。

uとvは独立した任意長の有限語。uが空でも成立し、部分一致を無断で全体一致へ変えない。

```lean
theorem contract_JL226 [DecidableEq α] (u v : List α) (r : Regex α) : denotes (derivatives u r) v ↔ denotes r (u ++ v) :=
  derivatives_correct u v r
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.RegularExpressions.derivatives_correct` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/RegularExpressions/Matcher.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL226_definition [DecidableEq α] (r : Regex α) : derivatives [] r = r := rfl
```

## 証明の構成

語uへの帰納法で一文字微分の意味保存を順に適用する。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL226_boundary : derivatives [true,false] (.seq (.atom true) (.atom false) : Regex Bool) = .eps := by decide
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。

## 検証と範囲

- 日本語仕様、主定理、定義契約、境界契約を別の担当が照合する。
- Lean 4.29.1同梱のInit/StdとJonnyLean内部の証明のみを使う。
- `sorry`、`admit`、独自公理、`Classical.choice`を許さず、privateと自動生成宣言を含む公理監査を行う。許容する基礎は`propext`と`Quot.sound`だけ。
- 機械検査の成功と意味のAIレビューを区別し、人間の承認は未記録のままとする。
- 契約ファイル: `contracts/JL226.lean`。
