# JL-100: 値と形式導関数を同時計算するHorner法

## 対象と定義

`evaluateDual [] x=(0,0)`。残りの対を(v,d)とすると、先頭係数aを処理した結果は `(a+x*v,v+x*d)`。

## 証明する命題

一回の係数列走査で多項式値と形式導関数値を同時に計算する評価器を実装し、二つの独立した評価との一致、積および合成への対応を証明する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem evaluateDual_correct (p : Polynomial) (x : Nat) :
    evaluateDual p x = (evaluate p x, evaluate (derivative p) x)
```

公開補題: `evaluateDual_correct`、`evaluateDual_value`、`evaluateDual_derivative`、`evaluateDual_product`、`evaluateDual_chain`。

## 独立契約

`contracts/JL100.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL100` で独立に記述する。`contract_JL100_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

空列と定数を含む。返す第二成分は形式微分の評価であり、係数列の正規化や解析的な微分可能性の判定は行わない。

境界契約は `evaluateDual [] 0 = (0,0)` と `evaluateDual [3,2,1] 4 = (27,10)`。

## 検証と依存制約

- 実装: `JonnyLean/Polynomials/DualEvaluation.lean`。
- 契約: `contracts/JL100.lean`。
- Lean 4.29.1 同梱の Init/Std のみを使用し、Mathlibを使わない。
- 未使用・private・自動生成宣言と契約も含めて公理依存を調べ、許容する基礎は `propext` と `Quot.sound` のみ。`sorry`、`admit`、独自公理、`Classical.choice` は許さない。
- 機械検証は独立した仕様レビューの承認を意味しない。

```sh
lake build JonnyLean.Polynomials.DualEvaluation
lake env lean -DwarningAsError=true JonnyLean/Polynomials/DualEvaluation.lean
lake env lean -DwarningAsError=true contracts/JL100.lean
```
