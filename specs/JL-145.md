# JL-145: 語の反転と言語連結の順序反転

## 対象と定義

反転言語 `reverse L` は、語を反転した結果が L に属することで定義する。語の順序の反転を言語演算へ持ち上げる。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL145_semantics (L : Language α) (w : List α) : reverse L w ↔ L w.reverse
```

## 証明する命題

連結の反転で二因子の順序が逆になることを証明する。二重反転、和との可換性、空語言語の保存も示す。

主要公開定理: `JonnyLean.Languages.reverse_concat`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL145 (L K : Language α) : reverse (concat L K) = concat (reverse K) (reverse L)
```

## 境界と範囲

アルファベットの文字は変更しない。文字の等値判定は必要ない。

境界契約:

```lean
theorem contract_JL145_boundary : reverse (fun w : List Nat => w = [1, 2]) [2, 1]
```
