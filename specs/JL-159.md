# JL-159: 状態の観測同値と接尾語安定性

## 対象と定義

二状態の観測同値は、全ての有限接尾語を読んだ後の受理Booleanが一致することで定義する。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL159_semantics (M : Machine α Q) (q r : Q) : M.Equivalent q r ↔ ∀ w, M.accept (M.run q w) = M.accept (M.run r w)
```

## 証明する命題

同値な状態から共通の語を読んだ結果も同値であることを証明する。反射・対称・推移、一文字遷移の保存、状態からの受理言語の一致も示す。

主要公開定理: `JonnyLean.Automata.Machine.equivalent_run`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL159 (M : Machine α Q) {q r : Q} (h : ∀ w, M.accept (M.run q w) = M.accept (M.run r w)) (u : List α) : M.Equivalent (M.run q u) (M.run r u)
```

## 境界と範囲

商状態の選択や代表元は構成しない。空の接尾語も量化するので現在の受理判定の一致を含む。

境界契約:

```lean
theorem contract_JL159_boundary (M : Machine α Q) (q : Q) : M.Equivalent q q
```

## 検証
