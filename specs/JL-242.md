# JL-242: 固定回数パーサーの結果個数保証

## 対象と命題

n回反復が成功したとき、得られる値リストの長さは必ずnであり、入力消費量とは区別される。

入力を消費しないパーサーでも結果個数はnとなる。入力の長さがn以上とは仮定しない。

```lean
theorem contract_JL242 {p : Parser α β} {n : Nat} {input rest : List α} {bs : List β} (h : repeatP p n input = some (bs,rest)) : bs.length = n :=
  repeat_length h
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.Parsing.repeat_length` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/Parsing/Repetition.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL242_definition (p : Parser α β) (n : Nat) : repeatP p (n+1) = bindP p (fun b => mapP (List.cons b) (repeatP p n)) := rfl
```

## 証明の構成

repeat_iffで独立Chainへ移し、Chainの段数と結果リスト長を帰納法で対応させる。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL242_boundary : repeatP (pureP 7 : Parser Bool Nat) 3 [] = some ([7,7,7],[]) := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。
