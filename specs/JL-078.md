# JL-078: 添字範囲の積の区間分割

## 対象と定義

`rangeProduct f 0=1`、`rangeProduct f (n+1)=rangeProduct f n*f n`。添字範囲は0以上n未満。

## 証明する命題

最初のn項の有限積を定義し、m+n項の積を前半m項と添字をずらした後半n項へ分解する。点ごとの積と整除も保存する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem rangeProduct_split (f : Nat → Nat) (m n : Nat) :
    rangeProduct f (m+n) = rangeProduct f m * rangeProduct (fun i => f (m+i)) n
```

公開補題: `rangeProduct_split`、`rangeProduct_mul`、`rangeProduct_const`、`rangeProduct_dvd`。

## 独立契約

`contracts/JL078.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL078` で独立に記述する。`contract_JL078_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

区間長0は空積1。関数fは任意の自然数値関数で、正値性を仮定しない。

境界契約は `rangeProduct (fun n => n+1) 0 = 1` と `rangeProduct (fun n => n+1) 5 = 120`。
