# JL-083: 多項式のスカラー倍と線形性

## 対象と定義

`scale c p=p.map (fun a => c*a)`。次数の変化ではなく係数列の長さを扱う。

## 証明する命題

全係数を自然数c倍する演算を実装し、評価・加法との交換、倍率の合成、長さの保存を証明する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem evaluate_scale (c : Nat) (p : Polynomial) (x : Nat) :
    evaluate (scale c p) x = c*evaluate p x
```

公開補題: `evaluate_scale`、`scale_scale`、`scale_one`、`scale_add`、`scale_length`。

## 独立契約

`contracts/JL083.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL083` で独立に記述する。`contract_JL083_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

c=0でも係数列の長さは保たれる。空列へのスカラー倍は空列。

境界契約は `scale 0 [3,2,1] = [0,0,0]` と `evaluate (scale 7 [3,2]) 5 = 91`。
