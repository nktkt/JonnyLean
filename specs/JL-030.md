# JL-030: 左右の逆写像の一意性

## 対象・定義・仮定

左逆 g は `∀ x, g (f x) = x`。右逆 h は `∀ y, f (h y) = y`。逆写像は入力データであり存在を選択公理から取り出さない。

同じ写像の左逆と右逆は各点で一致する。左逆からの単射性、右逆からの全射性、逆写像の合成を示す。

## 完全な契約命題

`contracts/JL030.lean` は実装モジュールを直接 import し、以下の完全な型に公開定理を当てはめる。型変数は任意の型であり、自然数や非空型への暗黙の制限はない。明示された場合だけ判定可能性・単射性・全域性・推移性を仮定する。

```lean
theorem JonnyLean.Contracts.JL030 {α : Type u} {β : Type v} (f : α → β) (g h : β → α)
    (hg : ∀ x, g (f x) = x) (hh : ∀ y, f (h y) = y) :
    ∀ y, g y = h y
```

公開定理: `JonnyLean.Functions.inverses_agree`。実装: `JonnyLean/Functions/Inverses.lean`。

## 証明と範囲

g y を g (f (h y)) と書き直し、左逆の等式で h y へ簡約する。補助定理も与えられた逆写像を具体的に適用する。

一般の入力に対する証明であり、具体例のみの有限検査ではない。補助定理は同じモジュールにあり、契約の追加例では境界ケースや関連した性質も検査する。仕様にない性能計算量・停止時間・外部環境での実行結果は主張しない。
