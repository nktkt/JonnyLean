# JL-070: 最大公約数による自然数対の既約化

## 対象と定義

`reducedPair a b = (a/gcd(a,b),b/gcd(a,b))`。Leanの自然数除算を用いる全域関数。

## 証明する命題

最大公約数で各成分を割る既約化を実装し、元の対の再構成と、少なくとも一成分が正なら既約対が互いに素になることを示す。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem reducedPair_coprime (a b : Nat) (h : 0 < a ∨ 0 < b) :
    Nat.gcd (reducedPair a b).1 (reducedPair a b).2 = 1
```

公開補題: `reducedPair_reconstruct_left`、`reducedPair_reconstruct_right`、`reducedPair_coprime`、`reducedPair_of_coprime`、`reducedPair_zero`。

## 独立契約

`contracts/JL070.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL070` で独立に記述する。`contract_JL070_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

(0,0)の既約化は(0,0)となり、互いに素ではない。そのため主定理は少なくとも一成分が正であることを要求する。

境界契約は `reducedPair 0 0 = (0,0)` と `reducedPair 18 30 = (3,5)`。
