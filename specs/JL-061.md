# JL-061: 三数の最大公約数の普遍性

## 対象と定義

`gcdTriple a b c` は `Nat.gcd a (Nat.gcd b c)`。整除は自然数の標準的な整除であり、0 も引数に許す。

## 証明する命題

三つの自然数をまとめる最大公約数を構成し、共通約数との同値、巡回置換、スカラー倍、一意性を示す。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem dvd_gcdTriple (d a b c : Nat) :
    d ∣ gcdTriple a b c ↔ d ∣ a ∧ d ∣ b ∧ d ∣ c
```

公開補題: `dvd_gcdTriple`、`gcdTriple_rotate`、`gcdTriple_scale`、`gcdTriple_zero`、`gcdTriple_unique`。

## 独立契約

`contracts/JL061.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL061` で独立に記述する。`contract_JL061_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

三数すべてが 0 のとき結果は 0。正値性を前提にしない。

境界契約は `gcdTriple 0 0 0 = 0` と `gcdTriple 18 30 42 = 6`。
