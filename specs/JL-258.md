# JL-258: 長さ付きリスト復号の厳密性

## 対象と命題

リスト復号器の成功は、入力がそのリストの正規符号と残余の連結であることに限られる。

境界例のunaryCodecでは、個数1のヘッダーだけで終わる入力は失敗する。一般のCodecは値の空符号も許すので、成功条件は各値の正規符号との一致であり、ヘッダー後の非空入力を一律に要求しない。余分な後続データは末尾として返し、完全消費にはcompleteを使う。

```lean
theorem contract_JL258 (c : Codec Bool β) (input rest : List Bool) (xs : List β) : decodeList c input = some (xs,rest) ↔ input = encodeList c xs ++ rest :=
  list_exact c input rest xs
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.Encoding.list_exact` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/Encoding/FramedLists.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL258_definition (c : Codec Bool β) : decodeList c [] = none := rfl
```

## 証明の構成

ヘッダーの厳密仕様、Chainからのフィールド入力復元、結果個数の保証を組み合わせる。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL258_boundary : decodeList unaryCodec [true,false] = none := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。
