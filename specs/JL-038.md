# JL-038: 有限集合の共通部分と分配則

## 対象・定義・仮定

既存の `FiniteSet α` は列と Nodup 証明を持つ。共通部分は左列を右集合の所属条件でフィルタする。`DecidableEq α` が必要。集合の同値は所属の同値であり表現列の等号ではない。

重複のない列で表現した有限集合について共通部分を構成し、和集合への分配法則を外延的同値として示す。包含の最大下界性、可換性、単調性を含む。

## 完全な契約命題

`contracts/JL038.lean` は実装モジュールを直接 import し、以下の完全な型に公開定理を当てはめる。型変数は任意の型であり、自然数や非空型への暗黙の制限はない。明示された場合だけ判定可能性・単射性・全域性・推移性を仮定する。

```lean
theorem JonnyLean.Contracts.JL038 {α : Type u} [DecidableEq α] (A B C : JonnyLean.FiniteSet α) :
    ∀ x, x ∈ JonnyLean.FiniteSet.intersection A (JonnyLean.FiniteSet.union B C) ↔
      x ∈ JonnyLean.FiniteSet.union (JonnyLean.FiniteSet.intersection A B)
        (JonnyLean.FiniteSet.intersection A C)
```

公開定理: `JonnyLean.FiniteSet.intersection_union_distrib`。実装: `JonnyLean/Collections/Intersection.lean`。

## 証明と範囲

フィルタの所属条件を論理積へ変換し、既存の和集合の所属条件を論理和へ変換して論理分配則を適用する。Nodup はフィルタで保存される。

一般の入力に対する証明であり、具体例のみの有限検査ではない。補助定理は同じモジュールにあり、契約の追加例では境界ケースや関連した性質も検査する。仕様にない性能計算量・停止時間・外部環境での実行結果は主張しない。
