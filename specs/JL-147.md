# JL-147: 言語の有限冪と指数加法

## 対象と定義

零乗を空語言語、後続の冪を L と直前の冪の連結として定義する。冪の指数は自然数である。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL147_semantics (L : Language α) (n : Nat) : power L (n + 1) = concat L (power L n)
```

## 証明する命題

指数の和に対する言語冪を二つの冪の連結へ分解する。零乗・一乗、包含の保存、空語言語の任意冪も証明する。

主要公開定理: `JonnyLean.Languages.power_add`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL147 (L : Language α) (m n : Nat) : power L (m + n) = concat (power L m) (power L n)
```

## 境界と範囲

零乗は元の言語が空でも空語言語であり、空言語にならない。

境界契約:

```lean
theorem contract_JL147_boundary : power (empty : Language Nat) 0 []
```
