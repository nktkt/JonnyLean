# JL-054: 部分グラフでの到達可能性と空グラフ

## 対象と定義

同じ頂点型上で辺集合を拡大する包含 `Graph.Subgraph G H` を扱う。包含から、頂点上では恒等写像である準同型 `inclusion` を作る。

包含はすべての辺の含意である。空グラフの辺は常に `False`、完全グラフの辺は常に `True`。

## 証明する命題

辺を追加すると到達可能性と相互到達可能性が保存される。グラフの和への左右の到達可能性の保存も示す。空グラフの歩道には辺を追加できないため、空グラフで到達可能であることは端点が等しいことと同値になる。

主要公開定理: `JonnyLean.GraphTheory.reachable_empty_iff`。

契約は次の型を独立に記述し、公開定理から直接構成する。

```lean
theorem contract_JL054 {V : Type u} (x y : V) :
    Nonempty (Walk (Graph.mk (fun _ _ : V => False)) x y) ↔ x = y
```

## 境界と範囲

空グラフの同一頂点間は到達可能、異なる Boolean 頂点間は到達不能。完全グラフでは異なる頂点間も到達可能。辺を削除したときの保存は主張しない。
