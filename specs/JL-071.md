# JL-071: 原始対の拡大率の一意性

## 対象と定義

原始対とは `Nat.gcd a b = 1` を満たす対。倍率 k は自然数で、0も許す。

## 証明する命題

互いに素な自然数対を同じ比率で拡大したとき、最大公約数が拡大率となることから、同じ拡大結果の倍率が一意であることを示す。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem primitive_scale_unique (a b c d k l : Nat)
    (hab : Nat.gcd a b = 1) (hcd : Nat.gcd c d = 1)
    (h₁ : k*a = l*c) (h₂ : k*b = l*d) : k = l
```

公開補題: `primitive_scale_gcd`、`primitive_scale_reduced`、`primitive_scale_unique`、`primitive_scale_lcm`。

## 独立契約

`contracts/JL071.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL071` で独立に記述する。`contract_JL071_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

倍率の一意性には正値性は不要。拡大対から原始対を復元する補題では倍率が正であることを要求する。

境界契約は `reducedPair (0*3) (0*5) = (0,0)` と `Nat.gcd (7*3) (7*5) = 7`。
