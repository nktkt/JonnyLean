# JL-056: 有限語の計数と積の法則

## 対象と定義

JL-055 の語の列挙について、リスト長を個数とする。アルファベットの同じ値の重複は別の出現として数える。

`words` の定義は JL-055 の再帰に従う。アルファベットの出現数を `m` とすると、各文字の分岐から同じ個数の語が生成される。

## 証明する命題

まず各分岐の長さが一定の `flatMap` の長さが、入力の長さと分岐の長さの積になることを帰納的に示す。これを用いて、長さ `n` の語の列挙個数が `alphabet.length ^ n` になることを証明する。長さ 1、長さ 2、単一文字アルファベットの系も示す。

主要公開定理: `JonnyLean.Combinatorics.length_words`。

契約は次の型を独立に記述し、公開定理から直接構成する。

```lean
theorem contract_JL056 {α : Type u} (alphabet : List α) (n : Nat) :
    (words alphabet n).length = alphabet.length ^ n
```

## 境界と範囲

空アルファベットと長さ 0 の場合の個数は 1、正の長さでは 0。値の異なる語の集合濃度ではなく、重複込みの列挙個数である。Boolean の長さ 3 は 8 個となる。
