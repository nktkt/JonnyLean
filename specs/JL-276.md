# JL-276: 燃料付き実行器の健全性

## 対象と定義

runが有限燃料nでsome tを返すならbig-step意味論に実際の停止導出が存在する。fuel0はskipを含めてnoneである。逐次合成の両子命令には同じ減少燃料を渡し、whileの本体と再帰にも同じ減少燃料を渡す。燃料は基本命令数ではなく導出木の高さを制約する。

状態は `State = Nat → Nat`、変数値は自然数である。減算は自然数の切り捨て減算を用いる。
`Exec c s t` は命令cの有限big-step導出、`run n c s` は燃料nの実行結果である。
`Hoare P c Q` は停止した実行についてのみQを保証する部分正当性を表す。

## 証明する命題

```lean
∀ (n : Nat) (c : Cmd) (s t : State), run n c s = some t → Exec c s t
```

主定理: `JonnyLean.Imperative.run_sound`。
命題に記載した量化・仮定をすべて保持する。有限のテスト入力のみの主張ではない。
関数の等式は全変数での値の一致を意味し、観測リストでの一致は `Agrees` と区別する。

## 独立契約と境界

`contracts/JL276.lean` の名前付き `contract` は上記の型を明記し、対象定理をその型に代入する。
`definition_check` は基礎定義の計算規則を別の命題で確認する。
次の境界・具体例も名前付き命題としてLeanで検査する。

```lean
(run 2 (.seq (.assign 0 (.lit 7)) .skip) (fun _ => 0)).map (fun t => t 0) = some 7
```

0、空の観測集合、更新されない変数も定義の対象である。変数の相異条件がある定理では、その条件を外した結論は主張しない。
`none` は一般には燃料不足であり、単独では非停止の証明としない。停止を含む例題では `∃ t, Exec ...` または具体的終了状態の `Exec` を結論に含める。
