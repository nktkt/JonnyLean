# JL-051: 無向グラフの歩道反転

## 対象と定義

`Undirected G` は全頂点対で辺関係が対称であるという命題である。有向グラフの型自体へ対称性を組み込まない。

`reverse sym` は空歩道をそのままにし、前の辺を反転して、反転した残りの後ろへ連結する。返り値の端点は元と逆順になる。

## 証明する命題

歩道を二回反転すると元に戻ることを示す。そのために、連結の反転は反転した二つの歩道を逆順に連結すること、反転で長さが保存されることを証明する。無向グラフでは到達可能性も対称になる。

主要公開定理: `JonnyLean.GraphTheory.Walk.reverse_reverse`。

契約は次の型を独立に記述し、公開定理から直接構成する。

```lean
theorem contract_JL051 {V : Type u} {G : Graph V}
    (sym : ∀ ⦃x y⦄, G.edge x y → G.edge y x) {x y : V} (p : Walk G x y) :
    (p.reverse sym).reverse sym = p
```

## 境界と範囲

対称性の仮定は必須。空歩道と 1 本の辺の反転も検査する。一般の有向グラフで同じグラフ内に反転歩道があるとは主張しない。
