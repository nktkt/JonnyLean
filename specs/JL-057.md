# JL-057: 順序を保つ位置の選択列挙

## 対象と定義

`selections k xs` はリスト `xs` から `k` 個の位置を元の順序のまま選んだ値列を列挙する。値が同じ位置も異なる選択肢として扱う。

0 個選ぶ結果は空リストただ一つ。空の入力から正個数を選ぶ結果は空。`a :: xs` から `k+1` 個を選ぶ結果は、`a` を選んで残りから `k` 個を選ぶ枝と、`a` を選ばない枝の連結である。

## 証明する命題

列挙への所属は「元の順序を保つ部分列であり、長さが `k`」と同値である。すべての部分列が対応する長さの列挙に現れることも、部分列の証明について帰納して示す。列挙結果の各値は元のリストに属する。全位置を選ぶと元のリストただ一つになり、入力長より多く選ぼうとすると結果が空になる。再帰構造に沿って証明する。

主要公開定理: `JonnyLean.Combinatorics.mem_selections_iff`。

契約は次の型を独立に記述し、公開定理から直接構成する。

```lean
theorem contract_JL057 {α : Type u} {xs ys : List α} {k : Nat} :
    ys ∈ selections k xs ↔ ys.Sublist xs ∧ ys.length = k
```

## 境界と範囲

`[1,2,3]` の 2 位置選択を `[[1,2],[1,3],[2,3]]` と検査する。`[1,1,1]` の 2 位置選択は同じ値列を 3 回含む。集合の冪集合や選択結果の重複除去は扱わない。
