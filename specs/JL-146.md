# JL-146: 前置語による左商と残余言語

## 対象と定義

語 u による左商は `leftQuotient u L w := L (u ++ w)` と定義する。指定された接頭語を読んだ後に必要な接尾語の言語である。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL146_semantics (u w : List α) (L : Language α) : leftQuotient u L w ↔ L (u ++ w)
```

## 証明する命題

二語の連結による左商は左商の反復と一致する。空語による左商、和・共通部分との可換性、包含の保存、空の接尾語の所属も示す。

主要公開定理: `JonnyLean.Languages.quotient_append`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL146 (u v : List α) (L : Language α) : leftQuotient (u ++ v) L = leftQuotient v (leftQuotient u L)
```

## 境界と範囲

「左商」の入力は単一の語であり、言語全体に対する存在量化された商ではない。

境界契約:

```lean
theorem contract_JL146_boundary : leftQuotient [1] (fun w : List Nat => w = [1, 2]) [2]
```
