# JL-003: 三角数の和の公式

## 対象・定義

対象は任意の自然数 `n : Nat`。自然数には **0 を含む**。三角数 `T n` は `1` から `n` までの自然数の和であり、空の和は `0` とする。除算を用いず、加算による再帰で定義する。

```lean
def JonnyLean.triangular : Nat → Nat
  | 0 => 0
  | n + 1 => JonnyLean.triangular n + (n + 1)
```

したがって、`T 0 = 0`、`T 1 = 1`、`T 2 = 3`、`T 5 = 15` となる。公式そのものを定義に埋め込むことはしない。

## 証明する命題

任意の自然数 `n` について、和の二倍は `n * (n + 1)` に等しい。追加の仮定はない。

```lean
∀ n : Nat, 2 * JonnyLean.triangular n = n * (n + 1)
```

公開定理の型:

```lean
JonnyLean.triangular_formula (n : Nat) :
  2 * JonnyLean.triangular n = n * (n + 1)
```

この課題が要求するのは自然数の等式である。自然数除算の切り捨てや、正の自然数だけという暗黙の制限を含まない。

## 証明の方針

`n` について帰納法を用いる。基底 `n = 0` は `0 = 0`。帰納段階では再帰定義、分配法則、帰納仮定を用いて、左辺を次のように変形する。

```text
2 * T (n + 1)
  = 2 * (T n + (n + 1))
  = 2 * T n + 2 * (n + 1)
  = n * (n + 1) + 2 * (n + 1)
  = (n + 1) * (n + 1 + 1)
```

最後の等式には JL-002 の算術補題 `JonnyLean.consecutive_product_step` を用いる。
