# JL-021: 階乗による小さい正整数の整除

## 対象と境界

1≤k≤n を満たす自然数 k は n! を割り切る。連続積による階乗の分割公式と、小さい階乗が大きい階乗を割り切ることを構成する。

k,n は自然数、0<k と k≤n が必要。k=0 の除外は本質的で、n=0 のとき仮定を満たす k は存在しない。

## 完全な契約命題

```lean
∀ k n : Nat, 0 < k → k ≤ n → ∃ w : Nat, factorialSpec n = k * w
```

公開定理は `JonnyLean.positive_le_divides_factorial`。契約名は `JonnyLean.Contracts.JL021.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 契約が固定する再帰定義

実装側の定義名に依存しない、契約内の独立した定義である。両者の一致は構造帰納法で別に検査する。

```lean
def factorialSpec : Nat → Nat
  | 0 => 1
  | n + 1 => (n + 1) * factorialSpec n
```

## 証明の構成

階乗 (m+r)! を m! と後続 r 因子の積へ分解する。k は k! を割り切り、k! は n! を割り切るので推移性を使う。

このモジュールに含まれる名前付き定理:

- `factorial_add_product`
- `factorial_divides_later`
- `input_divides_factorial`
- `positive_le_divides_factorial`
- `rising_product_positive`
- `rising_product_split`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `smallest_factor`: `∃ w : Nat, factorialSpec 1 = 1 * w`。
- `interior_factor`: `∃ w : Nat, factorialSpec 5 = 3 * w`。
- `zero_excluded`: `¬ (∃ w : Nat, factorialSpec 0 = 0 * w)`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。
