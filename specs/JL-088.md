# JL-088: 多項式の評価同値と演算の適合性

## 対象と定義

`Equivalent p q` は `∀ x, evaluate p x = evaluate q x`。商型の選択や代表元選択は用いない。

## 証明する命題

すべての自然数入力で評価が一致する関係を定義し、反射・対称・推移および加法・積・合成の両引数への適合性を証明する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem equivalent_compose (p q r s : Polynomial) (h : Equivalent p q) (k : Equivalent r s) :
    Equivalent (compose p r) (compose q s)
```

公開補題: `equivalent_refl`、`equivalent_symm`、`equivalent_trans`、`equivalent_add`、`equivalent_multiply`、`equivalent_compose`、`equivalent_trailing_zero`。

## 独立契約

`contracts/JL088.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL088` で独立に記述する。`contract_JL088_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

末尾0の異なる表現も評価同値になる。形式的な係数一致や商型の正規形はこの課題では構成しない。

境界契約は `evaluate ([] : Polynomial) 7 = evaluate [0] 7` と `evaluate [1,2] 3 = evaluate [1,2,0] 3`。

## 検証と依存制約

- 実装: `JonnyLean/Polynomials/Equivalence.lean`。
- 契約: `contracts/JL088.lean`。
- Lean 4.29.1 同梱の Init/Std のみを使用し、Mathlibを使わない。
- 未使用・private・自動生成宣言と契約も含めて公理依存を調べ、許容する基礎は `propext` と `Quot.sound` のみ。`sorry`、`admit`、独自公理、`Classical.choice` は許さない。
- 機械検証は独立した仕様レビューの承認を意味しない。

```sh
lake build JonnyLean.Polynomials.Equivalence
lake env lean -DwarningAsError=true JonnyLean/Polynomials/Equivalence.lean
lake env lean -DwarningAsError=true contracts/JL088.lean
```
