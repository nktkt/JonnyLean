# JL-153: 積機械と受理言語の共通部分

## 対象と定義

積機械は状態対を保持し、同じ入力文字で両成分を同時に遷移させる。受理判定は二つのBoolean判定の論理積とする。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL153_semantics (M : Machine α Q) (N : Machine α R) (q : Q) (r : R) (a : α) : (M.product N).step (q, r) a = (M.step q a, N.step r a)
```

## 証明する命題

任意状態対・任意語で走行が成分ごとの走行に一致し、初期状態からの受理言語が二言語の共通部分であることを証明する。

主要公開定理: `JonnyLean.Automata.Machine.language_product`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL153 (M : Machine α Q) (N : Machine α R) : (M.product N).language = inter M.language N.language
```

## 境界と範囲

積の状態型や初期状態を明示する。どちらかの機械が語を拒否すれば積も拒否する。

境界契約:

```lean
theorem contract_JL153_boundary (M : Machine α Q) (N : Machine α R) : (M.product N).language [] ↔ M.language [] ∧ N.language []
```
