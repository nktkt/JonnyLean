# JL-167: 挿入による順列列挙と階乗

## 対象と定義

空語の順列は空語一個とし、先頭文字を残りの各順列の全位置へ挿入して列挙する。位置の並べ替えを数える。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL167_semantics (a : α) (xs : List α) : permutations (a :: xs) = (permutations xs).flatMap (insertions a)
```

## 証明する命題

全列挙結果の語長保存と元の語自身の所属を示した後、列挙長が語長の階乗に一致すると証明する。

主要公開定理: `JonnyLean.Counting.length_permutations`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL167 (xs : List α) : (permutations xs).length = JonnyLean.factorial xs.length
```

## 境界と範囲

文字が重複する場合は同じ語が複数回出る。異なる語の集合濃度や重複除去後の個数は主張しない。

境界契約:

```lean
theorem contract_JL167_boundary : permutations [1, 1] = [[1, 1], [1, 1]]
```
