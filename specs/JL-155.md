# JL-155: 状態準同型による走行と受理の輸送

## 対象と定義

機械準同型 Hom M N は状態写像、初期状態の保存、遷移との可換性、受理Booleanの一致を持つ。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL155_semantics {M : Machine α Q} {N : Machine α R} (f : Hom M N) (q : Q) (a : α) : f.state (M.step q a) = N.step (f.state q) a
```

## 証明する命題

状態写像と任意語の走行が可換であることを帰納法で証明し、受理言語の等式を導く。恒等準同型と合成を構成し、合成の状態写像も明示する。

主要公開定理: `JonnyLean.Automata.Hom.language_eq`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL155 {M : Machine α Q} {N : Machine α R} (f : Hom M N) : M.language = N.language
```

## 境界と範囲

状態写像の単射性や全射性は要求しない。受理Booleanの一致を仮定するので単なる言語包含ではなく等式が成立する。

境界契約:

```lean
theorem contract_JL155_boundary (M : Machine α Q) (q : Q) : (Hom.id M).state q = q
```
