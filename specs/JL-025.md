# JL-025: アフィン写像の反復の閉形式

## 対象と境界

自然数上の写像 x↦ax+b を n 回反復した値を a^n x+bΣa^i で表す。写像の合成、結合則、恒等写像、反復の加法則も構成する。

a,b,n,x は 0 を含む自然数。0 回の反復は恒等写像。a=0 の定数写像、a=1 の平行移動も同じ公式に含める。

## 完全な契約命題

```lean
∀ a b n x : Nat, iterateSpec a b n x = a ^ n * x + b * sumSpec (fun i => a ^ i) n
```

公開定理は `JonnyLean.NatAffine.iterate_formula`。契約名は `JonnyLean.Contracts.JL025.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 契約が固定する再帰定義

実装側の定義名に依存しない、契約内の独立した定義である。両者の一致は構造帰納法で別に検査する。

```lean
def sumSpec (f : Nat → Nat) : Nat → Nat
  | 0 => 0
  | n + 1 => sumSpec f n + f n

def iterateSpec (a b : Nat) : Nat → Nat → Nat
  | 0, x => x
  | n + 1, x => a * iterateSpec a b n x + b
```

## 証明の構成

写像を傾きと切片の構造体で表す。合成の意味を確認し、反復回数に関する帰納法で傾き a^n と切片 bΣa^i を同時に求める。契約側では値の反復を独立に再帰定義して意味の一致を検査する。

このモジュールに含まれる名前付き定理:

- `eval_compose`
- `compose_assoc`
- `identity_left`
- `identity_right`
- `eval_ext`
- `iterate_coefficients`
- `iterate_formula`
- `iterate_add`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `zero_iterations`: `iterateSpec 3 4 0 7 = 7`。
- `constant_map`: `iterateSpec 0 5 3 8 = 5`。
- `translation`: `iterateSpec 1 3 4 2 = 14`。
- `affine_example`: `iterateSpec 2 1 4 3 = 63`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。
