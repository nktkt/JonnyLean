# JL-014: 自然数の平方展開

## 対象と境界

自然数の和の平方を展開し、平方差・隣接平方・平方の単調性へつなぐ。

a,b は 0 を含む任意の自然数。減算を含む補助定理では (a+b)^2-a^2 を Nat の減算で解釈する。

## 完全な契約命題

```lean
∀ a b : Nat, (a + b) ^ 2 = a ^ 2 + 2 * a * b + b ^ 2
```

公開定理は `JonnyLean.square_add`。契約名は `JonnyLean.Contracts.JL014.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 証明の構成

平方を乗法へ展開し、両側の分配法則を適用する。同じ交差項を二つ集め、結合・交換法則で整理する。

このモジュールに含まれる名前付き定理:

- `square_add`
- `square_succ`
- `square_add_symmetric`
- `square_product`
- `square_gap`
- `square_monotone`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `zero_pair`: `(0 + 0 : Nat) ^ 2 = 0 ^ 2 + 2 * 0 * 0 + 0 ^ 2`。
- `square_five`: `(2 + 3 : Nat) ^ 2 = 2 ^ 2 + 2 * 2 * 3 + 3 ^ 2`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。

## 実装・依存・検査

- 実装: `JonnyLean/Algebra/Quadratic.lean`。
- 契約: `contracts/JL014.lean`。
- 課題依存: なし（Lean 同梱 Init/Std のみ）。
- Lean: `leanprover/lean4:v4.29.1`、同梱 Init/Std のみ。
- `sorry`、`admit`、新規公理、`Classical.choice` は使用しない。
- 許容公理はプロジェクト方針の `propext` と `Quot.sound` のみ。
- 機械検査と独立レビューは区別する。レビューの正式な状態は `reviews/JL-014.json` に記録する。

```sh
lake build +JonnyLean.Algebra.Quadratic
lake env lean -DwarningAsError=true JonnyLean/Algebra/Quadratic.lean
lake env lean -DwarningAsError=true contracts/JL014.lean
```
