# JL-209: 四分割行列作用とブロック積の合成

## 対象と定義

型付き四象限のブロック行列を掛けた作用が二段階の作用と一致する。

`Vec n`は`Fin n → Nat`、`Mat m n`は`Fin m → Fin n → Nat`である。有限和`sum`は空次元で0、後続次元で先頭座標と残りの和を加える。`dot`は座標積の和、`mulMat`は共通次元の座標積の和である。
四分割行列は`Block m n p q`の四つの行列で表し、入力と出力はベクトルの対である。`Fin (m+n)`へ平坦化した行列への同型をこの仕様で主張しない。

## 証明する命題

```lean
theorem blockAct_comp {m n p q r s : Nat} (A : Block m n p q) (B : Block p q r s) (x : (Fin r → Nat) × (Fin s → Nat)) :
    blockAct (blockMul A B) x = blockAct A (blockAct B x)
```

各出力ベクトルへ行列作用の合成・加法分配を適用し、四項の加法順序を整理する。

## 量化・仮定・範囲

表示した次元・添字・係数・行列・ベクトルをすべて量化する。自然数次元には0を含み、正の次元を追加で仮定しない。`Fin n`型の添字を要求する命題では、n=0に対する添字は存在しない。
比較を含む定理では命題に明記した成分ごとの不等式だけを仮定する。係数は自然数であり、加法逆元、体、行列の一般的な可換性、実数内積空間についての主張ではない。

## 独立契約と境界検査

`contracts/JL209.lean`は入力を`Fin`から`Nat`への関数として明記した名前付き期待型`contract_JL209`を持ち、実装定理をその型へ代入する。主定理の型を推論させた別名にはしない。
表現の定義を次の独立した式で確認する。

```lean
(blockAct A x).1 = (fun i => sum (fun j => A.tl i j * x.1 j) + sum (fun j => A.tr i j * x.2 j))
```

具体計算: `(blockAct (Block.mk (fun _ _ => 1) (fun _ _ => 2) (fun _ _ => 3) (fun _ _ => 4) : Block 1 1 1 1) ((fun _ => 5),(fun _ => 6))).2 0 = 39`。
境界計算: `(blockMul (blockDiagonal (identity 1) (identity 1)) (blockDiagonal (identity 1) (identity 1))).tr 0 0 = 0`。
同一モジュールの法則を共有する複数課題があるが、各課題の主定理と期待型は異なる。
