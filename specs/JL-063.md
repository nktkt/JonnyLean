# JL-063: Euclidせん断列による共通約数の保存

## 対象と定義

`shear k (a,b) = (b,a+k*b)`。`shearTrace` は係数列を先頭から順番に適用する。

## 証明する命題

対(a,b)を(b,a+kb)へ送る計算と任意長の係数列による反復を構成し、最大公約数と共通約数全体の保存を示す。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem shearTrace_common (ks : List Nat) (s : Nat × Nat) (d : Nat) :
    (d ∣ (shearTrace ks s).1 ∧ d ∣ (shearTrace ks s).2) ↔
    (d ∣ s.1 ∧ d ∣ s.2)
```

公開補題: `shear_gcd`、`shearTrace_gcd`、`shearTrace_append`、`shearTrace_common`。

## 独立契約

`contracts/JL063.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL063` で独立に記述する。`contract_JL063_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

係数 0 は二成分の交換。空係数列は入力を返す。減算を使わない自然数上の操作。

境界契約は `shearTrace [] (0,0) = (0,0)` と `shearTrace [2,3] (6,9) = (24,81)`。
