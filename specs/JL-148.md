# JL-148: Kleene閉包の構成と最小性

## 対象と定義

`Star L` は空語を含み、L の語を左から連結して生成する帰納的言語である。有限回の生成だけを許す。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL148_semantics {L : Language α} {u v : List α} (hu : L u) (hv : Star L v) : Star L (u ++ v)
```

## 証明する命題

空語を含み、L を含み、連結で閉じた任意の言語 K が Star L を含むという最小性を示す。単語の包含、閉包内連結、単調性、有限冪からの包含も示す。

主要公開定理: `JonnyLean.Languages.star_minimal`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL148 {L K : Language α} (h0 : K []) (hL : ∀ w, L w → K w) (hc : ∀ u v, K u → K v → K (u ++ v)) : ∀ w, Star L w → K w
```

## 境界と範囲

L に空語が入っていてもよい。無限語や無限連結は扱わず、選択公理を使わない。

境界契約:

```lean
theorem contract_JL148_boundary : Star (empty : Language Nat) []
```

## 検証

- 実装: `JonnyLean/Languages/Star.lean`。
- 独立契約: `contracts/JL148.lean`。主定理・定義の意味・境界を名前付き命題で検査する。
- 同梱 Init/Std と既存 JonnyLean のみを利用し、Mathlib は使用しない。
- 全宣言について `sorry`、独自公理、`Classical.choice` を禁止する。許容する基礎公理は `propext` と `Quot.sound` のみ。
- 機械検証は独立レビューによる承認を意味しない。

```sh
lake build JonnyLean.Languages.Star
lake env lean -DwarningAsError=true JonnyLean/Languages/Star.lean
lake env lean -DwarningAsError=true contracts/JL148.lean
```
