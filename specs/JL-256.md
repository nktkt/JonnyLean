# JL-256: 指定個数の連続フィールド復号

## 対象と命題

任意のCodecで各値を符号化して連結した列は、要素数を指定したrepeatP復号によって元リストと末尾へ戻る。

個数は外部指定であり、この段階ではストリームへ埋め込まない。空リストなら入力を消費しない。

```lean
theorem contract_JL256 (c : Codec α β) (xs : List β) (rest : List α) : decodeFields c xs.length (encodeFields c xs ++ rest) = some (xs,rest) :=
  fields_roundtrip c xs rest
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.Encoding.fields_roundtrip` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/Encoding/FramedLists.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL256_definition (c : Codec α β) (xs : List β) : encodeFields c xs = xs.flatMap c.encode := rfl
```

## 証明の構成

値リストへの帰納法で一要素のCodec roundtripと残りの反復復号を合成する。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL256_boundary : decodeFields unaryCodec 2 (unary 1 ++ unary 2 ++ [true]) = some ([1,2],[true]) := rfl
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。

## 検証と範囲

- 日本語仕様、主定理、定義契約、境界契約を別の担当が照合する。
- Lean 4.29.1同梱のInit/StdとJonnyLean内部の証明のみを使う。
- `sorry`、`admit`、独自公理、`Classical.choice`を許さず、privateと自動生成宣言を含む公理監査を行う。許容する基礎は`propext`と`Quot.sound`だけ。
