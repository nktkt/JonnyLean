# JL-059: 自然数重み付き有限質量と事象の加法性

## 対象と定義

有限の結果リスト `xs`、自然数重み `w : α → Nat`、Boolean 事象 `p : α → Bool` を用いる。正の総質量はまだ要求しない。

`mass w [] = 0`、`mass w (a::xs) = w a + mass w xs`。`eventMass` は各結果が事象を満たす場合のみ重みを加える。リストの重複は出現ごとに加算される。

## 証明する命題

事象と Boolean 補事象の質量の和が総質量に等しいことを帰納法と Boolean の場合分けで示す。フィルターによる意味づけ、空・全事象、質量の上界、台上の事象の同値性と包含による単調性、台上で交わらない二事象の有限加法性も示す。

主要公開定理: `JonnyLean.DiscreteProbability.eventMass_complement`。

契約は次の型を独立に記述し、公開定理から直接構成する。

```lean
theorem contract_JL059 {α : Type u} (w : α → Nat) (p : α → Bool) (xs : List α) :
    eventMass w p xs + eventMass w (fun a => !p a) xs = mass w xs
```

## 境界と範囲

空の結果リストと重み 0 を許す。補事象は列挙した台の中で評価する。非交和の加法性は各台上で `p a = true → q a = false` という明示的な仮定を必要とする。
