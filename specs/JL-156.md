# JL-156: 入力アルファベット写像の引き戻し

## 対象と定義

β文字を読む機械 M と写像 f : α → β から、α文字 a を f a として読む機械 M.comap f を作る。状態と受理判定は保持する。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL156_semantics (M : Machine β Q) (f : α → β) (q : Q) (a : α) : (M.comap f).step q a = M.step q (f a)
```

## 証明する命題

引き戻した機械での走行と、元の機械で写像後の語を読む走行の一致を証明する。受理言語の逆像、恒等写像、写像合成も示す。

主要公開定理: `JonnyLean.Automata.Machine.run_comap`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL156 (M : Machine β Q) (f : α → β) (q : Q) (w : List α) : (M.comap f).run q w = M.run q (w.map f)
```

## 境界と範囲

f の単射性・全射性は必要ない。同じβ文字へ写る異なる入力文字を許す。

境界契約:

```lean
theorem contract_JL156_boundary (M : Machine α Q) : M.comap id = M
```

## 検証

- 実装: `JonnyLean/Automata/InputMap.lean`。
- 独立契約: `contracts/JL156.lean`。主定理・定義の意味・境界を名前付き命題で検査する。
- 同梱 Init/Std と既存 JonnyLean のみを利用し、Mathlib は使用しない。
