# JL-067: 有限積のゼロ条件と整除

## 対象と定義

`product [] = 1`、`product (a::xs) = a*product xs`。列の重複も積の因子として数える。

## 証明する命題

自然数列の有限積を再帰構成し、ゼロ因子の存在、正値性、連結公式、各要素による整除を示す。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem product_eq_zero (xs : List Nat) : product xs = 0 ↔ 0 ∈ xs
```

公開補題: `product_append`、`product_eq_zero`、`member_dvd_product`、`product_positive`、`product_singleton`。

## 独立契約

`contracts/JL067.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL067` で独立に記述する。`contract_JL067_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

空積は1であり0ではない。0を含む列の積は0。

境界契約は `product [] = 1` と `product [3,0,7] = 0`。
