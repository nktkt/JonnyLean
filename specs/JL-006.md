# JL-006: 自然数の偶奇分解

## 対象と境界

すべての自然数が偶数または奇数であることを具体的な証人で示す。混合和・奇数和と排他性も証明する。

変数 n は任意の自然数で、0 を含む。正値の仮定はない。偶数と奇数はそれぞれ 2*k と 2*k+1 の形とする。

## 完全な契約命題

```lean
∀ n : Nat, (∃ k : Nat, n = 2 * k) ∨ (∃ k : Nat, n = 2 * k + 1)
```

公開定理は `JonnyLean.even_or_odd`。契約名は `JonnyLean.Contracts.JL006.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 証明の構成

0 は偶数。後者関数は偶数を奇数へ、奇数を偶数へ移すため、n の構造帰納法で証明する。

このモジュールに含まれる名前付き定理:

- `even_succ_odd`
- `odd_succ_even`
- `even_add_odd`
- `odd_add_even`
- `odd_add_odd`
- `even_or_odd`
- `not_even_and_odd`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `zero_even`: `∃ k : Nat, 0 = 2 * k`。
- `one_odd`: `∃ k : Nat, 1 = 2 * k + 1`。
- `mixed_sum`: `∃ k : Nat, 4 + 3 = 2 * k + 1`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。

## 実装・依存・検査

- 実装: `JonnyLean/NumberTheory/OddSums.lean`。
- 契約: `contracts/JL006.lean`。
- 課題依存: JL-001。
- Lean: `leanprover/lean4:v4.29.1`、同梱 Init/Std のみ。
- `sorry`、`admit`、新規公理、`Classical.choice` は使用しない。
- 許容公理はプロジェクト方針の `propext` と `Quot.sound` のみ。
- 機械検査と独立レビューは区別する。レビューの正式な状態は `reviews/JL-006.json` に記録する。

```sh
lake build +JonnyLean.NumberTheory.OddSums
lake env lean -DwarningAsError=true JonnyLean/NumberTheory/OddSums.lean
lake env lean -DwarningAsError=true contracts/JL006.lean
```

契約末尾の `#print axioms` が公開定理と名前付き契約の公理依存を出力する。
