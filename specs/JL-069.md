# JL-069: 互いに素な因子の取消しと同時整除

## 対象と定義

自然数の標準整除を使い、取消しには `Nat.gcd a b = 1` を明示する。

## 証明する命題

gcd(a,b)=1のもとで積bcの整除からbを取り消し、aとbの共通倍数がabの倍数となることを構成的な証人で示す。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem coprime_product_dvd_iff (a b c : Nat) (h : Nat.gcd a b = 1) :
    a*b ∣ c ↔ a ∣ c ∧ b ∣ c
```

公開補題: `coprime_cancel`、`coprime_cancel_power`、`coprime_two_factors`、`coprime_product_dvd_iff`。

## 独立契約

`contracts/JL069.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL069` で独立に記述する。`contract_JL069_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

互いに素の仮定は不可欠。a=6,b=4,c=12では各因子はcを割るが積は割らない。

境界契約は `(6:Nat)*5 ∣ 90` と `¬ ((6:Nat)*4 ∣ 12)`。
