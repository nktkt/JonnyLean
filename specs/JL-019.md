# JL-019: 等比和の除算を使わない公式

## 対象と境界

正の自然数を底とする有限等比和について (a-1)Σa^i=a^n-1 を証明する。法則を除算の部分性に依存させず、a=1 も扱う。

a>0、n は 0 を含む自然数。減算は Nat の切り捨て減算。主公式は a=1 でも成立し、除算は行わない。補助の a*S+1=S+a^n は a=0 にも成立する。

## 完全な契約命題

```lean
∀ a n : Nat, 0 < a → (a - 1) * sumSpec (fun i => a ^ i) n = a ^ n - 1
```

公開定理は `JonnyLean.geometric_sum_sub_formula`。契約名は `JonnyLean.Contracts.JL019.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 契約が固定する再帰定義

実装側の定義名に依存しない、契約内の独立した定義である。両者の一致は構造帰納法で別に検査する。

```lean
def sumSpec (f : Nat → Nat) : Nat → Nat
  | 0 => 0
  | n + 1 => sumSpec f n + f n
```

## 証明の構成

先頭項を分離した等比和の再帰式から a*S+1=S+a^n を得る。a=(a-1)+1 を使って整理し、自然数の減算に変換する。

このモジュールに含まれる名前付き定理:

- `geometric_sum_one`
- `geometric_sum_recurrence`
- `geometric_sum_formula`
- `geometric_sum_split`
- `geometric_sum_mono_base`
- `geometric_sum_sub_formula`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `empty_geometric`: `(3 - 1) * sumSpec (fun i => 3 ^ i) 0 = 3 ^ 0 - 1`。
- `base_one`: `(1 - 1) * sumSpec (fun i => 1 ^ i) 5 = 1 ^ 5 - 1`。
- `base_two`: `(2 - 1) * sumSpec (fun i => 2 ^ i) 4 = 2 ^ 4 - 1`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。
