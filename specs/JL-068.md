# JL-068: 有限積との互いに素性の特徴付け

## 対象と定義

互いに素とは `Nat.gcd a b = 1`。有限積には JL-067 の再帰定義を用いる。

## 証明する命題

ある自然数が有限積と互いに素であることと、すべての因子と互いに素であることを同値にする。連結と積の累乗への保存も得る。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem gcd_product_eq_one_iff (a : Nat) (xs : List Nat) :
    Nat.gcd a (product xs) = 1 ↔ ∀ b ∈ xs, Nat.gcd a b = 1
```

公開補題: `gcd_product_eq_one`、`gcd_product_eq_one_iff`、`gcd_product_append`、`gcd_product_powers`。

## 独立契約

`contracts/JL068.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL068` で独立に記述する。`contract_JL068_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

空列との互いに素性は任意の自然数で成立する。因子0がある場合、互いに素となる入力は1に限られる。

境界契約は `Nat.gcd 0 (product []) = 1` と `Nat.gcd 5 (product [6,7,9]) = 1`。
