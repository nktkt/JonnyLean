# JL-099: 形式微分の積則と連鎖律

## 対象と定義

JL-098の形式微分と、JL-085・JL-086の係数演算を組み合わせる。等式は全自然数入力での評価について述べる。

## 証明する命題

有限係数の再帰構成から、積の形式微分と多項式合成の連鎖律を証明する。平方と入力平行移動の微分公式も導く。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem evaluate_derivative_compose (p q : Polynomial) (x : Nat) :
    evaluate (derivative (compose p q)) x =
      evaluate (derivative p) (evaluate q x) * evaluate (derivative q) x
```

公開補題: `evaluate_derivative_multiply`、`evaluate_derivative_compose`、`evaluate_derivative_square`、`evaluate_derivative_translate`。

## 独立契約

`contracts/JL099.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL099` で独立に記述する。`contract_JL099_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

入力が0でも法則は成立する。自然数係数の形式微分であり、負係数・実数関数・極限を仮定しない。

境界契約は `evaluate (derivative (compose [0,0,1] [1,1])) 2 = 6` と `evaluate (derivative (multiply [] [1,1])) 3 = 0`。

## 検証と依存制約

- 実装: `JonnyLean/Polynomials/DerivativeRules.lean`。
- 契約: `contracts/JL099.lean`。
- Lean 4.29.1 同梱の Init/Std のみを使用し、Mathlibを使わない。
- 未使用・private・自動生成宣言と契約も含めて公理依存を調べ、許容する基礎は `propext` と `Quot.sound` のみ。`sorry`、`admit`、独自公理、`Classical.choice` は許さない。
- 機械検証は独立した仕様レビューの承認を意味しない。

```sh
lake build JonnyLean.Polynomials.DerivativeRules
lake env lean -DwarningAsError=true JonnyLean/Polynomials/DerivativeRules.lean
lake env lean -DwarningAsError=true contracts/JL099.lean
```
