# JL-232: 正規表現閉包の一段展開

## 対象と命題

閉包による受理は空語の場合か、基底言語の一語と閉包の一語を連結する場合のいずれかである。

空語を受理する基底言語も許し、分解の一意性は主張しない。これは有限反復の展開式。

```lean
theorem contract_JL232 (r : Regex α) (w : List α) : denotes (.star r) w ↔ w = [] ∨ ∃ u v, denotes r u ∧ denotes (.star r) v ∧ u ++ v = w :=
  star_unfold r w
```

上の命題は独立契約の型であり、公開定理 `JonnyLean.RegularExpressions.star_unfold` をその型へ代入する。契約の型はLeanによる推論任せにせず明記する。

## 定義と実装

実装は `JonnyLean/RegularExpressions/Transformations.lean`。定義に対する契約は次の計算式を直接検査する。

```lean
theorem contract_JL232_definition (r : Regex α) : denotes (.star r) = JonnyLean.Languages.Star (denotes r) := rfl
```

## 証明の構成

Starのnil/step構築子の分解と再構成により両方向を証明する。

仕様の必要な仮定は上記の型にすべて記載し、成立させるための例外や結果そのものの仮定を追加しない。

## 境界例

```lean
theorem contract_JL232_boundary : accepts (.star (.zero : Regex Bool)) [true] = false := by decide
```

この具体例に加え、主定理は任意の型・値・有限入力に対する量化を保つ。具体例だけによる一般命題の代用はしない。
