# JL-087: 多項式の自然数累乗

## 対象と定義

`power p 0=[1]`、`power p (n+1)=multiply (power p n) p`。

## 証明する命題

畳み込み積による反復累乗を実装し、評価との交換、指数の加法と乗法、合成との交換を証明する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem evaluate_power (p : Polynomial) (n x : Nat) :
    evaluate (power p n) x = (evaluate p x)^n
```

公開補題: `evaluate_power`、`evaluate_power_add`、`evaluate_power_mul`、`evaluate_compose_power`。

## 独立契約

`contracts/JL087.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL087` で独立に記述する。`contract_JL087_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

零多項式の0乗も定数1と定義する。係数列の末尾0は正規化しない。

境界契約は `evaluate (power [] 0) 0 = 1` と `evaluate (power [1,1] 3) 2 = 27`。
