# JL-160: 不変状態型への制限と有限carrier

## 対象と定義

開始状態を含む遷移不変述語 P から、状態型を `{q // P q}` に制限した機械を構成する。有限リストstatesの場合は開始状態の所属と遷移閉性を仮定する。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL160_semantics (M : Machine α Q) (P : Q → Prop) (hs : M.Stable P) (h0 : P M.start) : (M.restrict P hs h0).start.val = M.start
```

## 証明する命題

制限機械の受理言語が元と等しいことを包含準同型から導く。有限carrier内に全走行が留まることと、到達可能状態だけへの制限も示す。

主要公開定理: `JonnyLean.Automata.Machine.language_restrict`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL160 (M : Machine α Q) (P : Q → Prop) (hs : M.Stable P) (h0 : P M.start) : (M.restrict P hs h0).language = M.language
```

## 境界と範囲

有限リストに状態の重複を許す。全ての外部状態を列挙する必要はない。有限性が必要なDFAモデルはこの閉じたcarrierの部分型で表せる。

境界契約:

```lean
theorem contract_JL160_boundary (M : Machine α Q) (states : List Q) (h0 : M.start ∈ states) : M.run M.start [] ∈ states
```

## 検証

- 実装: `JonnyLean/Automata/Restriction.lean`。
- 独立契約: `contracts/JL160.lean`。主定理・定義の意味・境界を名前付き命題で検査する。
- 同梱 Init/Std と既存 JonnyLean のみを利用し、Mathlib は使用しない。
- 全宣言について `sorry`、独自公理、`Classical.choice` を禁止する。許容する基礎公理は `propext` と `Quot.sound` のみ。
- 機械検証は独立レビューによる承認を意味しない。

```sh
lake build JonnyLean.Automata.Restriction
lake env lean -DwarningAsError=true JonnyLean/Automata/Restriction.lean
```
