# JL-012: 二次多項式による合同の保存

## 対象と境界

合同な入力を同じ自然数係数の二次多項式へ代入すると、結果も合同になる。加法・乗法・任意自然数累乗・アフィン式の保存を積み上げる。

法 m と係数 u,v,w は 0 でもよい。唯一の仮定は a%m=b%m。自然数累乗の 0 乗は 1 とする。

## 完全な契約命題

```lean
∀ m a b u v w : Nat, a % m = b % m → (u * a ^ 2 + v * a + w) % m = (u * b ^ 2 + v * b + w) % m
```

公開定理は `JonnyLean.congruent_quadratic`。契約名は `JonnyLean.Contracts.JL012.contract` である。整除・偶奇・合同の課題では存在命題または剰余等式を契約に直接記述する。再帰的対象を扱う課題では下記の独立定義を使う。

## 証明の構成

剰余の加法則と乗法則から各演算の保存を証明する。累乗は指数について帰納法を使い、これらを二次式の各項へ適用する。

このモジュールに含まれる名前付き定理:

- `congruent_add`
- `congruent_mul`
- `congruent_pow`
- `congruent_affine`
- `congruent_quadratic`

これらは一つの公開課題を支える再利用可能な補助定理であり、同じ主張を別課題として重複計上しない。

## 境界例

- `modulus_one`: `(7 * 3 ^ 2 + 2 * 3 + 9) % 1 = (7 * 8 ^ 2 + 2 * 8 + 9) % 1`。
- `quadratic_example`: `(2 * 3 ^ 2 + 3 + 4) % 5 = (2 * 8 ^ 2 + 8 + 4) % 5`。
- `zero_modulus`: `(2 * 3 ^ 2 + 3 + 4) % 0 = (2 * 3 ^ 2 + 3 + 4) % 0`。

契約の有限例だけで一般命題を証明したことにはしない。すべての量化された値に対する証明を Lean が検査する。

## 実装・依存・検査

- 実装: `JonnyLean/NumberTheory/CongruenceOperations.lean`。
- 契約: `contracts/JL012.lean`。
- 課題依存: JL-011。
- Lean: `leanprover/lean4:v4.29.1`、同梱 Init/Std のみ。
- `sorry`、`admit`、新規公理、`Classical.choice` は使用しない。
- 許容公理はプロジェクト方針の `propext` と `Quot.sound` のみ。
- 機械検査と独立レビューは区別する。レビューの正式な状態は `reviews/JL-012.json` に記録する。

```sh
lake build +JonnyLean.NumberTheory.CongruenceOperations
lake env lean -DwarningAsError=true JonnyLean/NumberTheory/CongruenceOperations.lean
lake env lean -DwarningAsError=true contracts/JL012.lean
```

契約末尾の `#print axioms` が公開定理と名前付き契約の公理依存を出力する。
