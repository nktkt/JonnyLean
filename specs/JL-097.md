# JL-097: 係数打ち切りと高次項の整除

## 対象と定義

低次部分は `p.take n`、残りは `p.drop n`。足りない係数を補うための仮定は不要。

## 証明する命題

最初のn係数と残りの係数へ分割し、評価を低次部分とXのn乗倍へ分解する。打ち切り評価の下界、差の整除、Xのn乗を法とする剰余一致を証明する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem evaluate_truncate (p : Polynomial) (n x : Nat) :
    evaluate p x = evaluate (p.take n) x + x^n * evaluate (p.drop n) x
```

公開補題: `evaluate_truncate`、`evaluate_take_le`、`evaluate_drop_dvd_difference`、`evaluate_take_mod`。

## 独立契約

`contracts/JL097.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL097` で独立に記述する。`contract_JL097_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

nが係数長を超えると残りは空列となる。入力0や指数0を含み、法0の場合もLeanの剰余規約を使う。

境界契約は `evaluate ([3,2,1].take 0) 10 = 0` と `evaluate [3,2,1] 10 % (10^2) = 23`。
