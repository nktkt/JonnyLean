# JL-085: 係数列の畳み込み積の正しさ

## 対象と定義

`multiply [] q=[]`、`multiply (a::p) q=add (scale a q) (0::multiply p q)`。

## 証明する命題

先頭係数によるスカラー倍と再帰的な積のシフトを加える畳み込み積を実装し、評価が数の積になることを示す。分配・結合・交換則を評価の意味で導く。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem evaluate_multiply (p q : Polynomial) (x : Nat) :
    evaluate (multiply p q) x = evaluate p x * evaluate q x
```

公開補題: `evaluate_multiply`、`evaluate_multiply_comm`、`evaluate_multiply_assoc`、`evaluate_multiply_add`、`evaluate_multiply_one`。

## 独立契約

`contracts/JL085.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL085` で独立に記述する。`contract_JL085_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

末尾0を除去しないため積の交換則等は評価についての定理とする。係数リストの構造等式は主張しない。

境界契約は `evaluate (multiply [] [2,3]) 9 = 0` と `evaluate (multiply [1,1] [1,1]) 3 = 16`。
