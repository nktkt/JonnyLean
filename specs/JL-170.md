# JL-170: 直積事象の抽出と計数の分離

## 対象と定義

左成分のBoolean条件pと右成分の条件qの両方を満たす直積の出現をfilterする。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL170_semantics (p : α → Bool) (q : β → Bool) (xs : List α) (ys : List β) : (product xs ys).filter (fun z => p z.1 && q z.2) = product (xs.filter p) (ys.filter q)
```

## 証明する命題

直積をfilterしたリストが各成分をfilterしてから作る直積と一致すると証明する。結果の長さが二つの抽出長の積であることと、左成分だけの抽出も示す。

主要公開定理: `JonnyLean.Counting.length_filter_product`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL170 (p : α → Bool) (q : β → Bool) (xs : List α) (ys : List β) : ((product xs ys).filter (fun z => p z.1 && q z.2)).length = (xs.filter p).length * (ys.filter q).length
```

## 境界と範囲

二条件は各自の成分だけに依存する。一般の対に依存する条件に対する積への分離は主張しない。

境界契約:

```lean
theorem contract_JL170_boundary (p : α → Bool) (q : β → Bool) (ys : List β) : ((product [] ys).filter (fun z => p z.1 && q z.2)).length = 0
```
