# JL-043: 状態付き走査の不変条件

## 対象・定義・仮定

`step : σ → α → σ × β` は更新状態と一つの出力を返す。`mapState step state xs` は左から右へ走査し最終状態と出力列を返す。状態・入力・出力型は異なってよい。

各一歩が状態述語を保存し出力述語を満たすなら、列全体の状態付き走査も最終状態の述語と全出力の述語を満たす。長さ、最終 fold 状態、連結則も示す。

```lean
theorem JonnyLean.Contracts.JL043 {σ : Type u} {α : Type v} {β : Type w}
    (step : σ → α → σ × β) (p : σ → Prop) (q : β → Prop)
    (preserve : ∀ s x, p s → p (step s x).1 ∧ q (step s x).2)
    (state : σ) (xs : List α) (hs : p state) :
    p (JonnyLean.Algorithms.mapState step state xs).1 ∧
```

## 証明と範囲

初期状態を一般化した列の帰納法。一歩の保存仮定を得て、その状態で残りの帰納仮定を適用する。出力先頭には一歩の仮定、出力末尾には帰納仮定を使う。

一般の入力に対する証明であり、具体例のみの有限検査ではない。補助定理は同じモジュールにあり、契約の追加例では境界ケースや関連した性質も検査する。仕様にない性能計算量・停止時間・外部環境での実行結果は主張しない。
