# JL-072: 剰余を保ちながら計算する累乗

## 対象と定義

`modularPower m a 0 = 1%m`、後続指数では前の結果に a を掛けて m で割った余りを取る。

## 証明する命題

各乗算後に剰余を取る累乗アルゴリズムを実装し、通常の累乗の剰余と一致すること、範囲、指数加法、入力の正規化を証明する。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem modularPower_correct (m a n : Nat) : modularPower m a n = a^n % m
```

公開補題: `modularPower_correct`、`modularPower_bounded`、`modularPower_add`、`modularPower_input`、`modularPower_zero_modulus`。

## 独立契約

`contracts/JL072.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL072` で独立に記述する。`contract_JL072_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

法0では通常の累乗を返す。法1では指数0も含めて0を返す。範囲定理には法が正であることを要求する。

境界契約は `modularPower 0 3 4 = 81` と `modularPower 5 3 4 = 1`。

## 検証と依存制約

- 実装: `JonnyLean/Arithmetic/ModularPower.lean`。
- 契約: `contracts/JL072.lean`。

- 未使用・private・自動生成宣言と契約も含めて公理依存を調べ、許容する基礎は `propext` と `Quot.sound` のみ。`sorry`、`admit`、独自公理、`Classical.choice` は許さない。
