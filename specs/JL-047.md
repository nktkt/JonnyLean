# JL-047: 端点付き歩道と頂点列の長さ

## 対象と定義

`Walk G x y` は始点と終点を型に持つ有限歩道である。`nil x` は空歩道、`cons e p` は辺 `e : G.edge x y` を歩道 `p : Walk G y z` の前につなぐ。

歩道は頂点・辺の重複を許す。`length` は辺数で、空歩道では 0、前に辺を加えると 1 増える。`vertices` は端点を含む頂点列で、空歩道でも `[x]` を返す。

## 証明する命題

歩道の帰納法により、頂点列の長さが辺数よりちょうど 1 多いことを示す。長さ 0 なら始点と終点が等しいこと、異なる端点を結ぶ歩道は正の長さを持つことも示す。

主要公開定理: `JonnyLean.GraphTheory.Walk.vertices_length`。

契約は次の型を独立に記述し、公開定理から直接構成する。

```lean
theorem contract_JL047 {V : Type u} {G : Graph V} {x y : V} (p : Walk G x y) :
    p.vertices.length = p.length + 1
```

## 境界と範囲

空歩道の辺数は 0、頂点数は 1。自己ループ 1 本の歩道の辺数は 1。閉歩道だから長さが 0 とは限らない。単純路を定義する課題ではない。
