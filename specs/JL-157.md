# JL-157: 遷移不変量と全語に対する拒否

## 対象と定義

状態述語 P が各一文字遷移で保存されることを Stable とする。開始状態または任意の現在状態が P を満たすと仮定する。

定義の意味を契約で次のように固定する。

```lean
theorem contract_JL157_semantics (M : Machine α Q) (P : Q → Prop) : M.Stable P ↔ ∀ q a, P q → P (M.step q a)
```

## 証明する命題

任意の有限語を読んだ後も P が保たれることを証明する。不変状態全ての受理判定がfalseなら全ての語を拒否する。不変量の共通部分も保存される。

主要公開定理: `JonnyLean.Automata.Machine.run_invariant`。

独立契約は、仕様に対応する期待型を明示して公開定理を適用する。

```lean
theorem contract_JL157 (M : Machine α Q) (P : Q → Prop) (hs : ∀ q a, P q → P (M.step q a)) (q : Q) (hq : P q) (w : List α) : P (M.run q w)
```

## 境界と範囲

帰納法は入力語の長さに対して行う。全ての状態がPを満たす必要はなく、出発状態の証明だけを要求する。

境界契約:

```lean
theorem contract_JL157_boundary (M : Machine α Q) (P : Q → Prop) (q : Q) (hq : P q) : P (M.run q [])
```
