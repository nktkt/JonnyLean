# JL-084: 単項式Xの累乗による係数列シフト

## 対象と定義

`shift 0 p=p`、`shift (n+1) p=0::shift n p`。低次係数側に0を挿入する。

## 証明する命題

先頭へn個の0を挿入する演算を実装し、評価がXのn乗倍になること、シフトの合成、長さ、スカラー倍との交換を示す。

主定理の型は次のとおりで、量化された任意の入力について証明する。有限個の計算例の検査で代用しない。

```lean
theorem evaluate_shift (n : Nat) (p : Polynomial) (x : Nat) :
    evaluate (shift n p) x = x^n * evaluate p x
```

公開補題: `evaluate_shift`、`shift_add`、`shift_length`、`shift_scale`。

## 独立契約

`contracts/JL084.lean` は当該モジュールを直接 import し、主定理の期待する命題を別名 `contract_JL084` で独立に記述する。`contract_JL084_definition` は使用する定義の計算式または命題の意味を明示し、二つの名前付き境界定理を別に検査する。

## 境界と範囲

空列をシフトすると零係数のみの列となり、評価は常に0。指数0では入力をそのまま返す。

境界契約は `shift 0 [] = []` と `evaluate (shift 2 [3,1]) 4 = 112`。
