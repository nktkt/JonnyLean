# JL-113: 二リストキューの正規化不変条件

## 対象と境界

frontと反転したbackの連結をFIFO列とする。frontが空の場合だけbackを反転する正規化は内容を保存し、空frontなら空backという不変条件と冪等性を満たす。

キューの論理列は `front ++ reverse back`。未正規化の入力も許す。空frontなら空backという不変条件は、結果の正規化について明示した場合だけ要求する。

## 完全な契約命題

```lean
∀ (α : Type u) (q : Queue α), queueView (Queue.normalize q) = queueView q ∧ ((Queue.normalize q).front = [] → (Queue.normalize q).back = []) ∧ Queue.normalize (Queue.normalize q) = Queue.normalize q
```

公開定理は `JonnyLean.DataStructures.Queue.normalize_contents`。固定された名前付き契約は `JonnyLean.Contracts.JL113.contract`。

## 独立した意味モデル

以下は `JonnyLean/DataStructures/SpecificationModels.lean` にある固定モデルである。実装対象の関数を呼ばずに再帰または一命令の状態遷移を定義する。各 `*_matches` 補題を構造帰納法で検査してから公開定理と接続する。

```lean
def queueView (q : DataStructures.Queue α) : List α := q.front ++ q.back.reverse
```

## 証明の構成と再利用補題

構文または入力列の構造帰納法を基礎にし、任意の部分木・式・初期状態について帰納仮定を適用する。蓄積引数・後続列・環境は必要に応じて一般化している。独立モデルとの橋渡しは契約の検査に含まれ、主張を実装の型の別名だけで済ませない。

この課題に関連する再利用補題:

- `Queue.normalize_normal`。
- `Queue.normalize_of_normal`。
- `Queue.normalize_idempotent`。

同じ補題を複数の課題として重複計上しない。評価保存、固定点、サイズ制約、静的検査は異なる明示命題として区別する。

## 境界例

- `empty_queue`: `Queue.normalize (⟨[], []⟩ : Queue Nat) = ⟨[], []⟩`。
- `rotate_back`: `Queue.normalize (⟨[], [3, 2, 1]⟩ : Queue Nat) = ⟨[1, 2, 3], []⟩`。

有限例は境界条件の固定に使う。一般命題の証明を例の列挙で代替しない。
