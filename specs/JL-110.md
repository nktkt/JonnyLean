# JL-110: 二分木の外部葉数公式

## 対象と境界

空木を一つの外部葉として数えると、任意の有限二分木の外部葉数は値付き節点数よりちょうど一つ多い。完全木や平衡木の仮定は不要。

木は空木 `empty` または左右の部分木と値を持つ `node` からなる有限二分木。空木は節点数・高さ0で、外部葉としては1個に数える。値型に有限性・順序・等号判定は仮定しない。

## 完全な契約命題

```lean
∀ (α : Type u) (t : Tree α), leaves t = nodes t + 1
```

公開定理は `JonnyLean.Trees.Tree.externalLeaves_eq`。固定された名前付き契約は `JonnyLean.Contracts.JL110.contract`。

## 独立した意味モデル

以下は `JonnyLean/Trees/SpecificationModels.lean` にある固定モデルである。実装対象の関数を呼ばずに再帰または一命令の状態遷移を定義する。各 `*_matches` 補題を構造帰納法で検査してから公開定理と接続する。

```lean
def leaves : Tree α → Nat
  | .empty => 1
  | .node l _ r => leaves l + leaves r

def nodes : Tree α → Nat
  | .empty => 0
  | .node l _ r => 1 + nodes l + nodes r
```

## 証明の構成と再利用補題

構文または入力列の構造帰納法を基礎にし、任意の部分木・式・初期状態について帰納仮定を適用する。蓄積引数・後続列・環境は必要に応じて一般化している。独立モデルとの橋渡しは契約の検査に含まれ、主張を実装の型の別名だけで済ませない。

この課題に関連する再利用補題:

- 公開定理の帰納証明が課題の一般命題を直接検査する。

同じ補題を複数の課題として重複計上しない。評価保存、固定点、サイズ制約、静的検査は異なる明示命題として区別する。

## 境界例

- `empty_has_one_leaf`: `leaves (Tree.empty : Tree Nat) = 1`。
- `single_has_two`: `leaves (.node .empty 0 .empty) = 2`。

有限例は境界条件の固定に使う。一般命題の証明を例の列挙で代替しない。
