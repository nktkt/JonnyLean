# 初等数学ロードマップ

各課題は、対象・定義・仮定・結論の日本語仕様、Lean の一般証明、独立した型を要求する契約を備える。以下の実装状態は人間のレビューや承認を意味しない。

| ID | 課題 | 到達目標 | 状態 |
| --- | --- | --- | --- |
| JL-001 | 偶数どうしの和 | `∀ a b : Nat, Even a → Even b → Even (a + b)`。偶数は `∃ k : Nat, n = 2 * k`。 | 仕様・証明・契約を実装 |
| JL-002 | 連続する自然数の積 | `∀ n : Nat, Even (n * (n + 1))`。0 を含むすべての自然数。 | 仕様・証明・契約を実装 |
| JL-003 | 三角数の和の公式 | `T 0 = 0`、`T (n + 1) = T n + (n + 1)` と定義し、`∀ n : Nat, 2 * T n = n * (n + 1)`。 | 仕様・証明・契約を実装 |
| JL-004 | 交わらない有限集合の和集合の濃度 | 共通の要素がない有限集合に対し `card (union A B) = card A + card B`。重複なし表現、通常の和集合の membership、表現によらない濃度も証明。 | 仕様・証明・契約を実装 |
| JL-005 | 冪集合の濃度 | `card (powerset A) = 2 ^ card A`。全部分集合の網羅、包含条件、重複なし性、同じ数学的部分集合の代表の一意性も証明。 | 仕様・証明・契約を実装 |

すべて Lean `4.29.1` 同梱ライブラリのみで完結し、Mathlib 等の外部パッケージに依存しない。JL-002 は JL-001 の偶数定義を用い、JL-003 は JL-002 の算術補題を再利用する。JL-005 は JL-004 の有限集合表現を用いる。

JL-001 から JL-003 の公開定理の実際の公理依存は空である。JL-004 と JL-005 は同梱 List 補題に由来する `propext` と `Quot.sound` に依存するため、プロジェクトの許可方針に明示する。新規公理、`Classical.choice`、`sorryAx` は使わない。

有限集合は `List` と `Nodup` の証明を組み合わせる。列挙の順序と数学的な集合の等しさを区別し、membership の一致から濃度の一致を証明する。冪集合は元の列挙の部分列を代表に選び、順序違いの同じ集合を二重計上しないことを証明する。詳細な型と境界例は各仕様・契約を参照する。
